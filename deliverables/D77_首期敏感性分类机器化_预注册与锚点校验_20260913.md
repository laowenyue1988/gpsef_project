## §4 四档分类（判据在结果之前冻结）

设 `d_full` = 全窗 ΔCalmar%、`d_ex` = 剔除首期后 ΔCalmar%、`mdd_ok` = 子窗 `|MaxDD_arm| ≤ |MaxDD_ctrl|`：

| 档 | 判定式 | 语义 |
|---|---|---|
| ① **单期驱动（脆弱否证）** | `d_full < 0 ∧ d_ex ≥ +10 ∧ mdd_ok` | 增益由首个持有期单独驱动 ⇒ **不构成**对窗口结论的稳健否证 |
| ② **全期广泛（稳健否证）** | `d_ex ≤ −10`（且非①） | **计入**「整体不稳健」证据链 |
| ③ **灰区（保守计入）** | `−10 < d_ex < +10`（且非①） | 保守计入 |
| ④ **单日+分段驱动（事件段驱动）** | 本应落③ ∧ **O-7 ③ 分段证据成立**（`--seg-evidence yes`） | 首例 = M8/`R2A-OVER_c3`；须在结论标题标注"由 X 段驱动" |
| ⑤ 通过（未触发否证档） | `d_ex ≥ +10`（且非①） | 首期外仍达标 |

**★边界含等号**（E6/E7 断言）：`d_ex = +10.00%` 判**通过**；`d_ex = −10.00%` 判**全期广泛**。

**★限定**：分类只作用于**未复现臂**；对已达标的臂调用本工具仅作披露用途。
