## 一、我对需求的理解（逐条复述）

1. **基准策略** = `strategies/hs300_alpha191/`（标准对齐版：HP-Search + 嵌套 Purged K-Fold + MDA 投票 + 聚类 + 折集成扰动 + AUC 门控，**不含** small_alpha191_test 的 O1+ 两轮迭代——您未要求，我不加入）。

4. **其余模块必须逐字节一致**：labels / ensemble / data_utils / pool / factors / barriers / snapshot / __init__ 等全部复制，md5 校验相等。

### 3.2 解读（超参调整的客观依据）

1. **信号极弱**：PKF meta_auc ≈ 0.50-0.51，接近随机；HP-Search 候选 AUC 差距仅 0.01-0.02。这是 hs300 大盘股 + 20 日调仓的弱信号本性。
2. **已存在中度过拟合**：train/OOS gap = 0.04-0.10。
3. **浅模型 + 强正则胜出**：两次重训分别选中 c1（depth3，最浅最正则）与 c3（depth5，中正则）；c2（现状 baseline，depth6）与 c4（depth6/cs0.8 最强）均垫底（0.510-0.522）。
4. **因子池扩大 +40% 维度**（302 → 423 特征），样本不变（70.9K）→ 过拟合风险进一步上升，且参考回测已证明深模型在此场景不占优。

## 五、需您确认的决策点

- **D1 — total_score 是否纳入因子池？** wyckoff 快照的 `total_score`（V5 综合得分，类似 v10_pred 的角色）。建议**纳入**（作为 `wv_total_score`，与其余 120 列同等待遇，交由特征选择裁决）。若您认为它与 40 个 score 列高度冗余，可排除。
- **D2 — 列前缀 `wv_`**：为特征可识别性 + 避免与 alpha 的 score/conf 扫描冲突，建议统一前缀。如无异议按此执行。
- **D3 — 超参调整方案**（第三节 3.3 表格）：是否认可"整体向更浅+更强正则平移一档"？如认可，按表实施；如希望更保守（仅微调）或更激进，请指示。
- **D4 — 等价性测试开关**：config `factor_pool_extra.enabled: false` 时行为必须与原版逐位一致（这是"只有因子池不同"的最强证明）。建议保留该开关（默认为 true）。

## 七、风险与说明

1. **训练耗时上升**：423 特征 vs 302（+40%），HP-Search / PKF / MDA 的每次训练与置换评估变慢，首日总耗时预计从 ~15min 升至 ~20-25min；重训间隔 ri=1 时全程累计耗时显著增加。若您在意，可顺带评估 ri=5（本次不改，仅提示）。
2. **meta_auc 大概率仍弱**：参考回测已显示 0.50-0.51 水平；威科夫因子能否带来增量取决于其与 P(profit) 的真实相关性，本次扩展的价值以最终回测绩效（vs 基准）裁决。
3. **wyckoff 快照 2020-07 前缺失**：训练窗口最早 2021-07，无影响。
4. **bj. 代码映射局限**：`map_code_to_ts_code` 不识别 4/8 开头（北京所），但 hs300 池无北交所股票，且 wyckoff 覆盖 99%，影响可忽略。
5. **中性化维度**：331 因子 × OLS 中性化（行业+log_mv），逻辑不变，仅列数增加。
