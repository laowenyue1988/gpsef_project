## 二、根因（代码级证据链）

### 2.1 回撤熔断状态机（`_update_dd_breaker`, strategy.py L3597-3634）

三态设计: 0=NORMAL(满仓) / 1=HALF(建仓 x0.5) / 2=FLAT(不建仓)
- 触发: 回撤 ≤ -15% → FLAT; 回撤 ≤ -10% → HALF
- 恢复: FLAT→HALF 需指数≥MA 连续 trend_confirm_days(3) 日 + **峰值重置**;
  HALF→NORMAL 需回撤收窄 > -5%

### 2.2 缺陷: FLAT 恢复的"峰值重置"赦免全部历史亏损

```
L3627:  self._dd_peak = self._prev_nav   # 峰值重置: 以恢复入场点净值为新基线
```

**2026-06~07 完整事件链（日志实证）**:

| 日期 | 事件 | 净值 | 回撤(对真实峰值) |
|---|---|---|---|
| 06-16 | 满仓建仓 x1.0 (趋势AUC门控放行 AUC=0.5792>0.50) | 1,297,320 | ~-5% |
| 06-22 | **回撤 -10.50% → HALF** | 1,256,417 | -10.5% |
| 06-26 | **回撤 -15.41% → FLAT 不建仓** | 1,187,518 | -15.4% |
| 07-01 | 指数确认3日 → FLAT→HALF (**峰值重置 1,182,201**) | 1,182,201 | 重置后 dd=0 |
| 07-02 | **回撤 0.00% > -5% → NORMAL 满仓** | 1,182,930 | 被赦免 |
| 07-15 | 调仓日 回撤熔断=1.0 (满仓逻辑, 实际 -9.4% 应 HALF) | 1,174,735 | -9.4% |
| 07-24 | **最大回撤 -19.37%** (熔断已失效) | 1,134,870 | -19.4% |

**机制**：FLAT 恢复分支把 `_dd_peak` 从真实历史高点 (1,368,281, 05-18) 强制改写为
当前净值 (1,182,201) → 回撤基线归零 → 次日 `dd=0 > -5%` 立即 NORMAL 满仓 →
**自 118 万起的任何后续下跌都不再受 10%/15% 门槛保护** → 7 月深跌 -19.37% 全程无熔断。

### 2.3 为什么 R12 同期没踩到

R12 与 test 的熔断代码**逐行相同**（缺陷是 R12 自带的）。R12 同期因趋势过滤
(旧版) 与选股差异，建仓多为 x0.5 半仓 → 回撤最深 -12.70% **未到 -15% 门槛** →
未触发 FLAT → 未触发峰值重置 → 熔断一直有效。本次 test 因：
1. 趋势AUC门控 06-16 满仓放行 (AUC=0.5792 > 0.50, 指数≥MA10) → 高仓位暴露
2. 净值峰值更高 (1,368,281) → 同跌幅回撤百分比更大
→ 回撤突破 -15% 触发 FLAT → 峰值重置 → 熔断失效

## 三、附带发现

1. **2024-02 同样发生** (回撤 -15.05% → FLAT → 峰值重置 929,444 → NORMAL)，2024 年最大回撤 -14.98% 也受此影响
2. 峰值重置共触发 2 次 (2024-02、2026-07)，均为 FLAT 恢复路径

## 四、修复方案（待用户确认后实施）

**核心原则**: FLAT→HALF 恢复时**保留历史峰值**（不重置 `_dd_peak`），
使熔断门槛对"从历史高点的回撤"持续有效；用指数确认（市场信号）解决
"空仓净值恒定 → 净值恢复条件死锁"的问题。

```python
# 修改前 (L3624-3630):
if self._dd_state == 2 and self._dd_above_days >= c['trend_confirm_days']:
    self._dd_state = 1
    self._dd_scale = 0.5
    self._dd_peak = self._prev_nav   # ← 缺陷: 赦免历史亏损
    self._dd_above_days = 0
    ...

# 修改后:
if self._dd_state == 2 and self._dd_above_days >= c['trend_confirm_days']:
    self._dd_state = 1
    self._dd_scale = 0.5
    # 不重置 _dd_peak → 回撤基线仍为历史高点, 熔断门槛持续有效
    self._dd_above_days = 0
    ...
```

**效果**: FLAT→HALF 后回撤仍按真实历史峰值计算；若回撤仍 ≤-15% 会立即再次
触发 FLAT (状态机触发守卫 `self._dd_state != 2` 防抖) → 实际进入
HALF/FLAT 交替，直到净值真正收复或指数确认多次后由市场信号驱动恢复。

**备选方案 B**: 峰值重置改为"重置到 FLAT 触发时的净值"，即回撤基线 = FLAT 入场点，
但不低于 dd_flat 阈值对应净值——需额外状态字段，复杂度高，暂不采用。
