## 二、亏损根因分解（五条，均有数据支撑）

### 根因 1：2024-01 微盘崩盘 = 单月 −19.8%（三臂一致）
- 2024-01：BASE −19.84% / L2 −19.74% / DD12 −19.76%——**系统性风险，无臂幸免**
- 主回撤段 = 2023-12-08 → 2024-09-18：BASE −38.7% / L2 −30.1% / DD12 −32.6%（段内）
- 该段内**低敞口日（<10%）占 43~48%**——近一半时间空仓，但依然深跌 ⇒ **损失发生在"熔断触发前的下跌段"与"存量持仓的继续下跌"**

### 根因 2：熔断"滞后触发"+ "只限建仓、不强清"
- 触发时回撤已 −15%~−17.7%（设计阈值 15%，但触发后**净值仍继续下跌**）
- **FLAT 期间净值继续跌**：BASE 五周期合计 **−5.13%**；L2 −3.47%；DD12 **−9.14%**（更频繁触发反而成本更高）
  - 2024-01 周期：L2 触发（1/24，−17.04%）→ 恢复（2/28）期间净值 **−4.97%**——**FLAT 不等于保护**（只限新仓、存量持仓裸奔）
- e3_derisk 批量清仓单笔 **−35%~−62%**（2024-01~02）：熔断触发时个股已深度重创（跌停/跳空无法及时卖出）

### 根因 3：熔断恢复条件过早 → "打地鼠"循环（2024-04~08）
- 恢复规则 = "指数确认 3 日"，过于机械：
  - BASE：4/16 触发 → 5/7 恢复 → **恢复后 20 日继续 −6.76%** → 6/26 再触发 → 8/5 恢复
  - L2：6/7 触发 → 8/5 恢复 → **恢复后 20 日 −2.90%**
- 三个周期连续"触发→恢复→再触发"，每次循环都在下跌中继重新进场。**

### 根因 4：纵深亏损的结构性放大器——"基线重置"
- 熔断恢复时"回撤基线重置至 FLAT 触发净值"⇒ 下一轮触发需从**新基线**再跌 15%
- 结果：−17% 触发 → 重置 → 再跌 15% 再触发 ⇒ **总回撤可以叠加到 −30%~−42%**（这正是 MaxDD ≈ 1−(1−dd_flat)^k 的机理；k=4~6 次触发）
- **DD-F12 的反例证明"仅调阈值不够"**：阈值 12% 触发更频（6 次），FLAT 期成本 −9.14%，**阈值调节只是改变了循环的节奏，没改变循环本身**

### 根因 5：L2 锁定机制的真实作用与局限（不可一票否定）
- **真实优势 1（防深亏）**：strategy 深阶段止损显著更轻（stage4_sl：−7.9 万 vs BASE −19.2 万；stage3_sl：−21.0 vs −28.2 万）；e3_derisk 亏损减半（−13.4 vs −25.2 万）
- **真实优势 2（收敛在关键月）**：2024-04 L2 **−2.42% vs BASE −10.28%**（+7.9pp 单月），2025 全年 L2 +13.4% vs +7.4%
- **局限 1**：崩盘单月（2024-01）与 BASE 无异（−19.74% vs −19.84%）——**锁定机制不防系统性首日暴跌**
- **局限 2**：2021 单边上涨年拖累收益 −19pp（+11.3% vs +30.4%）——锁定让上涨期提前止盈
- **净效果**：全期 +4.15%（远弱于窗口2 的 +76.2%）——**优势被"两次系统性段"稀释**；但 **8.1pp 的 MaxDD 改善（42→34）是真实的、可归因的**（防深亏 + 2024-04 保护）

## 三、优化方案（针对性，四簇）

> 设计原则：**不再单轴调参**（E9 已证在极端行情下失效）；围绕"熔断结构 + 仓位措施 + 止盈止损组合"设计。

### 簇 1：熔断机制结构升级（★最高优先级——直击根因 2/3/4）
- **1a 触发时强制减仓**（分级清仓）：现状"只限建仓"⇒ 建议触发时立即清至 50% 以下、深度触发（−20%）清至 20%；消除"FLAT 期裸奔"
- **1b 恢复条件收紧**：现状"指数确认 3 日"⇒ 建议叠加"净值恢复至触发前高点 X%（如 5%）"或"指数 10 日新高 + 冷却期"；避免下跌中继被套
- **1c 基线重置规则修正**：恢复后回撤基线改用"原峰值"（消除"重置→叠加"放大器）——与已登记的 O-2/D-76 残余赦免项一并处理
- 预期效果（粗估）：仅 1a+1b 可把主回撤段的三次"触发-恢复"循环成本（−3.4~−5.0% / 周期）削减一半以上

### 簇 2：组合级仓位/波动率措施（用户提示的"整体仓位措施"）
- **2a 目标波动率缩放**：组合实现波动 >阈值时整体降仓（现有 vol_scale 机制的强化——需审计现状效力）
- **2b 微盘风险指标联动**：微盘指数波动率/流动性恶化时整体降仓（对 2024-01 类事件的事前保护）
- **2c 仓位与熔断的分级联动**：预警级（−10%）降至 60%仓、触发级（−15%）降至 30%仓、深度级（−20%）清仓

### 簇 3：极端行情个股保护（直击根因 2 的 e3_derisk 深亏）
- **3a 无条件硬止损**：个股 −25%（独立于 σ 体系）时市价/次日开盘强制出（防 −40%~−60% 惨案）
- **3b 跌停/流动性感知**：监测一字跌停/极低成交时提前挂单（虽不能完全解决流动性，但能改善执行）

### 簇 4：止盈止损×锁定×风控的参数联动再标定（用户提示的"配套选择"）
- **4a 锁定机制保留**（L2 价值已证实）但**重标定锁定值**（+1.0σ 在长窗防深亏有效；结合簇 1 后可测试 +0.75/+1.25σ）
- **4b σ 轴重定位**：不再作为独立轴筛选，转为"在熔断结构确定后的二次优化"（E9 收口的正确姿势）
