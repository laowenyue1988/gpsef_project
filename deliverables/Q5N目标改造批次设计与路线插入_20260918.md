## 0. 结论：**需要插入**

**依据**：现行路线（Q5A 止盈轴 → Q5L 阶梯 → Q5C BARRA → Q5D 回撤阈值 → Q5E 组终验）**全部在优化"工程参数"**
（止盈/止损/阶梯/BARRA/回撤阈值），**没有任何一条在动"训练目标"**。
而 D-226 的判定是：**问题不在工程层，而在目标层** ⇒ 现行路线存在**结构性盲区**，必须插入一个「**目标轴**」批次。

**插入位置**：`Q5L → Q5C → 【Q5N】→ Q5D → Q5E`
**理由（顺序硬约束）**：Q5D（回撤阈值）与 Q5E（组合终验）都应落在**最终确认的目标**上；
若 Q5N 胜出则目标变更 ⇒ Q5D/Q5E 必须在新目标上做，否则**白跑**。故 **Q5N 必须前置于 Q5D**。

### 1.2 ② 由事实推出的可判别假设

- **H1**：目标对 `rank(vol)` 正交化后 ⇒ **IC 显著下降，但兑现率上升** ⇒ 原目标的 vol 成分是"虚高 IC"（**D-226 成立**）。
- **H2**：把目标换成「同周期前瞻收益」并中性化 ⇒ **IC 进一步下降，兑现率再升**（回到业界主流标的）。
- **H3（反向证伪条款）**：若正交化后 **IC 与兑现率同时下降** ⇒ vol 排序本身就是收益来源 ⇒ **原设计合理，D-226 被推翻**。
  —— **本条款必须写在预注册里并接受**。

## 7. ★路线级修正（2026-09-18 23:55，用户澄清「池 = 上层模型输出」后）

### 7.1 用户澄清

用户指出：300 只池不应视为「固定池子」，而应视为**上层模型（Wyckoff V10）的输出**。**该澄清成立**，
并使本档先前的定性需要修正 —— 在「池 = 上层输出」的解读下，本架构**确实取得了元标记的两层骨架**。

### 7.2 元标记要件对账（在「池 = 上层输出」解读下）

| LdP meta-labeling 要件 | 本架构 | 判定 |
|---|---|---|
| 两层：上层定机会集，下层定「是否下注 / 下多少」 | V10 → 池；Alpha191 → top-20 | ✅ **符合** |
| 下层样本 = 上层输出集 | 训练样本 = 池内 300 只 | ✅ **符合** |
| 下层**不得翻转方向**，只做筛选/sizing | 全多头，仅做筛选 | ✅ **符合** |
| 目标是**二分类「上层这次对不对」** | 当前为**连续截面分位**（`staged_rank`） | ❌（但代码已有 `staged_binary`） |
| 输出 = **已校准概率** | 回归模式**自动跳过校准** | ❌ |
| 存在 **bet sizing** 通道 | `max_meta_selected=20` **等权**取前 20；仓位由 `sell_pct`/敞口管理决定，**与预测值无函数关系** | ❌ |

**⇒ 修正定性**：本架构 = 「**两层堆叠 + 层内截面排序（stacked selection）**」，
是元标记的**近亲**，但缺的正是元标记**唯一独有的机制 —— 用校准概率做 bet sizing**。
补上这一环（目标改二分类 + 打开校准 + 概率→仓位函数），它就是**标准元标记**。

**★连带修正 D-226 第 ⑤ 项**：「命名与架构不符」**必须收窄适用范围** ——
段名 `meta_labeling` 对 **V10→meta 路径是正确命名**，**只在 `smallcap` 池模式下名不副实**。

### 7.4 ⇒ Q5N 的前置缺口：必须先做「架构对账」

Q5N 原设计落在 **`smallcap` 池**（市值选池）。若生产架构是 **V10→meta**，则 Q5N **改完也用不上**。
**⇒ 新增 `Q5P`（架构对账，0 算力）插到 Q5N 之前**，回答四问：

1. **V10→meta 路径的可跑性**：数据已齐 1236 天；为何 `v10_gate_enabled=false`、`recommended_by_date` 被置空？
2. **哪条是生产路径**：`smallcap` 市值池 vs `V10` 池？
3. **目标改造在两条路径上分别意味着什么**：`vol` 正交化（原 Q5N）／ 二分类 + 校准 + sizing（元标记补齐）？
4. **是否需要补 sizing 通道**（校准概率 → 仓位函数）—— 这是元标记**唯一独有**的机制。

**Q5P 判据**：产出「架构对账表 + 生产路径判定 + Q5N 落点与目标形态建议」三件套；
**0 算力、不起臂、不改代码**；结论须写清「否定的是**路径**还是**机制价值**」。
