## 2. 本轮产出（三处新增，单一文件 additive）

### 2.1 §3b 敞口序列分布（D-150 强制项）

- **口径（钉死）**：逐日敞口 `e_i = position_value / total_value_eod`（缺失退回 `total_value`）。
  **★与 §3 权威口径 `Σpos/Σtv` 不同源** ⇒ 报告内**并列披露两者差值**并显式声明「属口径差，不是策略差异」。
- **分位法（钉死）**：`pos = (n-1)·q` 线性插值（等价 `numpy.percentile(method='linear')`），
  **纯 Python 实现**（不为单指标引入 numpy 依赖）。
- **计数阈值（预注册常量）**：零敞口 `<1%`｜低敞口 `<10%`｜`≥90% 天数` 为 `e ≥ 90%`。

### 2.2 §3c 分段归因（D-150 强制项）

- **① 等分段**：边界 `n·k//N`（余数并入末段）；段收益基数 = 段首日**前一交易日** `total_value`
  （首段取 `initial_cash`）⇒ **等分段收益连乘恒等于全窗总收益**（已在真实臂上逐位验证，见 §3.3）。
- **② 自动空仓段**：连续 `e < 5%` 且长度 `≥ 5` 交易日（预注册常量）。
- 每段输出：区间/天数/段收益/段均敞口/段内最低敞口/PT·SL 笔数/**SL 实现盈亏合计**/段内指数/★躲跌贡献。
- **★基准口径披露（新登记）**：段内指数取自 `daily_values.csv` 的 `benchmark_cumulative`，
  实测对应配置 `backtest.benchmark_code = sh.000300`（**沪深300**）——**不是** o3 池等权指数。
  **D-150 裁定 4 引用的「o3 指数 −6.22%」与之不同源** ⇒ 该列**必须标基准名**，否则会被混读。

### 2.3 §3d 空仓成因分解（O-28，本轮新增；**启发式候选判定**）

解析 `backtest.log` **单一稳定机读行** `[<date>] 调仓完成，持仓数: N staged: M` → 调仓日表 →
对每个空仓段给出 4 值候选判定（规则 v2，见下）。**不使用 `$` 锚点**（规避 R-21），缺失/不可解析时 **fail-closed**。

| 判定 | 条件（钉死） | 实测命中 |
|---|---|---|
| `调仓日跳过（风控空仓平台候选）` | 段内**无任何**调仓日 | **FULL-WC** |
| `调仓日全清（IC门控型候选）` | 段内**全部**调仓日持仓数均为 0 | **BASE-WA / FULL-WA** |
| `段内清仓（风控型候选）` | 段内**存在**持仓数 > 0 的调仓日 | 合成夹具 |
| `证据不足` | 其余 | — |

> **判定规则 v1 → v2 的修正（首跑拦截留痕）**：v1 仅覆盖「段首日为调仓日且段内无其他调仓日」，
> 结果对 **BASE-WA（段内有 2 个零持仓调仓日）** 与 **FULL-WC（段内无调仓日）** 两种**真实**形态
> **均误判为「证据不足」**。v2 改为集合级判定（`all(==0)` / `any(>0)` / `∅`）后二者均被正确归类。

## 4. ★新发现：WA 窗 40 交易日「IC 门控空仓」（逐字取证）

### 4.1 现象
`BASE-WA` 与 `FULL-WA` 的逐日敞口序列**同时**出现 **40 个 `e = 0.0000` 的交易日**：
**2021-06-02 ~ 2021-07-28**（占 WA 窗 124 交易日的 **32.3%**）。两臂该段**逐日一致**。

### 4.2 因果取证（日志逐字，非推断）
```
[2021-06-02] 调仓日 - 选股流程 (第 41 个交易日, 调仓周期=20)
[HP-Search] 候选 c1..c4: val IC=-0.0841 / -0.0871 / -0.0630 / -0.0529   ← 全为负
Fold 1..5: Val IC = -0.1334 / -0.0177 / -0.0391 / -0.1491 / -0.0414     ← 全为负
[2021-06-02] 调仓完成，持仓数: 0 staged: 0
[2021-06-02] 总资产: 1,060,930, 现金: 1,060,930, 持仓数: 0              ← 100% 现金
```
配置 `ic_gate_threshold: 0.02`（注释：**验证集 Spearman IC < 此值 → 空仓**）。
⇒ **2021-06-02 调仓日 IC 门控触发全清**；**2021-07-01** 调仓日再次全清；
直到 **2021-07-29** 调仓日重建 20 只 ⇒ 空仓窗口 = 40 交易日。

### 4.3 影响判定（★必须分清「机制」与「巧合」）
1. **对 Q1 裁决（保护性结论）**：BASE 与 FULL **共享**该空仓段（同区间、同调仓日表、同判定）
   ⇒ WA 的 `ΔSharpe +0.691181 / ΔCalmar +63.31% / Δ|MaxDD| −1.4216pp` **不受该段污染**。
2. **对该段的「躲跌」价值**：段内沪深300 **−10.88%**，策略段收益 **−0.34%**
   ⇒ 表面「躲跌 +10.54pp」，但成因是**选股链 IC 门控**，**不是**风控机制
   ⇒ **不得计入「风控机制族净贡献」**（D-150 裁定 1/2 的降级限制在此再次成立）。
3. **对 Q2（出场规则标定）**：WA 有效持仓交易日仅 **84/124（67.7%）** ⇒ **对出场规则的鉴别力进一步下降**，
   **强化**「WA 禁外推尾部」的既有结论；Q2b 主判窗 **{WD,WX,WC}** 的选择再获支持。
4. **对「裸基线敞口」口径**：`BASE-WA` 平均敞口 **0.4070**（逐日口径 0.4084）
   ⇒ 与 D-150 已作废的旧判断「裸基线敞口恒 100%」**再次冲突**，确认作废。

## 6. 口径与统计功效限制（诚实披露）

1. **§3b 与 §3 敞口不同源**：逐日 `e_i` 均值 ≠ `Σpos/Σtv`。实测差值：
   BASE-WA `+0.0014`｜FULL-WA `+0.0020`｜BASE-WB `+0.0030`｜FULL-WB `+0.0026`｜
   BASE-WC `−0.0012`｜FULL-WC `−0.0061` ⇒ 量级 <1pp、方向不固定，**禁跨口径比较**。
2. **§3c 段内指数 = 沪深300**（配置 `benchmark_code`），**非** o3 池等权指数；
   D-150 裁定 4 的「o3 指数 −6.22%」应读作池口径（本工具给 −4.43% 为沪深300 口径）。
3. **§3d 为启发式候选判定**：仅依据调仓日机读行的持仓数，**不构成因果证明**；
   因果归属须辅以日志逐字核验。日志缺失时 **fail-closed**（返回不可用，不给伪判定）。
4. **统计功效**：单窗 124 交易日、空仓段 n=1（每臂）⇒ **不足以做显著性检验**；
   本报告一切结论为**描述性 + 一致性核对**，不宣称统计显著。
5. **等分段 ≠ 事件段**：等分段按交易日均分，与 D-150 裁定 4 的人工事件分段
   （04-01~07-01 / 07-02~08-26 / 08-27~10-01）**边界不同** ⇒ 两套分段**并列阅读，不可互换**。
