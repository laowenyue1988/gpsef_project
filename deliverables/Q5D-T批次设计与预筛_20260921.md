## 一、立项理由（三件套：事实 → 假设 → 臂对应）

### 1.1 ★实测数据事实（零算力，全部可复验）

### 1.2 由事实推出的可判别假设

> **H7**：**在"总敞口层"上，趋势类信号（价格相对均线位置）优于波动率目标信号**，因为它刻画的是**方向/持续性**（已实现的趋势），而波动率目标刻画的是**波动幅度**（与微盘后续收益**正相关** ⇒ 方向相反）。

**可判别性**（R-1~R-5 预注册见 §3）：
- 若 H7 成立 ⇒ Q5D-T 在 ★Sharpe / ★Calmar / 单位敞口年化 上**优于参照**（且优于已关闭的 Q5D_024/018）
- 若 H7 不成立 ⇒ 与 Q5D 同型劣化 ⇒ **"总敞口择时"这一整层被否定**（连带关闭 `Q5D-B` 条件臂，因该层无正贡献）

### 1.3 每臂对应哪个假设

| 臂 | 假设 | 说明 |
|---|---|---|
| **T1** `MA60 / 下方降至 0.30` | **H7 主检验（激进档）** | 预筛 ★Sharpe 1.8897（最高）|
| **T2** `MA60 / 下方降至 0.50` | **H7 主检验（温和档）+ 剂量-反应** | 预筛 ★Sharpe 1.6740 |
| **T3** `MA20 / 下方降至 0.50` | **H7 稳健性（短周期）** | 预筛 ★Sharpe 2.1396（但穿越 26.5 次/年，摩擦更高）|
| 参照 | — | `S17b_SL060PT150`（零算力）|

**★为何选 3 臂而非 1 臂**：T1/T2 提供**剂量-反应**（同一信号不同强度）；T3 提供**信号参数正交检验**（不同周期）⇒ 三者可区分"真机制"与"单点最优"。

## 四、实现方案（**源码改动，待 NR-A 落臂后执行**）

### 4.1 改动点（**唯一文件：`strategy.py`**；不触 `labels.py` / `ensemble.py` / `target_transforms.py`）

在 `_update_daily_vol_scale`（`strategy.py:4366-4414`）内新增**信号类型分支**：

```yaml
garch_control:
  enabled: true
  use_daily_scale: true
  signal_type: trend        # ★新增：vol(默认) | trend
  trend_ma_days: 60         # ★新增：均线周期
  trend_floor: 0.30         # ★新增：下方敞口档位
  # vol_target / ewma_lambda / min_scale / max_scale / recovery_ma_days 保持原样
```

**逻辑（草案，待实现时细化）**：
```
若 signal_type == 'trend':
    ma = close[<=T-1].rolling(trend_ma_days).mean()[-1]
    scale = 1.0 if close[T-1] > ma else trend_floor
    # 保留原不对称恢复？—— 否：趋势信号已含方向信息，恢复应由信号自身决定
else:
    ...原波动率路径不变...
```

**★关键设计决定**：
1. **`signal_type` 默认 `vol`** ⇒ **零影响闭合**（未设置该键时行为逐位不变）—— 必须用 `_exp_version.py` 的零影响验证 + R-126 烟测确认；
2. **趋势路径不叠加"不对称恢复"**（趋势信号本身已含持续性；叠加会引入额外滞后）；
3. **`use_drawdown_control` 仍须 `false`**（与 `use_daily_scale` 互斥守卫，保持原样）。

## 五、与 Q5P′ 的关系（**下一层，不混淆**）

| | **Q5D-T（本批）** | **Q5P′（后继候选）** |
|---|---|---|
| 作用对象 | **总敞口** | **单位敞口波动**（选股/配权层）|

**★注**：D-252 说"敞口缩放不能改善 Sharpe"，但 **Q5D-T 不是均匀缩放**（它是**二值择时**）⇒ **不受该定理限制**；它改善的是**收益路径**（避开下跌段），而非缩放尺度。这正是预筛 C 组（1.89）优于 A 组（0.93）的原因。
