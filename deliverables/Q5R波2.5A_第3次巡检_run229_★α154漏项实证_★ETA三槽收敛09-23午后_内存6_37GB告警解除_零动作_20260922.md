## ★★ 本轮核心新增（零算力、只读）：`alpha_154` 不在权威受影响列清单 —— 漏项实证

### 4.1 我做了什么

用**权威清单** `_d281_affected_cols.json`（39 列）之外，对 `factor_snapshots_test`（修复前）与
`factor_snapshots_fixed`（修复后）做**全量 168 个可比对交易日**的逐列比对（NaN 视为相等），
**不抽样**（对比工具 `_compare_snapshot_generations.py` 默认只抽 3 日）。

### 4.2 实测结果

| 指标 | 值 |
|---|---|
| 可比对日期 | **168 日**（20200102 ~ 20241211） |
| **变化列并集** | **40 列** |

| `alpha_154` 全量可比对数 | 6477 对中 **翻转 6477/745,000 ≈ 0.869%**（0→1: 2053｜1→0: 4424 ⇒ **双向翻转**） |

**★关键额外发现（否定"`alpha_154` 是偶然噪声"）**：在 2020 年初部分日期，**权威 39 列中只有 18~27 列发生变化，而 `alpha_154` 仍在该日变化** —— 即 `alpha_154` 的变化**不依赖**于 39 列中任何一列当天是否变化，说明**它自己被 `VWAP` 直接驱动**，不是其他列变化的副产品。

### 4.3 为什么会漏（根因）

静态源扫描 `strategies/small_alpha191_test3/factors.py` 中"表达式出现 `VWAP`/`AMOUNT`"的因子，得到 **37 个**，与**实测反推 39 列**不同。查证：

```
factors.py:971
result[f'alpha_154{suffix}'] = (VWAP - ts_min(VWAP, 16)
                                < ts_corr(VWAP, ts_mean(VOLUME, 180), 18)).astype(float)
```

`alpha_154` **直接建立在 `VWAP` 之上**，且**恰好是高敏的单点判定**：比较两侧都是 `VWAP` 的泛函，`VWAP` 被反向缩放 `f²` 后，`(VWAP − ts_min(VWAP,16))` 与 `ts_corr(VWAP, …)` **两项以不同指数缩放** ⇒ 不等式的**符号会翻转** ⇒ 二元输出整体翻转。

> **⇒ 根因 = 清单构建方法学缺陷**。原清单是"**实测反推**"（`_compare_snapshot_generations.py` **仅抽 3 日**：20200102/20200103/20241008），而 `alpha_154` **恰好同时满足两个"看不见"条件**：① 3 日样本内翻转率低 ② 它在 20241008 那天也在 39 列全变的日子变化 ⇒ **被 39 列掩盖**。**单靠 3 日抽样无法发现"只在部分日期变化的第 40 列"** ⇒ 属 **R-108 家族（样本选点缺陷）**，与 **R-144**（诊断结论须覆盖连续谱）**同源**。

## 段⑤ 小白版四问（D-269 强制）

### ① 这段在解决什么问题？

我们在修一个**数据算错方向**的老毛病：算「成交均价」时，每股的价格乘了一个"复权系数"，但成交金额却**除了**同一个系数（方向反了）。结果算出来的均价被缩放成了原来的**系数平方倍**，在**除权日**前后出现假跳变（幅度 0.9%~7.5%）。

修完之后，我需要回答一个很具体的问题：**"这次修复到底改动了哪些因子？"** —— 因为这决定了①要不要把历史上跑过的实验**全部重算**（很贵）②还是**只在文档上标注一下**（很便宜）就够了。

原来给出的答案是"**39 个因子**"。我这次做的事 = **不信这个数字，自己把全部历史日期都查一遍**。

### ② 用了什么办法？

- **办法**：把**修复前**的快照目录（`data/factor_snapshots_test`）和**修复后**的快照目录（`data/factor_snapshots_fixed`），**同一个交易日**逐列对比。判定规则很严格：**同一个股票、同一个因子，两个数值必须"逐位完全相同"**（NaN 空值算相等）。只要有一位不一样，就记"这一列变了"。
- **关键升级**：原来的对比工具**默认只查 3 天**（这是它的默认参数 `--max-n 3`）。我把可比对的 **168 个交易日全查了**（2020-01-02 ~ 2024-12-11）。
- **缩写当场解释**：
  - **`VWAP`** = 成交量加权平均价，可以理解成"当天按成交金额摊算出的平均成交价"。
  - **`amount` / `volume`** = 当天成交金额 / 成交股数；`VWAP = amount ÷ volume`。
  - **复权系数（`f`）** = 因为分红送股，历史价格要调整，调整用的那个乘数。
  - **`alpha_154`** = 191 个因子里的第 154 号，它是一个"**是 / 不是**"的判断题，输出只有 0 和 1。
  - **`_neu`** = 中性化后的版本（扣掉行业/市值等影响后的版本）。
  - **MDA** = 模型里衡量"这个因子对预测贡献多少"的指标；**Top-5 / Bottom-5 MDA** = 贡献最大 / 最小的 5 名。

### ③ 结果是什么？

| 我查到的 | 数字 | 所以怎样 |
|---|---|---|
| 全量 168 天里"变过的列"总共有多少 | **40 列**（不是 39） | **多出 1 列** |
| 这 40 列里，不在原答案（39 列）里的是谁 | **`alpha_154`（唯一一个）** | 原清单**漏了它** |
| 它有多少天发生变化 | **166 / 168 天（98.8%）** | **不是偶发，是几乎天天在变** |
| 原答案的 39 列里，有没有我查不到变化的 | **0 列** | 原答案**没有多算**，只是**漏算** |
| `alpha_154` 变化的幅度/形式 | 全部是 0↔1 **翻转**（0→1 有 2053 次、1→0 有 4424 次），每天翻转率**中位 0.14%** | **双向翻转，不是单向漂移** |
| 它在采用包（`S17b_SL060PT150`）训练里到底有没有被用上 | **有**：66 轮里**被选中 1 轮**，排名 **#12**，`votes=3/5`、`IC=0.2745`、自己的簇占 **1.4%**；另有 **2 次**进入"贡献最小 5 名"榜（t = −12.05 / −20.31） | **确实进了模型，但极少、很小、而且是负贡献倾向** |

另外还查了三个配套事实：
- `alpha_154` 的公式是 **直接在 `VWAP` 上做的**（`factors.py:971`：`VWAP − ts_min(VWAP,16) < ts_corr(VWAP, …)`），比较的两边**都是 VWAP 的函数**，所以**符号会翻转**，输出自然跟着翻。
- 在 2020 年初某些日子，**原 39 列里只有 18~27 列变化，但 `alpha_154` 照样在变** —— 说明它是**自己受 VWAP 驱动**，不是别的列变化的"连带产物"。
- 因此原来那条"**39 列变 / 182 列一字不改**"的自证，**在数学上永远达不成**（168 天里至少变 1 列的并集已经是 40），**上限只能到 181**；**正确数字应为「40 列变 / 181 列不变」**。

**所以怎样**：修复本身**没有做错**（该变的列都变了、不该变的一列都没多算），但**"受影响清单"这个数字是错的**，连带**自证判据的数字**也错了；而错的原因是**用只查 3 天的样本去反推全量清单**。

### ④ 对你意味着什么？

**决策影响（4 条，按重要性）**：
