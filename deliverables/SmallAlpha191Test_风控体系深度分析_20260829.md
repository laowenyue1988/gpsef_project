## 2. 三层风控的冲突分析（核心问题）

### 2.1 冲突总览

| 冲突对 | 冲突类型 | 机制描述 | 危害等级 |
|---|---|---|---|
| staged_exit vs GARCH | **波动率口径不一致** | staged_exit 用 **EWMA λ=0.94** 入场 σ 定阈值；GARCH 用 **EGARCH(1,1)-t 条件波动率**动态更新。两者对"当前波动水平"判断不同步 → 止损/止盈阈值与实际波动错配 | 🔴 高 |
| staged_exit vs GARCH | **双重降仓叠加** | GARCH scale<1 后单只仓位变小，但 staged_exit sell_pct 基于**初始仓位** → 卖出份额可能超过当前实际持仓（过度卖出） | 🔴 高 |
| staged_exit vs GARCH | **目标函数冲突** | GARCH 目标=波动率压到 vol_target（20%）；staged_exit 目标=分批锁定利润。同时作用 → 组合波动被**双重压缩**，收益下降 | 🟡 中 |
| staged_exit vs BARRA | **权重漂移** | BARRA 在调仓日优化 Σw=1.0 权重；staged_exit 20 天窗口内卖出 60-100% 持仓 → 实际暴露结构与 BARRA 目标**严重偏离**，BARRA 约束在卖出后失效 | 🔴 高 |
| staged_exit vs BARRA | **频率错配 20 倍** | BARRA 每 20 天优化一次（截面）；staged_exit 每日触发（时序）——两者风控动作频率差 20 倍，无法协调 | 🟡 中 |
| BARRA vs GARCH | **顺序依赖（设计已处理）** | 代码注释已明确"BARRA→GARCH"顺序，GARCH 用 BARRA 权重合成历史收益估波动——设计合理，但两者都关闭 | ✅ 无 |
| 三者叠加 | **风险预算缺统一框架** | 三层各自为政：交易层（单笔损失）、截面层（权重约束）、缩放层（波动目标）——无统一风险预算（1/N、VaR/CVaR、Roncalli risk budgeting），易"过度风控"或"风控盲区" | 🟡 中 |

### 2.2 冲突的数学本质

- **staged_exit 的 σ 阈值**：`PT/SL = entry × (1 ± k × σ_EWMA(entry))`——入场时刻的 EWMA 波动率快照
- **GARCH 的 vol_target 缩放**：`scale = min(max_scale, target_vol / σ_EGARCH(now))`——当前时刻的条件波动率
- **口径错配**：EWMA（λ=0.94，RiskMetrics）对波动率冲击的反应滞后约 1/(1-λ)≈17 天；EGARCH 对负冲击（杠杆效应，Nelson 1991）当日反应。**微盘暴跌日：GARCH 已预测波动飙升（scale 骤降），staged_exit 的 -2σ 止损线还钉在 17 天前的 EWMA σ 上 → 止损过宽，亏损超预期**；反之波动率回落时，GARCH 已加仓，staged_exit 阈值仍宽 → 风险暴露不足时止损过松。

### 2.3 实验证据（回测日志）

| 证据 | 数值 | 含义 |
|---|---|---|
| hard_sl（-6σ）触发 | **0 次** | 分层止损（-2σ~-4σ）足够早，硬兜底从未需要——止损层有效但高频（2373 次止损） |
| PT后SL上移/SL后PT下移 | **2070 次** | 动态调整机制极其活跃（每 2.6 笔交易一次）——风控动作过密 |
| 止损 vs 止盈 | 2373 : 2935 | 止盈略多（1.24:1），但 S4 止盈仅 95 次（长尾未捕获） |
| 最差单日 | **2024-12-23 -6.5%**、2024-01-22 -6.4%、2025-04-07 -5.3% | ①调仓日满仓接盘（01-22）②关税冲击日（04-07）③无组合级止损，单日 -6.5% 无熔断 |
| 2024-02 微盘危机 | 组合仅 -0.4% | 被动低仓位（现金 96%）的意外保护——**不是主动风控的功劳** |

**结论 2：当前风控的特点是"交易层过密（5308 次触发）+ 组合层缺失（无回撤熔断、无趋势过滤、无截面约束）"。这正是 -15.97% 回撤的结构性原因——不是风控太少，而是风控全压在交易层，宏观/组合层是真空。**

## 3. 业界最佳实践框架（对照）

### 3.1 分层风控（Layered Risk Control）标准做法

```
宏观层（月度/周度）   : 回撤熔断 / vol targeting / 市场状态过滤
组合层（调仓日）      : 权重优化（BARRA/CVaR/风险平价） / 行业暴露约束 / 流动性约束
交易层（日内/持仓期） : triple barrier / 分批退出 / 动态 SL-PT
```

- 每一层管**不同的时间尺度与目标**：交易层管单笔、组合层管暴露结构、宏观层管整体回撤
- **业界原则：同一尺度不要重复风控**（如个股止损 + 组合止损若都用同一 σ 指标会互相干扰）
- De Prado（AFML）：triple barrier + meta-labeling 本身是"交易层风控 + 模型层门控"的标准组合；组合层建议 risk budgeting（Roncalli 2013）或 CVaR 约束

### 3.2 当前策略的层间缺口

| 层 | 现状 | 缺口 |
|---|---|---|
| 交易层 | ✅ staged_exit（完备但过密） | 无 |
| 模型层 | ✅ AUC/IC 门控 | 无 |
| 组合层 | ❌ 仅静态 10% 上限 | **无调仓日趋势过滤、无行业/风格约束** |
| 宏观层 | ❌ 无 | **无组合级回撤熔断、无单日暴跌保护** |

### 3.3 关键判断：BARRA 与 GARCH 该不该启用？

**理论推演 + 微盘策略特质的结合判断（需回测验证）**：

- **GARCH 全量 vol_target 大概率有害**：当前微盘策略平均仓位 41.6%（隐含年化波动 ~15%）；若启用 vol_target=20%，GARCH 在波动率高于目标时降仓——微盘日波动 3-5%，EGARCH 预测经常 >20% 年化 → **仓位会被压到 30% 以下，收益进一步缩水**。vol_target 是为"满仓策略"设计的，对"半仓策略"是雪上加霜。
- **BARRA 全量权重优化大概率有害**：策略 alpha 依赖微盘小盘暴露（Beta+规模风格，见归因）；BARRA 因子偏离约束（max_ind_dev 0.12 / lambda_dev 0.2）会拉低小盘暴露 → 稀释核心 alpha。grid_lowvol 的 BARRA 归因显示"价值暴露 -317bp 拖累"——风格约束在低波策略上是双刃剑。
- **但它们的"轻量版本"有价值**：
  - GARCH 模块中的**回撤分级保护**（dd_function concave + 二级/三级地板 0.50/0.25）——独立于 vol_target，可在启用 GARCH 的同时 `vol_target` 设大（如 99%）只取回撤保护部分
  - BARRA 的**单股权重上限 + 行业偏离软约束**（lambda_dev 0.1 弱约束）——不强行中性化，只防过度集中

## 4. 推荐的风控组合与参数（供审核）

### 4.1 设计原则（吸取 grid_lowvol 教训）

1. **不同尺度各管一段，同尺度不重复**：交易层保留 staged_exit；组合层新增调仓日趋势过滤；宏观层新增组合回撤熔断
2. **风控动作必须是"限制建仓"而非"持仓强清"**（grid_lowvol 的 combo_half 反向加仓 bug 教训——熔断时严禁放大敞口）
3. **所有新参数入 config 且默认关闭**，逐项 A/B 验证
4. **不启用会压仓位的模块**：GARCH vol_target、BARRA 全量优化保持关闭

### 4.2 方案 A（推荐：补宏观层 + 组合层，交易层微调）

| 模块 | 配置 | 依据 |
|---|---|---|
| **组合级回撤熔断**（新增） | 净值回撤 >10% → 建仓减半；>15% → 空仓；恢复 = 回撤 <5%（滞后带） | 2024-12-23 -6.5% 单日无熔断；-15.97% 回撤无干预 |
| **调仓日趋势过滤**（新增） | 调仓日微盘指数（sh.000852 中证2000）收盘 < MA20 → 建仓减半 | 2024-01-22 调仓日 -6.4% 满仓接盘（日志实证） |
| **staged_exit S1 阈值** | 2σ → 2.5σ（止盈/止损同步） | S1 触发 1746 次 = 20 天窗口 P(≥2σ)≈99.9% 必然事件；2.5σ 恢复选择性 |
| **AUC 门控** | 0.52 → 0.54 | 门控口径统一（折内 OOS 均值）；低 AUC 期减少无效暴露 |
| **GARCH/BARRA** | 保持关闭 | 见 §3.3 论证（压仓位/稀释 alpha） |
| **reinvest** | 保持关闭（或条件化 50%，另案） | 避免改变 2024-02 保护基线 |

### 4.3 方案 B（进取：引入 GARCH 回撤分级 + 轻量 BARRA）

在方案 A 基础上：
```yaml
garch_control:
  enabled: true
  vol_target: 99.0        # 变相关闭 vol 缩放（不压仓位）
  use_drawdown_control: true   # 只启用回撤分级
  dd_function: concave
  secondary_dd_threshold: 0.15
  tertiary_dd_threshold: 0.20
  min_scale: 0.0
barra:
  enabled: true
  risk_aversion: 0.3      # alpha 主导（弱约束）
  max_ind_dev: 0.20       # 放宽行业偏离
  lambda_dev: 0.1         # 弱因子约束
```
- 预期：回撤分级提供宏观层第二道保险；轻量 BARRA 防极端集中
- 风险：模块交互复杂度上升（需验证 GARCH 回撤保护与组合熔断的先后关系）

### 4.4 参数敏感性网格（验证用）

`S1_σ ∈ {2.0, 2.5, 3.0} × 熔断阈值 ∈ {8%, 10%, 12%} × 趋势MA ∈ {10, 20} `——12 组 A/B 回测后择优

## 5. 审核者质疑（对推荐方案的批判）

**质疑 1：组合回撤熔断会不会重蹈 grid_lowvol 的覆辙（熔断=抄底、恢复死锁）？**
- 回应：grid_lowvol 的教训是①`order_target_percent` 语义反转（目标=总资产×50%）②空仓恢复依赖净值回撤（死锁）。本方案直接复用已修复的语义：熔断只减建仓规模（不改现有持仓）、恢复用市场信号（指数≥MA）而非净值——**若实施必须先在测试中覆盖这两类 bug 的回归用例**。

**质疑 2：S1 2σ→2.5σ 会不会放大单笔亏损？**
- 回应：止损同步放宽（-2σ→-2.5σ），单笔止损幅度从 ~6% 升到 ~8%（微盘 σ3-4%），但 S1 触发次数降 60-70% → 总止损次数下降、且避免 2σ 截断的利润损失（止盈 1098→减少）。**净效应需 A/B 验证**——若回撤恶化则回退。

**质疑 3：调仓日趋势过滤在 2025 微盘牛市中会不会误杀？**
- 回应：中证2000 在 2024-09-24 后持续 >MA20（牛市），过滤不会触发；2024-01（<MA20）与 2024-02 危机期会触发减半——**方向正确但需验证牛市启动初期（指数刚突破 MA20）的滞后成本**（回测 2025-01 段验证）。

**质疑 4：为什么不直接启用已实现的 GARCH/BARRA？**
- 回应：它们是"满仓策略的机构级工具"，本策略 41.6% 仓位的核心矛盾是**收益利用不足**而非风险暴露过大（回撤 -15.97% 对微盘风格属中等）。启用它们会进一步压仓位、稀释 alpha——**与上轮审计"提仓位"方向相反**。先补"缺失的宏观/组合层"，GARCH 回撤分级/轻量 BARRA 作为方案 B 增量验证。

**质疑 5：三层风控会不会总有一层误触发，导致收益下降？**
- 回应：这是真实风险。验证方法：每个模块单独 A/B（不叠加），确认单模块增益后再组合——**避免"三模块叠加互斥无法归因"**。统计检验用 920 日 ab_sig_test（Holm 校正）。

## 6. 结论

1. **当前风控结构失衡**：交易层过密（5308 次触发、2070 次动态调整）、组合层/宏观层真空（无回撤熔断、无趋势过滤）——-15.97% 回撤与 2024-01-22 调仓日 -6.4% 单日大亏均源于此
2. **staged_exit 与 BARRA/GARCH 存在真实冲突**：波动率口径（EWMA vs EGARCH）、权重漂移（BARRA 优化 vs 持续卖出）、双重降仓（vol_target × 分批退出）——**不建议直接启用两者**
3. **推荐方案 A**（组合回撤熔断 + 调仓日趋势过滤 + S1 2.5σ + 门控 0.54），每模块独立 A/B 验证，默认关闭、参数化
4. **方案 B**（GARCH 回撤分级 + 轻量 BARRA）作为增量探索，需先验证与 A 的交互
