## 二、归因：三层事实

### 事实层 A：R12 与四轮存在数据版本混杂（无法跨版本归因，必须正视）

- R12 跑于 2026-08-30（补数据前），四轮跑于 09-02/03（用户补齐日线/分钟数据后）。
- 实证：R12 与轮1 **调仓选股平均重合率仅 42.3%**（41 个共同建仓日）；训练 meta_AUC 序列**仅首位相同**（0.5630 一致，其后轮1 系统性低 0.002~0.004：0.5758/0.5553/0.5351 vs 0.5720/0.5548/0.5367）。
- 含义：①两轮模型训练输入不同 → 收益差的一部分来自数据本身，不是纯策略改动；②**新数据上模型 AUC 系统性略降**（alpha 或候选池质量变化），是独立于门控的隐忧。
- ⚠️ 但 R12 优势幅度太大（+12pp 收益、+0.4 Sharpe、回撤小 4.6pp 且暴露更低），**不能全部用数据噪声解释**——方向性判断可信（见 B/C）。

### 事实层 B：四轮内部（同数据版本，干净归因）——参数效应方向确凿

轮1 与轮4 选股完全一致（仅 3-5 个门控分歧日）、AUC 序列逐位相同 → 模型相同，差异纯参数：

| 对比 | 唯一变量 | 收益差(裁剪) | 机制实证 |
|---|---|---|---|
| 轮1 vs 轮2 | stage1 **3σ→2σ** | **-26.4pp** | 2σ 使 stage1_sl 373 vs 275、stage2_sl 376 vs 276（+198 单），过度止损把仓位打没（暴露 27.3% vs 38.7%）。2σ 是 **config 事故值**（test2 config=2.0 但注释标 3.0 裁决） |
| 轮1 vs 轮4 | 门控 **up0.52+中证2000 → up0.54+上证** | **-19.9pp** | 轮4 空仓日 15.2% vs 10.3%；上证信号与微盘持仓错配（2024-02-27 微盘反弹日轮4 空仓错过，后 20 日中证2000 +2.7%） |
| 轮1 vs 轮3 | up_bad 0.5→0.0 | 0pp | 净值/订单逐位相同 → 该分支从未触发 |

### 事实层 C：R12 为何全面更优（门控哲学差异 + 单位暴露效率）

**R12 的运行画像（日志实证）**：
- 门控哲学：**AUC≥0.54 才建仓（全期二元，不分趋势）+ 建仓即半仓（趋势过滤恒 x0.5，32 次半仓）** → 平均暴露仅 32.3%、波动 11.05%；
- 空仓调仓日 6/49（12.2%）——低 AUC 期直接不进场；2024-01~06 微盘危机期暴露压到 24.2%（净值 +3.7% 平稳过冬）。

**轮1 的运行画像（orders 实际买入金额实证，45 个建仓日）**：
- 真实仓位 = 22 半仓 + 22 满仓 + 1 低仓，平均建仓 72.1%（满仓日比 R12 多 7 个：含 2023-10/11、2024-02、2026-06 等 R12 半仓/空仓的日子）；平均日暴露 38.7%、波动 14.06%。
- 分时段：2024-10 前平均 68%（9 满仓）vs R12 前段 57%（4 满仓）——该段特质 alpha 为正(+2289bp, 见归因)，R12 用更低暴露赚更多 → R12 保守择时在 alpha 正期更精准；2024-10 后两轮都转激进(~75%)，但该段特质 alpha 转负(-3773bp) → 满仓放大负 alpha。
- 危机期 2024-01~06 暴露 41.9%（吃到反弹 +7.9%，但承担更大波动与回撤）。

**单位暴露效率（收益 ÷ 平均暴露）**：

| | R12 | 轮1 |
|---|---|---|
| 收益(裁剪) | 77.15% | 65.04% |
| 平均暴露 | 32.3% | 38.7% |
| **单位暴露效率** | **2.39** | **1.68** |

R12 每单位暴露产出高 42%——**轮1 多放行的暴露（up0.52 门槛更低 + 趋势强满仓）在 2022-2026 样本内边际产出为负或很低**：多暴露 6.4pp，收益反而少 12.1pp。

**分歧调仓日（5 个，净贡献有限）**：轮1 独建仓 3 日（2023-11-24 后20日 -5.1%、2024-02-27 +2.7%、2026-07-20 +17.1%），R12 独建仓 2 日（2024-05-28 -7.7%、2024-07-24 +1.8%）——分歧日两者互有输赢，**主要差距在共同持仓期的选股质量与暴露节奏**，而非个别调仓日。

## 三、为什么"都比 R12 下降"——直接回答

1. **轮1/轮3（四轮最优）仍落后 12.1pp**：核心是门控哲学回退——R12 的"0.54 高门槛 + 恒半仓"用 32% 暴露/11% 波动实现了 77%，而矩阵门控"0.52 低门槛 + 趋势强满仓"多暴露了 6.4pp 却少赚 12pp。**放宽的建仓门槛（up 0.52）与满仓上限（scale 1.0）是收益-风险的双重恶化源**。
2. **轮2**：stage1=2σ config 事故（-26.4pp），与门控无关。
3. **轮4**：门控收严到 0.54 但信号指数换错（上证 vs 持仓错配），且 scale_up_bad=0 全空仓太极端（-19.9pp）。
4. **混杂因素**：数据版本（选股 42% 重合、新数据 AUC 略降）让 R12 与四轮的数字差不能 100% 归因——**但 R12 低暴露 + 高收益 + 低回撤的组合优势在方向上是稳健的**。

## 四、提升绩效的方法（把握度分级）

### P0-① 同数据 A/B 裁决（最有价值，必须先做）
当前所有跨版本对比不干净。用**同一份（9-03 补全后）数据**跑两版（各 2 次取中位数去随机噪声）：
- **A 版 = R12 门控**（AUC 0.54 全期二元 + 趋势过滤恒半仓 + 上证）——test2 策略代码即此门控，config 恢复即可；
- **B 版 = 轮1 矩阵**（up0.52/dn0.54 + 中证2000）——test 当前配置。
- 裁决指标：收益 / Sharpe / 单位暴露效率 / MDD。两种可能结论：
  - A 仍显著胜 → **矩阵门控的放宽设计（up0.52+满仓）需要修正**，且新数据上模型 alpha 衰减被确认 → 转 P1-②+P1-④；
  - B 追平或反超 → 数据版本是主因（补数据改变了候选池/特征），门控保留 → 深查候选池漂移。

### P0-② 修 config 事故（立即，零风险）
test2 `staged_exit.stage1` pt/sl 2.0/-2.0 → 3.0/-3.0（与注释"最终裁决 3.0σ"一致），杜绝再跑出轮2。

### P1-③ 若 R12 门控胜出：矩阵门控向 R12 语义收敛（中等把握，需单变量 A/B）
方向（按证据强度排序）：
1. `auc_threshold_up` 0.52 → **0.54**（提高趋势强时建仓门槛，减少低 AUC 暴露期）——注意轮4 失败不等于 0.54 失败：轮4 同时换了上证+up_bad=0，三变量混杂；应只改 up_thr 保持中证2000。
2. `scale_up_ok` 1.0 → **0.5~0.7**（趋势强也不满仓，向 R12 半仓哲学靠拢）——轮1 vs R12 的效率差（1.68 vs 2.39）主要来自满仓暴露的低边际产出。
3. 保留 dn 侧 0.5/0 不变（趋势弱保守已合理）。

### P1-④ 检查数据补齐对候选池/alpha 的影响
新数据 AUC 系统性低 0.002-0.004、选股仅 42% 重合 → 需核查：补数据后动态池（市值最低 300）成分漂移是否合理；特征快照是否有口径变化。若 alpha 确实衰减，单独决策（非门控问题）。

### P1-⑤ 收敛"风控指数"实验范围
中证2000 vs 上证之争目前被 3 个变量污染（up 阈值、up_bad、指数）——A/B 中固定其他变量单测指数（up0.52 下 zz2k vs sh），才能干净回答中证2000 是否真优（昨日适配性分析支持 zz2k 更贴持仓，但轮4 把指数混进了坏参数组合）。

## 五、局限（诚实声明）

1. **数据版本混杂是最大不确定源**：R12(8-30 旧数据) vs 四轮(9-02/03 新数据)，选股重合 42.3%、AUC 序列不同 → 直接数值对比含数据噪声；本报告的方向性判断（R12 保守哲学占优）基于"优势幅度大 + 机制清晰"，仍须 P0-① 同数据 A/B 定案。
2. 轮2/轮4 各单样本，参数效应方向确定、幅度受路径影响。
3. 熔断修复（9-02 上线）存在于四轮、不存在于 R12：R12 本窗口无 FLAT/峰值重置触发，影响有限但未剥离。
4. 区间口径：R12 至 08-04，四轮至 08-31，本报告已裁剪共同区间（08-05~08-31 的 19 个交易日差异不参与对比）。
5. 未做持仓重叠期收益归因（共同持仓的 20 只中重合仅 ~8 只），个股层面差距未能完全拆解。
