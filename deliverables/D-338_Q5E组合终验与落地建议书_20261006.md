### 3.2 ★满仓等效加法分解（严格闭合）

```

  ① size beta 项  = (策略自有池 − 沪深300)   = +13.85pp   ← ★正向（占 41.0%）

```

**⇒ 声明（逐字，取代旧四条）**：
1. **约 59% 的超额来自"池内选股 alpha"，约 41% 来自"小市值风格本身（size beta）"，且 size beta 为正向（+13.85pp）** ⇒ **策略确实部分地"赚了小市值的钱"，不是纯 alpha**。

4. **★新增风险提示（原报告缺失）**：既然 **约 41% 的超额来自 size beta**，则 **微盘风格的逆转会直接冲击约 41% 的收益来源**；策略**身处微盘池** ⇒ 微盘池的系统性风险（流动性、政策、退市）仍是最大暴露源。

## §9 小白版（四问）

**①这段在解决什么问题？** 这是整个项目的"**最终验收**"。前面所有实验都在问"能不能改得更好"，**答案是不能**；那么最后一个问题是：**现在这套配置，到底算不算过线？以及"过线"这件事本身诚不诚实？**

**②用了什么办法？** 直接读现行配置的**历史回测产物**（1315 个交易日、66 轮调仓），**用两种口径各算一遍**：一种是"实际账本"（原样），一种是把仓位放大到满仓（满仓等效）；再核对基准（小市值本身涨不涨）、列出**没开的风险开关**、说明**换到别的股票池时哪些数字必须作废**。

**③结果是什么？**
- **过线了，但"过线"靠的是仓位轻**：实际账本的最大回撤是 **16.33%**（线是 20%），但**把仓位放大到满仓后回撤是 34.70%，远超线**。数学上这两者的"收益效率"**完全一样**（Sharpe 一字不差，差异只有 10⁻¹⁶ 量级）⇒ **轻仓只能等比压缩波动和回撤，不能创造额外能力。**
- **超额一部分是"赚小市值的钱"**：拿**策略自己的股票池**（每日 300 只、等权、复权价）本身来比，它年化 **+12.18%**、最大回撤 **44.94%**。我们的满仓等效超额 **+33.78pp** 里，**小市值风格贡献 +13.85pp（41.0%）**、**池内选股贡献 +19.93pp（59.0%）**。**换句话说：约六成靠选股，约四成靠"买小市值"本身。**
- **风险开关基本没开**：**没有尾部熔断、没有换手限制**；回撤控制完全靠"选股 + 平均 42.8% 的仓位 + 单只不超 10%"。
- **换池子时这些数字全部作废**：σ 阈值、标签倍数、保护线、仓位上限——**都只是"这个池子的波动率结构"解出来的数**，换个池子必须重新标定。

**④对你意味着什么？**
- **建议：不改**。本项目 9 条优化轴全部收口（"测不出可辨识效应"）、3 条确凿变差关闭、**0 条达到采纳门槛**。**任何改动都等于把一个噪声当能力。**
- **3 个候选只作为"上限情景"披露、不采纳**：最好的是 `NEG10`（Sharpe 1.24、回撤 13.4%），但它的可分辨度只有门槛的 **46.7%**，而且后来用更密的点重测，**证明它所在的"山"其实是抖动的**。
- **风险敞口要说实话**：**真实风险是 34.70% 级别的回撤**，被 42.8% 的仓位压到了 16.33%。对外只说 16.33% 是不诚实的。
- **下一步**：只剩两件——①**泄漏体检**（确认那 0.25 的预测力不是偷看未来，见 `D-337`）；②**对齐结构**（本项目唯一还有正向线索的方向，"样本权重与标签是否对齐"的效应比"权重加多大"大一个量级）。
