# 第三部分 · 新增／调整的附加实验

## §9.1 ★Q5I-3a · 标签置换检验（同日打乱）—— **恢复朋友原版建议**

| 项 | 内容 |
|---|---|
| **目的** | 直接检验"截面内的可预测性是否来自真实信号" |
| **做法** | 取训练样本，**在每个交易日截面内 shuffle `y`**（保留日期结构），重训模型，看 IC |
| **为何保留日期结构** | 若**完全打乱**，会连带破坏"日期共同成分"；**同日打乱**保留了每日的波动率结构 ⇒ **若模型仍能预测 ⇒ 说明它读到的是特征里的日期共同成分（一种泄漏）** |
| **判据（预注册）** | **P-1** 打乱后训练 IC **\|IC\| < 0.02**（= `ic_gate_threshold`）⇒ 无泄漏；**P-2** 若 \|IC\| ≥ 0.02 且显著 ⇒ **判为泄漏**，须定位来源 |
| **成本** | **轻算力**（只训 1 个模型 + 算 IC，**不跑完整回测**）⇒ 估计 **< 30 分钟** |
| **工具** | 新增 `_q5i_label_permutation.py`（复用 ensemble 训练链路，传入置换后的 `y`）|
| **排期** | **可立即做**（不占臂槽，纯 CPU 短任务）|

## §9.2 ★Q5R · 零信息对照批次（**臂数 5 → 20**）

| 项 | 内容 |
|---|---|
| **假设** | H-0：**191+XGB 在池内不创造可检测价值**（预测值 ≈ 随机） |
| **臂定义** | **R0** = 基线（零算力，用 S17b 读数）；**R1~R20** = **随机分位**（唯一变量 = `preds`），等价于「**池内随机 20 只等权 + 同套止盈止损**」 |
| **为何 20 臂** | 经验分布分位估计：5 臂 ⇒ 只能判"是否在范围内"；10 臂 ⇒ 可估 **P90**；**20 臂 ⇒ 可估 P95**（朋友的经验做法）。**N=20 时最小值即 P95 的单侧无偏估计** |
| **唯一变量纪律** | 除 `preds` 外**逐键相同**（R-113）；须打印完整逐键 diff |
| **成本** | 长窗 11h/臂 ⇒ **20 臂 = 220h ÷ 3 并发 ≈ 73h ≈ 3 天** |
| **★序贯设计（控制成本）** | **分 4 波 × 5 臂**，每波后做**预注册中期判定**：<br>· **正向提前终止**：基线 ★Sharpe **> 全部已跑随机臂的最大值**，且差距 > 分布跨度的 50% ⇒ 判定「模型有可检测贡献」，**停止补臂**<br>· **反向提前终止**：基线 ★Sharpe **< 已跑随机臂的中位数** ⇒ 判定「无可检测贡献」，**停止补臂**（再补只会让分布更集中）<br>· 否则继续至 20 臂 |
| **预注册判据 R-1~R-5** | **R-1** 基线 ★Sharpe / ★Calmar 是否 **落在随机分布的 P95 之外**；**R-2** 必须并列 **单位敞口年化 + 均敞口%**（D-150：随机臂敞口不可控 ⇒ 防"降敞口躺平"被误读）；**R-3** CI 只读方向 + 形态（R-114/R-115）；**R-4** 分段（含 WD/WX 尾部窗）；**R-5 可反驳**：**基线落入随机分布内 ⇒ 判定「191 在当前框架内未产生可检测贡献」⇒ 路线转入 Q5V 或新因子挖掘** |
| **口径限制（必同引）** | ① `max_positions=20` ⇒ 非全池等权 ② 20 个种子给的是**分布上界估计**，非精确分位 ③ 随机臂的**敞口序列不可控** ⇒ 与基线比较须并列敞口指标 |

## §13 强制口径限制（必同引）

1. **跨修复节点禁用绝对读数**（S17 实证 PT150 Δ+0.1117）。
2. **BARRA 结论只可引 Q5C-1 / Q5C-1b**；禁引 Q1_full / Q3c/d/e 的 BARRA 部分。

7. **D-245**：`|MaxDD|<20%` 是 **Q5E 终验线**，非过程闸门。
8. **D-251/252**：波动率目标敞口有**低波动阴跌盲区**；**敞口缩放不改善 Sharpe**（尺度不变）⇒ 能改善 Sharpe 的是**选股/配权层风险处理**。
