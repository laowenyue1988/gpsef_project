## 0. 执行摘要（TL;DR）

1. **审计事实澄清**：项目当前的中性化**不是"分步回归"**。真实形态是——①Winsorize、②Z-score（逐列、逐截面预处理）→ ③**一次多元 OLS 取残差，X = 行业哑变量 + log(市值)**。真正需要裁决的"分步 vs 一步"只发生在回归环节，而回归环节**当前已经是一步到位**。
2. **数学结论**：若把"分步中性化"理解为"先对行业回归取残差、再把残差对市值回归取残差"这类**多次回归串联**，则仅在风险因子两两正交时与一步等价；真实数据下**非等价且严重依赖顺序**。用本项目真实暴露网格实测：同一 y、同一因子集，仅改变因子进入顺序，与一步回归的残差 RMS 差可达一步残差的 **55%–122%**（反序，2026-05 期），残差相关降至 **0.63**。而"Gram–Schmidt 型分步（每步对已残差化因子回归）"与一步回归数值完全一致（RMS 差 ~1e-15）——**说明想与一步等价，分步只是做了与一步相同的事（QR/正交投影），没有独立价值**。
3. **业界结论**：因子中性化（回归取残差）的标准做法就是**一次截面多元回归**（Barra 风险模型、Grinold–Kahn、主流券商金工的多因子预处理均如此）；"缩尾→标准化→回归取残差"的预处理流水线本身按列分步是**正确且必要**的，与回归无关，不属于"分步中性化"。
4. **归因结论**：当前归因模型仅 5 风格因子+截距、无行业，Active R² 为负、特质收益 2024-10 后持续为负——这是**归因解释模型不完整 + 策略 alpha 转负**两个独立问题。"进一步对拖累收益的因子做中性化"须先澄清层面（特征/组合/归因），不同层面做法与代价完全不同；**建议先做归因模型扩展（诊断），再决定是否动组合/特征**（详见 §5）。
5. **现状评价**：核心中性化管线（Winsorize→Zscore→一步多元 OLS on [行业, log_mv]）**基本合理（与业界一致，约 8/10 分）**。可讨论的两点：①回归系数是"训练段 pooled 拟合一次、预测期所有截面复用"，而非逐截面重估（业界 Barra 每日重估）——无未来泄漏但系数带时变性误差；②行业哑变量全列+截距用 ridge(1e-12) 处理共线，可接受。
6. 本次零代码改动。

## 3. 数学事实：为什么"分步回归 ≠ 一步多元回归"

### 3.1 记号与定义

设要中性化的对象（因子值或收益）为 y（截面向量），风险因子 X = [X_1, …, X_k]（含截距时每列零均值化后等价）。

- **一步多元（joint）**：残差 e_joint = M_X y，M_X = I − X(XᵀX)⁻¹Xᵀ（正交投影到 X 张成空间的补空间）。e_joint 是"在所有同时正交于 X_1…X_k 的向量中模最小"的唯一向量，**与因子排列顺序无关**。
- **分步（sequential）**：先对 X_1 回归取残差 e₁ = M₁y，再对 **原始** X_2 回归取残差 e₂ = M₂e₁，依此类推 → e_seq = M_k ⋯ M₂ M₁ y。
- **Gram–Schmidt 型分步**：第 j 步先把 X_j 对前 j−1 个**已残差化因子**做回归取残差（得到与前面全部正交的 U_j），再对 U_j 回归取残差 → e_gs。

### 3.2 等价条件与反例直觉

1. 投影算子 M_i 之间**不可交换**（除非 X_i 两两正交）。因此 M₂M₁ ≠ M₁M₂，顺序改变结果。
2. 只有当样本内 X_iᵀX_j = 0（两两正交）时：M_jM_i = M_iM_j = M_{[i,j]}，分步 ≡ 一步（验证见 §3.4 sanity）。
3. 非正交时的直观危害：第一步残差 e₁ 正交于 X₁，但第二步用**原始** X₂（含 X₁ 的成分）投影 e₁ 时，会把 X₁ 方向的分量**加回来一部分**——分步中"后一步破坏前一步建立的正交性"。5 步累积后残差可与一步结果面目全非。
4. Gram–Schmidt 型分步中，由于每一步的 U_j 彼此正交，残差投影不破坏前步正交性，结果与一步严格等价（数值上即对 [X₁…X_k] 做 QR 后的投影）——**想用分步得到与一步相同的结果，本质上只是在重做一次联合回归**，无独立意义。

### 3.3 数值演示（本项目真实暴露网格，仅读取分析，未改代码）

数据：`data/.barra_attr_cache/exposure_grids_smallcap/*.parquet`（每期 300 微盘池 ∪ 持仓，783–1258 只），风险因子 = 5 风格暴露（size/beta/value/momentum/volatility，Barra 归因标准化后）。y 用两类：合成微盘 alpha（y = −size + 0.3ε，模拟"因子天然与市值负相关"的真实结构）与当日真实前复权截面收益。

| 期 | 分步[正序 size→vol] vs 一步 | 分步[反序 vol→size] vs 一步 | Gram–Schmidt vs 一步 |
|---|---|---|---|
| 2022-08-01（合成 y） | corr 0.9998 / RMS差 2.0% | corr 0.876 / RMS差 **55.0%** | corr 1.000000 / 0 |
| 2023-06-29（合成 y） | corr 1.0000 / 0.3% | corr 0.858 / **59.8%** | 同上 |
| 2024-06-26（合成 y） | corr 0.9999 / 1.6% | corr 0.832 / **66.6%** | 同上 |
| 2025-06-24（合成 y） | corr 0.9999 / 1.3% | corr 0.773 / **82.0%** | 同上 |
| 2026-05-22（合成 y） | corr 1.0000 / 0.9% | corr 0.633 / **122.3%** | 同上 |
| 5 期平均（真实日收益 y） | corr ~0.999 / 1.6–7.3% | corr 0.99 / 5.6–14.5% | corr 1.000000 / ~1e-15 |

**sanity（正交条件）**：把 5 个因子替换为严格正交的 QR 列后，正序/反序分步与一步的 RMS 差均 ≈ 2e-4（仅 ridge 数值噪声）——证实"正交 ⇒ 等价"。

读数：
- 分步正序（把与 y 最相关的 size 放最前）接近一步，是因为第一步已剔除绝大部分信号，后续因子贡献小；**但这只对该 y 成立**，换 y（如动量驱动的 alpha）最优顺序就不同——顺序依赖本身即缺陷。
- 分步反序 RMS 差可达一步残差的 **122%**（残差比一步残差还大），残差相关仅 0.63——**同样的因子、同样的方法，仅顺序不同，中性化结果几乎不相关**。若把该残差直接用于排序选股，风格过滤结果将完全不同。
- Gram–Schmidt 与一步的残差相关 = 1.0000000000、RMS 差 ~1e-15：证明"分步想等价必须正交化处理因子"，而正交化处理因子后得到的正是联合投影（一步回归）。

**演示脚本**：`analysis_neutral_seq_vs_joint.py`（输出 `results/_neutral_seq_vs_joint.txt`，可复现）。

### 3.4 数值演示与"业界"的对齐说明

注意演示中因子间截面相关仅 ~0.08–0.10（微盘池内风格相关被压窄），差异却达 55–122%——说明**即使在"低相关"外观下，分步的顺序偏差也不可忽略**；在沪深全市场截面（size/momentum/volatility 相关常 0.3–0.6）偏差会更大。这正是业界必须"一步回归"的量化理由。

## 4. 业界最佳实践综述

### 4.1 因子中性化的标准定义与做法

- **目标**：让因子值与既定风险因子（行业、市值、必要时风格）在截面内**正交**，即剔除"因子值中可由风险因子线性解释"的部分。数学上 = 对风险因子矩阵做一次（加权）OLS，取残差。
- **主流实现（Barra 体系，CNE5/CNE6、USE4 同源逻辑）**：
  1. 缩尾（Winsorize，1%/99% 或 5%/95% 视稳健性要求）；
  2. 标准化（Z-score，或 Barra 的市值加权标准化参数）；
  3. **一次**截面回归（Barra 在因子收益估计/风格收益估计中用市值平方根加权 WLS；在 alpha 因子中性化场景，A 股券商金工普遍用行业哑变量 + ln(市值) 一次 OLS/加权 OLS 取残差，个别再叠加流动性）；
  4. 取残差作为中性化后因子。
- **关键纪律**：所有要控制的风险因子**同时进同一回归**；回归**逐截面（逐日/逐调仓日）重估**，不跨期共享系数（Barra 每日重估；因子 IC 检验按日截面）。
- 归因/风格收益估计（Grinold–Kahn 框架）：r_i = f_0 + Σ X_ij f_j + u_i 的截面回归本身就是**一次多元回归**，各因子收益 f_j 同时解出，**特质收益 u_i = 残差**。不存在"先解 size 收益、再在残差里解 beta 收益"的两步法（除非刻意做方差分解，见 4.4）。

### 4.2 预处理为什么可以（也必须）"分步"

- Winsorize 与 Z-score 是**逐因子的单变量变换**：一个因子是否缩尾、是否标准化与其他因子无关，天然按列依次做。
- 顺序上"先缩尾后标准化"是标准惯例：先缩尾防止极端值污染均值和标准差，后标准化获得可比尺度。
- 把缩尾/标准化塞进"一次多因子回归"在数学上无意义（缩尾是数据清洗、标准化是尺度变换，二者都不涉及对风险因子的投影）。
- **结论：用户问题里"分步 vs 一步"只适用于回归环节；预处理环节的分步是正确且必要的，无需改动。**

### 4.3 "正交化（orthogonalization）"与"中性化"的术语澄清

- **中性化**：y 对风险因子 X 回归取残差 → y 与 **X** 正交。
- **因子正交化**：处理**风格因子之间**的高相关（如 size 与 momentum），使进入回归/组合的因子彼此正交——常见于 Barra 风格因子构建（对称正交/施密特正交）与机器学习特征去相关（本项目的 feature_clustering/CFI 属同类目的）。
- 两者常被混淆。本文讨论的是前者；如果用户意图其实是"对拖累风格再做一次回归剔除"（即把 value/volatility 当作新的 X），那属于"扩展中性化集合"，正确做法是**把它们并入原来的 X 一步回归**（§5.3 路线 A），而不是在旧残差上再跑一次新回归。

### 4.4 "分步"的合法用途（都不是中性化）

只有当研究问题本身带顺序结构时，分步回归才有意义：
- **序贯方差分解 / ANOVA 型 R² 分解**（先加行业解释多少、再加市值解释多少…）：用于**解释力诊断**，结论对顺序敏感，需声明顺序；
- **嵌套模型假设检验**（H_0: 控制 A 后 B 无增量）；同层嵌套检验顺序无意义。
- **显式政策/可解释性顺序**（例如必须先行业中性再规模中性）。
这些场景下顺序是"研究设计"的一部分，而非试图得到唯一残差。**用于构建中性化因子/特质收益时，业界一律用一步回归。**

### 4.5 加权、共线与缺失（与本项目相关的细节）

| 细节 | 业界通行 | 本项目现状 | 评价 |
|---|---|---|---|
| 回归权重 | 中性化通常等权；风格收益估计常用市值或 √市值加权 | 中性化等权；归因因子收益 √市值加权（`barra_attribution` L543） | 与用途匹配，合理 |
| 行业哑变量共线 | 去一列（k−1 哑变量）或去掉截距；或用伪逆/正则 | 全 k 列+截距+ridge(λ=1e-12) | **可接受**：λ 极小，残差几乎不受影响（等价数值稳定解）；若追求教科书写法可改 k−1 列，非必须 |
| 缺失样本 | 不参与拟合；预测时残差 NaN 或按缺失组处理 | 不参与拟合；残差保留 NaN，XGBoost 原生处理 | 合理 |
| 回归频率 | 逐截面（日/调仓日）重估 | 训练段 pooled 拟合一次 → 预测期所有截面复用系数 | ⚠️ 见 §5 讨论点 B |
| 缩尾分位 | 1%/99%（或 5%/95%） | 1%/99%，组内 ≥10 样本才执行 | 合理 |

## 5. 裁决与建议（三个问题的直接回答）

### 5.1 Q1：当前中性化方式是否合理？——**核心合理，两个讨论点**

逐条评分（满分 10）：

| 环节 | 评价 | 得分 |
|---|---|---|
| 按日截面 Winsorize(1%,99%) | 与业界一致；先于 Z-score，顺序正确 | 9 |
| 按日截面 Z-score | 一致；向量化实现无逻辑偏差 | 9 |
| **一步多元 OLS（行业哑变量+log_mv）** | **与业界一致（正是"一步到位多因子回归"），是本项目做得对的关键** | 9 |
| fit/transform 分离（训练拟合、预测复用） | 防未来函数/泄漏的必要设计，方向正确 | 8 |
| ridge(1e-12) + solve 确定性 | 数值稳健、跨进程一致（2026-07-19 修复），比 lstsq 更可控 | 9 |
| 缺失样本 NaN 保留 | 正确（2026-05-15 修复后） | 9 |
| 行业哑变量全列+截距 | 教科书会去一列；ridge 下实际等价，无实质问题 | 7 |
| **系数 pooled 跨期复用（不逐截面重估）** | **与 Barra"逐截面重估"不同；无未来泄漏但有时变性误差** | 6 |

**讨论点 A（回归层 pooled vs 逐截面）**：训练期对多年样本**一次** OLS 得到的行业/市值系数是"历史平均溢价"，预测期新截面的残差只在**训练样本上**与行业/市值正交，对每个具体截面并不严格正交（当期行业溢价 ≠ 历史平均时残留暴露）。业界（Barra、因子检验）逐截面重估能保证"当日截面内正交"。
- 项目如此做的**合理性**：①训练/推断分离是 ML 惯例，逐日存系数实现成本高；②微盘池单截面 ~300–500 只、行业 20–30 个，逐日回归每行业样本少、系数噪声大，pooled 借用了历史信息；③严格无未来泄漏。
- **代价**：行业/市值"溢价"随时间漂移（尤其 2024-02 微盘流动性危机、2024-09-24 政策市）时，pooled 系数中性化后的因子仍可能带残余风格暴露。**这是"特征中性化是否彻底"的实测量，而不是对错问题。**建议后续用诊断量化：分时段检查中性化后因子与当日行业收益/市值收益的相关（若显著≠0 则说明系数陈旧），再决定是否改为滚动窗口重估（如最近 12 个月 re-fit）。**本文件不实施。**

**讨论点 B（与 V10 的口径差异）**：V10 预测路径 `_neutralize_full_market` 是"单日全市场快照 + 训练 betas"——与 alpha191 系同为"训练 pooled + 单日 apply"，两族口径一致；feat_analysis 是全区间 pooled（分析用途，可接受）。**无跨族不一致问题**，仅 V10 的全市场中性化天然包含当日全部股票，比 alpha191 系按池内股票回归的参考域更广——这是既定设计，不是缺陷。

### 5.2 Q2：分步还是"一次多因子回归一步到位"？——**一步到位**

- 若指**回归环节**：必须一次多元回归（§3、§4）。分步只产生顺序依赖的伪残差，除非做 Gram–Schmidt——而那是联合回归的另一种写法。
- 若指**预处理环节**：Winsorize/Z-score 本来就是分步逐列，且必须保留。
- **结论一句话**：当前实现已是正确形态；任何新增中性化因子（行业外的 value/volatility/流动性等）都应**并入同一 X 一步回归**，绝不建议"在现有中性化结果上再对某因子回归取残差"。

### 5.3 Q3：用户两个推进意图的落地路线

#### 意图 1："先解释得更平"

"解释更平"需先明确对象，两种读法对应不同工具：

| 读法 | 含义 | 对应工具 | 是否推荐 |
|---|---|---|---|
| 1a 归因解释力提升 | 提高归因模型 R²、降低特质残差幅度 | **扩展归因模型因子集**（行业哑变量、流动性/换手、必要时拆分动量与反转） | 推荐（诊断层，无副作用） |
| 1b 特质收益曲线更平稳 | 策略"选股能力"净值更平 | 组合层工具：持仓数/权重上限/风格约束/止损纪律/波动目标；**中性化本身不做波动管理** | 有条件推荐（先诊断） |
| 1c 因子值中性化更彻底 | 特征层剔除更多风险 | §5.3 路线 A | 谨慎（见下） |

- 1a 的操作要点：归因扩展与当前"特征中性化"无关，是 `barra_attribution` 模型侧加列（需行业数据 asof、注意微盘池内行业集中度、因子间共线）。加行业后 Active R² 会上升、epsilon_adj 会被**重定义**（原来归入特质的部分行业暴露收益会被重新分配）——这恰恰是"把解释做平"的正路：**先补解释变量，再谈残差含义**。但须预判：2024-10 后 epsilon_adj 转负的**主体是选股 alpha 消失而非行业漏解释**（同期 size/beta 风格贡献为正且大），加行业只会小幅改变该结论；真正的解释变量在"候选池内选股信号"而非行业。因此 1a 用于**口径修正**，不要指望它解释掉负 alpha。
- 1b 若用户想让"净值曲线/alpha 曲线更平"：工具是组合构建与风控（本项目已有：分阶段止盈止损、回撤熔断、趋势门控、中证2000 风控指数），与中性化无关。

#### 意图 2："在现有中性化基础上，进一步对拖累收益的因子做中性化"

先厘清对象。轮1 归因中"拖累"来自两处：**value（−147bp）、volatility（−1013bp）、epsilon_adj（−1222bp）**。其中 epsilon_adj 不是风格暴露，无法"中性化"；value/volatility 的负贡献 = 组合暴露 X × 因子收益 f。

三条技术路线（**不要混用**）：

| 路线 | 做法 | 业界对应 | 代价/风险 | 适用判断 |
|---|---|---|---|---|
| **A 特征层扩展中性化** | 把 value/volatility 暴露并入 alpha 因子中性化的 X（与行业+市值一步回归） | 因子构建期中性化全集 | alpha 因子中本就含风格信息的部分被剥掉 → alpha 空间缩小；与微盘策略"重仓小市值/高波动"的本质暴露冲突 | **不推荐作为默认**：只在中性化集合确为"无意风险"时才做 |
| **B 组合层风格约束** | 组合优化/加权时约束 value/volatility 暴露 ≈0（`config.barra.enabled` 当前 false；或手工后处理权重） | Barra 组合优化、风险平价 | ①强约束会把持仓推出微盘纯度，动摇策略身份；②约束"负贡献风格"只能消除暴露成本，**无法把负 alpha 变正** | 谨慎：需用户明确"可牺牲多少小市值/高波动纯度" |
| **C 归因层二次分解（诊断）** | 扩展归因模型加行业/流动性，观察 epsilon_adj 收敛；**不改变组合** | 归因诊断（Brinson/Barra 归因扩展） | 无实盘代价；结论口径变化 | **推荐先做** |

**决策前必答问题**：value/volatility 的负贡献是"组合无意识押注被风格惩罚"，还是"策略在风格内的选股 alpha 已消失"？
- 若前者（X 是无意暴露且 f 稳定为负）→ 中性化/约束暴露有正收益；
- 若后者（f 不稳定，或 epsilon_adj 才是主因）→ 中性化只能削平风格贡献项，**对 2024-10 后负 alpha 无修复作用**，甚至因减少风格对冲而放大特质波动。
轮1 数据显示后段 size/beta 风格贡献为正（掩盖了 epsilon_adj 转负），volatility 负贡献跨段稳定存在——**对 volatility 做组合层暴露收敛（路线 B 的温和版：把 +0.145 暴露压回 0 附近）是有据可依的**；value 负贡献很小（−147bp），不值得为此动组合。

#### 建议的推进次序（先诊断、后实施，全部待用户审核）

1. **P0-诊断（路线 C，不动代码/组合）**：扩展归因模型至"行业 + 5 风格"或"行业 + 风格 + 流动性"，量化 epsilon_adj 的口径变化与分时段收敛；同时补"中性化彻底性诊断"（见讨论点 A）——分时段看中性化后因子与当日行业/市值的相关，量化 pooled 系数的陈旧度。
2. **P1（条件实施）**：若 volatility 负贡献被确认是"稳定暴露成本"→ 在组合构建层加温和暴露约束（目标 |X_vol| ≤ 0.1–0.2 量级），以 A/B 回测验证（同数据同门槛，与 R12 同口径对比）；**不是特征层中性化**。
3. **P2（观察项）**：特征层中性化保持现状（行业+市值一步回归）；未来若扩集合（如流动性），一并入 X 一步回归并重跑全套验证（MDA/IC 口径、训练系数刷新频率需与重估窗口联动）。

**以上均未实施。**
