## 三、★★N-9 根因定位：`★Sharpe` 的真实口径与自助法口径**不同源**

### 3.1 定位结果（位级可复现，21/21 锚点）

```
N = daily_values.csv 行数（含首日）
annual_return      = (final_value / initial_cash) ** (252 / N) - 1      # 几何年化（按行数指数外推）
annual_volatility  = stdev(daily_return, ddof=1) * sqrt(252)            # n = N（首日 daily_return = 0.0）
★Sharpe            = annual_return / annual_volatility                  # report.json.sharpe_ratio
```

**⇒ `★Sharpe`（D-148 第一维度的真实来源）= 「几何年化收益 ÷ 算术波动年化」的混合比**，
它**既不是**日频收益的 Sharpe（`mean/σ·√252`），**也不是**自助法所用的同源点估计。
