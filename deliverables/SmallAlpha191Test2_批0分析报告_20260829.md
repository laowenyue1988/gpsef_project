## 2. Bug 根因（已定位 + 已修复）

**根因**：`before_market_open` 中 `if not need_rebalance_check: return`（strategy.py L3036）使非调仓日直接早退，而 `_update_dd_breaker(current_date)` 原实现位于函数**尾部**（早退之后）——状态机每 20 个交易日才更新一次：

- 2024-02-07 最大回撤日（-9.25%）**不是调仓日** → 回撤从未被检测
- 下一调仓日（约 2024-02-26）回撤已修复至 <8% → 熔断从未触发
- 危机期间（2024-01-22 至 2 月底）**无任何熔断保护**

**修复**（已实施 + 测试）：
- `_update_dd_breaker(current_date)` 移至 `before_market_open` **开头**（早退 return 之前），每日盘前更新状态机
- FLAT 清空调仓目标逻辑保留原位（仅调仓日执行，读盘前已更新的状态）
- 测试新增断言「熔断更新在早退 return 之前」→ **46/46 PASS**
- 修复后 R0/R1 重跑中（预期：R1 在回撤 >8% 时早于 R0 触发 HALF，两组结果将不同）
