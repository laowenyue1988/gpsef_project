## 3. 四维度敏感性结论

### 3.1 S1 σ（决定性参数）：越宽松越好，完全单调
```
S1 2.2σ → Sharpe 0.59    2.5σ → 1.08    3.0σ → 1.63~1.66
收益   +5.8%   →   +12.0%  →  +17.7~18.6%
回撤   -8.6%   →   -9.3%   →  -3.1~4.2%
```
- **机制**：微盘股 20 天窗口 P(≥2.2σ)≈必然事件，2.5σ 仍过密触发"止盈后高位重进"；3.0σ 才开始保留长尾利润，且空仓期（84 天）避开了危机回撤
- **单调性证据**：三个点完全单调 + R8 两次独立回测结果逐位一致（18.58%）

### 3.2 AUC 门控：0.54 局部最优（0.52 太松 / 0.56 太严）
- 0.52：仓位最高（31.9%）但回撤最深（-12.93%，危机暴露）
- 0.56：**空仓 310/384 天**（几乎全年不建仓），仓位 6.7%
- 0.54（A4 收紧方向）平衡 ✅；且 R11 证明：**门控 0.52 × S1 3.0 有负面交互**（Sharpe 1.06、回撤 -11.2%）

### 3.3 趋势过滤 MA：20 最优，参数不敏感（重要负结果）
- MA10：触发 15 次 → 仓位 24.4%、Sharpe 1.00（更差）
- MA30：触发 14 次与 MA20 相同 → 结果与 R0 逐位一致
- **但**：S1 3.0σ 下 MA10 反而小幅增益（R12：回撤 -3.11% < R8 -4.16%，Sharpe 1.66 > 1.63）——趋势过滤与 S1 有交互，MA10 减半建仓在 S1 3.0 的少卖特征下互补
- **仓位 25.6% 偏低的根源不在趋势过滤 MA**（改 MA 只能 24-26% 微动），而是 S1 止盈 + 不 reinvest + 门控空仓的组合机制

### 3.4 回撤熔断：本区间无区分度
- 区间最大回撤 -9.25%，熔断阈值 8%（R1）触发 1 次但落在"选股空"的调仓日 → R0=R1 逐位一致
- 机制已验证工作（-8.13%→HALF→build_scale 0.5 应用），但区间内无法评估其绩效贡献 → **待全窗口（20220801-20260522）验证**
