## ⑤小白版四问（D-269 强制）

**① 这段在解决什么问题？**
我们的策略要"读"一张每日因子表（快照），表里有一列是 **`vwap`（成交量加权平均价 = 当日成交金额 `amount` ÷ 成交股数 `volume`）**。之前发现：除权日数据组装时，`amount` 被乘了 **`1/f`**（f = 复权因子，>1），而价格被乘了 **`f`** ⇒ 两者方向相反，`vwap` 被反向缩放 **f²**，**不再落在当日最低价与最高价之间**（本该 0 次越界，实测 16~252/266 次越界）。这就是 D-281 缺陷，本轮正在重算全量快照把它修掉。

**② 用了什么办法？**
修 `amount×1/f → ×f`（2 行）＋ 加一条 **断言 `low ≤ vwap ≤ high`（相对容差 `rtol=1e-3`）** 和一条 **"限流"**（避免同一只股票反复刷警告）。然后把 1618 个交易日的快照**全部重算**，拆成 3 个分片并行：**S1 2022-06~2024-09（568 天）／S2 2020-01~2022-05（590 天）／S3 2024-10~2026-09（460 天）**，每片 `workers=2`、**带内存门控**（可用内存 <2.5GB 就等，最长等 600s），并支持断点续跑。

**③ 结果是什么？**
- 进度 **587 / 1618 文件 = 36.3%**，**失败 0 / 报错 0 / 缺列 0**。
- 三片速度：**S1 126.0s、S2 99.5s、S3 140.6s 每个文件**（= 每天约 2.1 / 1.7 / 2.3 分钟）⇒ **预计全部算完 = 09-23 上午 11:33 到下午 3:53**。**比上一轮估计又早了 0.5~1 小时**，且**连续三轮速度稳定**（S1 169.8→126→129.7→126 秒；S2 135.6→108.5→99.5→99.5 秒）⇒ 之前的"时快时慢"已确认为**阶段性波动，不是系统退化**。
- 断言命中 **60 行**（三片各 20 行），**全部落在 `sz.3008xx` 与 `sz.3009xx` 这两段创业板代码里**（如 `sz.300846`、`sz.300847`、`sz.300905`）。这些是**原始行情文件本身**就有问题的股票（`amount` 当天没刷新、沿用了前一天的值），不是修复没生效。
- **所以怎样**：修复按设计生效了 —— 命中密度和"原始数据固有坏点率 **0.000725%**"是同一个数量级，而修复前那个"**2.15%**"的说法是错的（那是被沪深300指数文件污染的）。修复把越界率从"两千分之一"降到"百万分之一级别"，**差三个数量级**。

**④ 对你意味着什么？**
- **决策影响**：**不需要停下来**。修复在轨、进度三分之一、ETA 落在今天午前到午后初，**它一完成就能进入波 2.5B（等价性实证）**。
