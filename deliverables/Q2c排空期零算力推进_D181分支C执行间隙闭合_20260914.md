### 2.2 ★★规则纠偏：正确规则是 `sl_sigma = BASE_SL × κ`，**不是**「×0.8 缩放」

§5.35.5 的建议②写作「变异键 = `staged_exit.stage{1,2,3,4}.sl_sigma`，逐档 **×0.8**」。
本轮**从源码实测**该表述的**机理不准确**：

```python
# _make_q2c_configs.py
:54   BASE_SL = [-3.0, -3.0, -4.0, -4.0]        # 模板 P0_Bare_long 的 stage{1..4}.sl_sigma
:132  if [v for _, v in t_info] != BASE_SL: ...  # 模板基值硬断言
:151  newv = fmt(bv * k)                         # ★唯一缩放公式：绝对值 = base × κ
```

⇒ 正确机理：**每档 `sl_sigma` = `BASE_SL[i] × κ`**（绝对定位到模板基值，非相对上一档缩放）。

**为什么这个纠偏重要**：对 `SL050`（κ=0.5）而言，`{−1.5,−1.5,−2.0,−2.0}`
既可表述为「`BASE_SL×0.5`」也可表述为「`SL050 的 −1.5/−1.5/−2.0/−2.0 × 0.8`」——
**两条路径数值巧合一致**（因 0.4/0.5 = 0.8）。但**只有前者是可推广的机理**：
若将来要派生 κ=0.45 或 κ=0.3，`×0.8` 表述会**直接失效**。
⇒ **规格必须以 `base×κ` 表述**，本轮据此产出目标值。
