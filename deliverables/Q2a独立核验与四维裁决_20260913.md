## 2. ★四维深度分析

### 2.1 组合层（portfolio）
- **Q2a 是出场端的"逐笔重放"**，不含组合路径：**不建模现金再投资**（`reinvest_enabled=false` ⇒ 提前退出后资金闲置至下一调仓，**本代理的"已实现收益"与生产一致**，这一点是口径上的**优点**，不是缺口）、不建模调仓日槽位竞争、不建模标签改动引起的**选择反馈**（改标签→改模型→改选股，用户令已声明）。
- 因此 Q2a **只能做剪枝**：它可靠回答"同一建仓集下，出场规则改变如何改变逐笔结果"，不能回答"组合 ★Sharpe/★Calmar 会怎样"。**代理指标 proxy_sharpe 是"逐笔类 Sharpe"（mean/std，未年化），与组合 ★Sharpe 无口径等价关系**，仅作**同样本单调代理**。

### 2.2 交易层（trade）
- P0 逐窗：WA +2.76% / WB +1.46% / WC −1.96% / WD −0.61% / WX −0.07%；**主判窗 {WD,WX,WC} 合并 −0.94%/笔**（n=380），**ALL5 +0.20%/笔**。
- **出场结构失衡**（结构性事实，独立复核一致）：**SL 占比 51%~61%、PT 仅 10%~21%** ⇒ 出场重心完全在 SL 侧，与 D-152"WC 盈亏比 0.92 是唯一结构性出血点"同向。
- **换手副作用必须记账**：SL 收紧使 `mean_fills` 2.689 → 3.363（×0.6）⇒ 成交笔数 +25%。按 commission 3bp + tax 5bp + transfer 0.1bp + slippage 10bp ≈ **18.1bp/笔**，且每次成交面额 ≈ 0.25×5% ≈ 1.25% 权益 ⇒ 增量成本 ≈ **0.0022% 权益/笔**，相对 +0.31pp 的逐笔增益**可忽略**（量级差 140×）⇒ **成本不构成否决理由**。

### 2.3 风控事件层（risk events）—— ★本轮核心
**发现 N-4：−6σ 硬止损是"死分支"（已证明，非推断）**

| 检验 | 结果 |
|---|---|
| hard_sl = −6.0 **vs 实际关闭（−99σ）** | **收益不同笔数 = 0 / 620，max\|Δ\| = 0.000e+00**（逐位相同） |
| hard_sl = −6.0 vs −5.0（对照，应不同） | 3 / 620 笔不同，max\|Δ\| = 9.819e−03 ✓ 对照有效 |
| 路径层面（模型无关，直读分钟 bar） | **P(minσ ≤ −6) = 14.84%**、P(≤ −8) = 7.42%、minσ 最差 **−16.03σ** |

⇒ **14.84% 的样本路径确实触及 −6σ，但硬止损一次都没触发。** 机理：`strategy.py:4502/4599` 的硬兜底检查的是**当根 bar 的 low ≤ −6σ**，而 **S4 的 −4σ 档位 SL 必然在更早的 bar（或同一 bar 的后续判序）先被置位**（`s_done4=True`）⇒ 硬兜底只在"**单根 5 分钟 bar 从 >−4σ 直接跳穿 −6σ**"（跳空/一字跌停）时可达，而 620 笔样本中**为 0 次**。
⇒ 该分支是**近乎不可达的兜底**，对 Q2 优化**零杠杆**。**节省一条整轴。**

**发现 N-5：`trade_reason='stage4_sl'` 是二义的（代码取证）**
`strategy.py:4505`（分钟路径）与 `:4601`（日线回退路径）在**硬兜底触发**时同样发 `events.append((4, False, ...))`，而 `:3999` 统一渲染为 `trade_reason=f'stage{stg}_{"pt" if is_pt else "sl"}'` ⇒ **−4σ 档位 SL 与 −6σ 硬兜底共用 `stage4_sl` 这一个字符串，orders.csv 无法区分**。
⇒ **D-152"新增议题：S4（−6σ 硬止损）在十臂中均为触发最多的止损档"表述不成立**，应更正为：**触发最多的是 stage-4 的 −4σ 档位 SL（残余 20% 档）**，−6σ 硬兜底贡献 ≈ 0。同时 ⇒ **任何"哪个 SL 档触发最多"的 orders.csv 归因对 stage4 不可解释**（Q1 十臂 `stage4_sl` 415 笔 ≫ stage3_sl 285 笔的差异，来自 S1/S2/S3 的 PT 抢先完成，而非"硬砍"）。

**发现 N-6：锁定轴存在"不可成交价"污染区（已量化）**
`profit_lock` 把 SL 上移到 `max(sl_i, pl_sl)`；当 `pl_sl > 该档 PT` 时，内核仍按 `entry×(1+pl_sl×vol)` 成交——**该价可高于当根 bar 的 high（不可成交）**。
**模型无关上界检验**（realized 不得超过"买入@entry、卖在窗内最高价"的上界）：

| 锁值 (s2/s3) | 违反上界笔数 | max(realized − 可达成上界) | 判定 |
|---|---|---|---|
| **1/2（现行）** | 1/620 (0.16%) | +0.1375pp | 基线微瑕（与锁定轴无关） |
| **2.5/3.5** | 1/620 | +0.1375pp | ✅ **干净** |
| 3/4 | 1/620 | +0.1375pp | ✅ 干净（边界） |
| **4/5** | **23/620 (3.7%)** | **+2.689pp** | ❌ **幻价污染，结论作废** |

⇒ **锁定轴的合法域 = `s2_sl ≤ 3.0` 且 `s3_sl ≤ 4.0`**（即锁值必须**严格不超过同档 PT**）。D-153 把 profit_lock 判为"可忽略/2%"**仅在已测的 (1,2)/(1.5,2.5) 区间成立**；实际上该轴在合法域内**单调上行**（见 §2.4），是一个**被低估的真实杠杆**，但**上限被 PT 钉死**⇒ 用户令 12:59 要求的"profit_lock 与 pt_after_sl 配套同步优化"**必须以此边界为硬约束**（否则产出幻价臂）。

**★统计功效裁决（本轮最重要的方法论修正）**
1. **多重比较校正**：本批共检验 ~59 个变体 ⇒ Bonferroni α=0.05/59 ≈ 8.5e−4 ⇒ **需 \|t\| ≥ 3.5**。**没有任何单个变体达标**（最大 \|t\|=3.78 出现在 SL×0.5/WC，属单窗子集）。
2. ⇒ **D-153 的"sl_scale 改善 53% / ALL5 ×2.96"是实测比值，但被表述为"唯一显著主杠杆"时缺了功效门槛**。正确表述：**SL 收紧是唯一在三个主判窗上"符号一致且量级最大"的轴（t≈2.0~2.7 pooled），属"名义显著、校正后不显著"的**候选**，必须交由 Q2b 真实回测判定**。
3. **明确判为噪声（\|t\|<1，不得据以决策）**：破简并、pt_after_sl、profit_lock 在 WC 上、hard_sl（惰性，N-4）。
4. **P0 自身不可拒绝**（t=+0.50）⇒ 620 笔的逐笔期望无法区分正负；**唯一单窗显著的是 WC 的 P0 = −1.96%/笔（t=−2.41）** ⇒ WC 的结构性出血**有独立统计支持**（与 D-152 一致），这是 Q2b 主判窗选择的又一实证。
5. **代理指标 ≠ ★Sharpe/★Calmar**：Q2a 无净值序列 ⇒ **无法计算 ★Sharpe / ★Calmar / MaxDD / 单位敞口年化**。故本裁决**不主张任何达标结论**，仅给剪枝与编队评价（符合用户令"D-148 三指标并列"仅适用于回测臂）。

## 4. 裁决（D-156）

1. **★否定的是路径，不是机制价值（延续 D-152 裁定 3）**：本轮否定的是**"破简并/卖出前移/硬止损"这三条 Q2 路径**（前者噪声、后者死分支），**不是**"分档止盈止损机制"本身。
2. **★Q2 的真实杠杆排序（合法域内，按主判窗符号一致性 + 量级）**：
   **① sl_scale 收紧（唯一三窗符号一致，t≈2.0~2.7）> ② profit_lock 上移（合法域内单调，但 WC 为零）> ③ 其他（噪声/死分支/有害：不得进入候选）**。
3. **★Q2b 保留并行（不中止）**，但**下一阶段（Q2c）应以本裁决为导向**：把资源从"硬止损/前移/破简并"转走，**唯一待补的轴是 profit_lock（合法域内）**——这与用户令 12:59"profit_lock 与 pt_after_sl 必须配套同步优化"**直接对齐**。
4. **★必附限制（强制声明）**：Q2a **不产出** ★Sharpe/★Calmar/MaxDD/单位敞口年化（无净值序列）；**proxy_sharpe 仅是同样本单调代理**；**620 笔在 Bonferroni 校正下无单轴显著**；**改标签会改模型（选择反馈未被建模）**；一切采纳结论**只能来自 Q2b 真实回测**，且 Q5 才验收 20% MaxDD。
