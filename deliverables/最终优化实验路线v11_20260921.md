## §11 ★备选优化项（2026-09-21 20:25 **修正版**）：`Q5R-OPT′` —— 免训练对照臂（dump + replay）

> **来源**：用户两轮质询（①"随机选股能不能跳过训练"②"买多少/买多久/什么时候止损跟模型有关系吗"）
> **答复档**：`deliverables/Q5R波1批次设计与启动_20260921.md` **§9（初答）+ §10（★修正答复，以 §10 为准）**

| 项 | 内容 |
|---|---|
| **实测成本结构** | 单轮 611.2s：标签+训练 **98.1%**／交易模拟 **1.8%** ⇒ 21 臂 ≈235h，其中 ≈230h 在**重复训练同一个模型** |
| **★逐通道核对（修正初答）** | **买多久**（固定 20 日调仓）= **与模型无关**｜**止损/止盈**（σ 的固定倍数，**σ = 入场时个股自身 EWMA 波动率**）= **与模型无关**｜**买多少**（代码 `target_weights=prob_dict`，但**实测近似等权**：66 轮 CV 中位 **2.55%**，唯二偏离日为整手/残余零股）= **实质与模型无关**｜**买不买**（IC 门控）= **唯一真模型通道**，但**实测 66/66 恒放行** ⇒ 可固定复现 |
| **⇒ 结论** | **用户的方案成立**：用"采纳包一致的固定规则"做对照有效；**且可做成免训练版** |
| **方案 `Q5R-OPT′`** | 新增 `preds_mode: dump`（跑 1 次，零行为改变，落盘每轮分数向量/候选集/门控决定）+ `preds_mode: replay`（N 个随机臂：同一 RNG 流同一置换 → Top-20 → 权重取前 20 大分数 → 其余逐位不变）⇒ **与现设计逐位等价** |
| **成本** | replay 单臂 ≈ **18 min**（现 11.2h）；21 臂 **≈235h → ≈17h（省 ~93%）** ⇒ **算力约束解除，可把分布补满 N=21** |
| **★前置（必做）** | 同一 seed 跑"训练版 vs replay 版"，逐位比对 ①66 轮选股序列 ②净值曲线 ③权重序列。**波 1 的三臂即"训练版"对照端** |
| **纪律** | 新增代码路径须过 ①零影响闭合（行为级 + 反自证）②R-126/R-127 烟测 ③回放臂与真跑臂逐位对上；**波 1 执行期间不动代码**；落码窗口 = 波 1 落臂后、波 2 起臂前；**等价性不成立则回退现设计** |
| **状态** | ⏳ 待落码（波 1 之后）。若波 2 gate 反向终止 ⇒ 本项一并作废 |

## §12 备选实验登记（2026-09-22 12:00 新增）：`Q5S` —— staged-exit「形状轴」

> **来源**：用户质询「止损太多是不是病因？能否设计更合理的止盈止损参数使退出分布更均衡？」
> **答复档**：`deliverables/分阶段出场排序机制与止损占比分析_20260922.md`（含真实 5 股票例证 + Q5A/Q5L 实测反证）

| 项 | 内容 |
|---|---|
| **用户假设** | 「止损占比太高 ⇒ 调参数让退出分布更均衡 ⇒ 组合更好」 |
| **实测反证** | **Q5A（PT 轴）**：止盈最紧的 `PT100` 退出分布**最均衡**（PT 占比 27.6%、胜率 46.6%），但**组合最差**（年化 9.11% / ★Sharpe **0.6832** / ★Calmar 0.5176 vs 采纳包 15.86% / 1.1587 / 1.0483）。**Q5L（更早 PT + 更均衡份额）**：4 臂 PT 占比 +2.2~2.8pp、胜率 +1.3~5.3pp，**但单笔均值全部下降**，整批裁决 **CI 全含 0、未采纳**。⇒ **"均衡"与"组合表现"在本轴上是负相关的**（均衡 = 砍右尾；微盘股收益是厚右尾）。 |
| **病因更正** | 止损多不是病因，而是**"σ 当尺子"的必然结果**（随机游走理论值 71.4% vs 实测 72.6%）；真病因是**标签把 σ 的排序当成了收益的排序**。**且模型已在显著降止损率**：交易侧 SL 54.7% vs 标签侧 72.6%（**−18pp**）。 |
| **★结构发现** | **S1 与 S2 阈值完全相同（+4.5σ/−1.8σ）** ⇒ 「4 阶段」实际只有 **3 条线**：**60% @ 4.5/−1.8σ、20% @ 6.0/−2.4σ、20% @ 9.0/−2.4σ** ⇒ **份额细调（25/35→30/30）几乎无杠杆**。 |
| **候选（未扫过的子空间）** | ①**SL 阶梯方向反转**：S3/S4 由 −2.4σ → **−1.8σ**（越晚越紧；Q5L_L3 只扫过"越晚越松"）｜②**份额重心后移** 60/20/20 → **45/25/30**｜③**保本线缓冲**：`profit_lock.s1_sl` 0.0 → **−0.5σ**｜④**二次入场** `pt_after_sl.s2_pt` 1.5 → 1.25（暂缓） |
| **排除项** | `hard_sl=−6σ`（<2% 概率）｜PT 阈值（**R-111 平台带** PT150~175 禁微调）｜SL 主档 −1.8（**D-219 已定锚**） |
