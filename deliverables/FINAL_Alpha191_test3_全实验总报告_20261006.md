### 1.3 为什么必须做"纪律体系"（本项目的核心方法论）

本项目在 6 个月里踩过的坑，**绝大多数不是策略问题，而是"判断方法"问题**。因此形成三层纪律：

- **第一层 · 落地前门禁（防"跑在错的东西上"）**：代码代际冻结（`_exp_version.py` 三闸门 `preflight`/`guard-edit`/`audit`）→ 快照门（R-156）→ 磁盘门（R-183）→ 内存门 → 存活门。**未过禁跑**。
- **第二层 · 改动守恒（防"改了却以为没改/没改却以为改了"）**：变更行数 == 变更键数（R-132）｜AST 符号集合守恒（R-169）｜**配置键分支可达性**（R-196：死键拦截）｜**剂量非退化断言**（R-181）｜**行为级自证 + 反自证**（R-178/R-132）。
- **第三层 · 裁决纪律（防"把噪声读成结论"）**：CI 含 0 只读方向（R-109）｜inconclusive ≠ 否证（R-164）｜多臂必校正（R-194）｜单基座禁外推（R-199）｜改标签则训练侧端点失格（R-198）｜**关闭出口两档化**：「资源结案」≠「冻结」（D-308）。

#### 3.5.1 D-281 · `amount` 反向复权缺陷（★最严重的数据缺陷）

- **问题**：`amount`（成交额）被按**相反方向**复权（价格 ×`f`、成交额 ×`1/f`）⇒ `vwap = amount / volume` 被**反向缩放 `f²`** ⇒ **40/221 个因子列**（39 列 ＋ `alpha_154`）带 **0.9%~7.5% 的伪跳变**；**至少自 2026-06-10 就存在**。
- **性质判定**：**不是前视泄漏**（基准日恒等于当日）；是**派生量量纲不一致**（R-147：管线**无任何经济不变量断言**发现它——`low ≤ vwap ≤ high` 在原始数据 0/266 越界、现行实现下 16~252/266 越界）。
- **修复**：`df_merged['amount'] = df_merged['amount'] * (backAdjustFactor / back_factor_T)`（与价格同向）；**重算 1616 个快照，墙钟 21.4h**。
- **修复自证（权威判据）**：**跨日期并集 40 列变化（含 `alpha_154`）／其余 181 列在每一个日期都逐位不变**（★"151 列"与"39/182"两版**均已作废**）。
- **影响面（波 2.5A Step 3 · 唯一变量 A/B 两臂）**：**新选股重合度 ∩/20 中位 0.70**、池化 0.5152；逐轮 `meta_IC` 配对差均值 **−0.0002**；日收益相关 **0.978**；R-105 ΔSharpe CI 含 0。
- **裁决**：判据 **FAIL**（重合度中位 0.70 < 0.95）⇒ **判定「修复确实改变了选股决策 ≈30%」**；三条处置：①**R-148 口径分界点** ②对照锚须在修复口径上重建 ③**不回溯重跑已关闭历史批次**。

#### 3.5.5 D-331 · 复权因子报错根因定论（★含一次公开纠错）

- **初始误判**：把日志中的 `读取复权因子失败 …: 'sz.301568'` **误读为「数据文件缺失」**，并据此对外声称"**系统性数据覆盖缺口**"、还把"数据覆盖核查"设为波 4.11 的**起臂前置安全阀**。
- **实测否决**：**全量 5,440 个 `data/back_adjust_factors/*.parquet` 穷尽扫描全绿**（schema 唯一、metadata 一致、**内容与文件名零错配**、0 读取失败；mtime 全为 2026-09-02 未被改写）⇒ **"缺失"不成立、误判撤回**。
- **真实根因**：`gpsef/data/local_provider.py:189-193` **缓存淘汰无锁并发竞态**——
  ```python
  if len(self._back_factor_cache) >= self._back_factor_cache_max_size:   # 500
      oldest = next(iter(self._back_factor_cache))
      del self._back_factor_cache[oldest]      # ← 8 线程下两线程取到同一 oldest ⇒ 后到者 KeyError
  ```
  标签阶段 `max_workers=8` 并发 ⇒ 抛 `KeyError(缓存中另一只股票)` ⇒ 被 `except` 吞掉 ⇒ 该股本次复权**静默降级为默认因子 1.0（= 不复权）**。**这解释了全部三个"怪象"**：文件明明可读却说"读取失败"、报错里的 key 是**另一只股票**、"无复权因子文件"提示紧随其后。
- **行为级验证**：人为拉长删除窗口 ⇒ **145 条同形态 ERROR**（`file = sh_600011` 而 `key = sh.600000`，与现场 4 条逐项一致）；正常窗口反自证 ⇒ **0 条**。
- **影响面**：**4 次 / 587 个回测**，每次 = **1 只股票 × 1 个基准日**；4 只受影响股票在对应臂的 `positions.csv`/`orders.csv` 中**出现次数 = 0**（从未被持有）⇒ **不影响任何已采纳/不采纳裁决，无需重跑历史实验**。概率 ≈ **2.3×10⁻⁸ / 次调用**。
- **修复（G17）**：5 处 `del cache[oldest]` → `cache.pop(oldest, None)`（`_back_factor_cache`/`_full_daily_cache`/`_slice_cache`/`_minute_cache`/`_dividend_cache`）。
- **★诚实留痕**：我前两轮复现（单线程 1,200 只、8 线程 1,200 只、放大 `max_size=20`、真实 5,440 只）**全部 0 错误**，一度以为机制不成立。原因是真实窗口只有 ~3 字节码，**样本量不足** ⇒ **复现失败 ≠ 机制不存在**。改"拉长窗口"后立即复现。
- **★两条教训（已入纪律）**：①**「日志里出现陌生标识符」≠「该标识物缺失」** —— 定性前必须先做"对象是否存在"的最低限度核实；②**否定一个机制时须给足样本量或放大条件**。

## §4 跨波综合洞察（12 条，这是本项目真正的"知识产物"）

> 下列 12 条是**跨波次反复验证**才成立的，不是任何单一波次的产物。**它们是本项目留给后续实验的最大资产。**

### 4.1 关于"策略为什么有效"的洞察

1. **模型贡献形态 = "降分母"而非"抬分子"**（D-279 / 波 2.5C / D-246）。
   采纳包年化 14.35% 与最好的随机臂（15.963%）**几乎相同**，但 ★Sharpe／★Calmar／\|MaxDD\|／单位敞口**四项全部 0/21 被达到**、且**均敞口反而更低（42.80% vs 48.6%）**。
   ⇒ **Alpha191+XGBoost 的贡献是"在同样收益下大幅降低波动与回撤"，不是"赚得更多"。**
   ⇒ **推论**：任何"提收益"的调整（出场档位、PT 阶梯、样本权重…）**天然打不到靶心**；**"降尾部/降回撤"才是模型的既有优势方向**——这也解释了为什么**唯一进 20% 线的候选（`NEG10` \|MaxDD\| 13.40%）出现在"回撤侧"而非"收益侧"**。

2. **约六成超额来自池内 alpha、约四成来自小市值 beta（同向）**（`D-340`，2026-10-07 修订；原 Z21 结论已判 INVALID）。
   策略自有池（等权、复权价、共同交易日 1282）年化 **+12.18%**、\|MaxDD\| **44.94%**；总超额 **+33.78pp** = **size beta 项 `+13.85pp`（41.0%）** ＋ **池内 alpha 项 `+19.93pp`（59.0%）**。
   ⇒ **策略既赚了"池内选股"的钱，也确实赚了"小市值风格"的钱（约 41%）** ⇒ **微盘风格逆转会直接冲击这部分收益**（原表述"不是在赚小市值的钱"**作废**）。
   ⇒ **★方法论教训（新立 `R-201`）**：基准必须**复用策略自有池**、**同源复权口径**、**报成分画像**、**与官方指数做跟踪误差校验**；原 Z21 因"裸排名池 ＋ 未复权价"把 `+13.85pp` 算成了 `−20.09pp`。

3. **"低波动异象"不适用于微盘池**（D-262）。
   微盘股「**高波动 ⇒ 高后续收益**」（池指 Spearman **+0.1055**、策略自身 **+0.1639**；高波组后续收益是最低波组的 **4.6~5.6 倍**）。
   ⇒ **任何"高波动时降敞口"的机制都会系统性卖在反弹前** ⇒ 这是一条**可外推的池级事实**（但**参数禁迁移**，R-172）。
