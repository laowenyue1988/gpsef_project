### 2.4 ★背离的机制解释（关键，应升级 D-234）

`barra_constraint.py:302-305`：

```python
# ── w_target: 默认 = softmax(alpha) ──
if w_target is None:
    exp_a = ...
    w_target = exp_a / exp_a.sum()
```

λ_l2 的作用是 **`min ... + λ_l2‖w − w_target‖²` ⇒ 向 `w_target` 收缩**。而 `w_target = softmax(alpha)`，`alpha` 由**实测 meta_auc/IC × vol_target × z** 构建、**截面上高度不均匀** ⇒ **softmax(α) 本身即高度集中的分布**。

⇒ **抬升 λ_l2 并非把解推向等权，而是把解推向 `softmax(α)`**；当 `softmax(α)` 比风险项 `λ_dev‖Bᵀw − B_bench‖²` 更集中时，**λ_l2↑ 反而可能强化集中**（或至少不能有效分散）。

**这正是预筛 0.0704 与实测 0.0852 背离的机制来源**：D-234 预筛在 α 输入上采用了**等值 α / 宽斜坡 / 单点突出**三种人造分布（`_q5c1b_prescreen.py:78-80`），**与真实 `softmax(α)` 的形态不同** ⇒ 预筛的 F2 结论「**λ_l2 是唯一有效杠杆**」（HHI 0.0871→0.0632）**在真实 α 语义下不成立**。

> **D-234 修正建议（登记，待落臂后正式升级）**：预筛 ③ 条须改为「在 **真实 `w_target = softmax(α)** 下」重跑，而非等值/斜坡 α；否则 F2/F5 无外推效力。
