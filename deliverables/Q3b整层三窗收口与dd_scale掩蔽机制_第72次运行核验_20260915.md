**★先排除「机制未生效」**：`Q3b-WX` 日志**确凿出现** `dd_scale < 1.0` 三档 ——
```
[仓位控制] vol_scale=0.796(σ=30.2%) dd_scale=0.856(DD=5.3%) → final=0.796
[仓位控制] vol_scale=0.588(σ=40.8%) dd_scale=0.722(DD=9.6%) → final=0.588
[仓位控制] vol_scale=0.723(σ=33.2%) dd_scale=0.902(DD=3.7%) → final=0.723
```
⇒ `compute()` **被调用**、四级阶梯**判定有输出**（D-176 P0-1/P0-2 修复维持有效）。**故「逐位等同」不是「未生效」，而必须是「生效但未触达仓位」。**

### 2.2 ★根因：`final_scale = min(vol_scale, dd_scale)` 的 `min` 合并

`garch_position.py:408-409`：
```python
final_scale = min(vol_scale, dd_scale)
final_scale = min(self.max_scale, max(self.min_scale, final_scale))
```
**当 `vol_scale < dd_scale` 时，DD 阶梯的扣减被 `vol_scale` 完全吞掉。**

### 2.3 ★★正确判据：`dd_scale < 1` 时 `final` 是否相对同窗 Q3a 下降

`Δfinal = final_Q3b − final_Q3a`（>0 不可能；<0 = 阶梯真实扣减；=0 且 `dd_scale<1` = **完全掩蔽**）
