## 一、目标与背景

**O1 问题**：HP-Search 在 ~136 粗筛特征上评估超参，生产模型实际运行于 15-19 精选特征——评估环境与应用环境的维度错配，可能导致选出的超参系统性偏保守（浅树/强正则）。

**方案 B 结论**（已审核）：当期 IC/PSI Top-30 作为评估特征，消除 9 倍维度差到 2 倍，每期独立。但剩余 2 倍差仍非零。

**本方案（O1+）**：在方案 B 思想之上，用**本期真实生产特征集**评估超参，将维度差收敛到 0——通过"同一期内两轮迭代"实现，不引入跨期依赖（规避方案 A 的缺陷）。

## 二、方案核心流程

```
当前单轮:
  粗筛(158) → HP-Search(评估于136) → θ₁ → PKF(θ₁) → F₁(15-19) → 生产(θ₁+F₁)

两轮迭代 (本方案):
  第1轮: 粗筛(158) → HP-Search(评估于136) → θ₁ → PKF(θ₁) → F₁(15-19)
  收敛检查: θ₂==θ₁ → F₂=F₁, 跳过 PKF#2 (确定性保证, 见 §3.1)
  第2轮: HP-Search(评估于F₁) → θ₂
         ├─ θ₂==θ₁ → F₂=F₁ (零额外 PKF 成本)
         └─ θ₂≠θ₁ → PKF(θ₂) → F₂ (特征在最终超参下重新选择, 闭环)
  生产: (θ_final + F_final), 门控=折集成 meta_AUC (不变)
```

**核心思想**：第 2 轮让"超参评估环境" = "第 1 轮产出的真实生产特征环境"；若超参因此翻转（θ₂≠θ₁），则特征必须在 θ₂ 下重新选择（F₂），保证**最终模型的特征与超参完全一致**。

## 三、关键设计决策

### 3.1 "θ₂==θ₁ 则跳过 PKF#2"的确定性论证
- PKF 折内模型参数全部来自 `config.XGB_*`（L2115-2127），种子固定（`XGB_RANDOM_STATE`），MDA 置换种子固定（random_state=42+i）；
- 因此 θ 相同 → 折内模型相同 → MDA/MDI 相同 → 投票结果相同 → F 相同；
- 该路径**零额外 PKF 成本**（仅多一次 HP-Search#2，评估于 15-19 特征，比 136 特征快 5-10 倍，约 5-15s）。

### 3.2 收敛与防振荡
- **收敛判据**：θ 逐参数完全相同（离散强判据，无伪收敛）；
- **理论上限**：`max_iterations=3`（第 3 轮同理，超出即用最新结果，防 θ-F 振荡）；
- 实测预期：候选集仅 4 组、GBDT 超参弱敏感性 → 多数周期 θ₂==θ₁，一轮收敛。

### 3.3 防护与降级
| 场景 | 处理 |
|---|---|
| 第 1 轮 PKF 失败/无特征 | 跳过第 2 轮，单轮降级（= 现状行为） |
| 第 2 轮 HP-Search 全候选 AUC<0.5 | 防护触发不写回 → θ₂=θ₁ → 等价跳过 PKF#2 |
| 第 2 轮 PKF 失败 | 回滚 θ 到 θ₁ + 用 F₁（完全一致路径，最安全） |
| iteration_rounds=1 | 完全等于现状（开关控制，无行为变化） |

### 3.4 协议一致性
- HP-Search#2 与 #1 同协议：3 窗 expanding、每窗早停、LRWarmup、生产 val 零接触、AUC<0.5 防护；
- 评估特征 = F₁（已 ⊆ 当期粗筛池，PKF 输出天然满足）；
- 候选超参集**复用同一 4 组**（c1-c4），保证两轮选择可归因（θ 翻转 = 特征环境变化所致，非候选集变化）。

### 3.5 配置项（config.yaml）
```yaml
hyperparam_search:
  ...
  iteration_rounds: 2        # 1=现状单轮; 2=本期两轮迭代 (O1+)
  max_iterations: 3          # 理论上限 (防振荡)
```

## 八、业界最佳实践标准客观评价

### ✅ 符合标准的部分
1. **迭代式模型选择（alternating optimization）**：θ 与 F 交替优化是"嵌套 CV 联合搜索（θ×F 全网格）"的标准工程近似（类似 coordinate descent / EM 交替），业界（Prado AFML、主流量化机构）普遍采用"两阶段 + 收敛迭代"形态；
2. **特征-超参一致性闭环**：最终特征 F₂ 在最终超参 θ₂ 下选出（第 2 轮 PKF）——完整满足"特征选择必须用最终模型配置"（Cawley-Talbot 原则的工程实现）；
3. **收敛监测与防振荡**：θ 离散判据（无伪收敛）+ 3 轮上限，是迭代优化框架的标准配套；
4. **评估数据零接触**：两轮 HP-Search 均剔除生产 val，PKF 验证块只评 AUC（P0-1 成果保持）；
5. **无跨期依赖**：两轮均在本期完成，每期独立、可复现、可中断续跑（优于方案 A）。

### ⚠️ 工程折中（诚实声明）
6. **非联合搜索全网格**：交替优化是联合搜索的近似（理论上限是完整嵌套 CV），计算预算下的标准取舍（成本 ×1.3-2 vs ×5-10）；
7. **第 2 轮候选集复用 c1-c4 而非 θ₁ 邻域微调**：弱信号条件下的**收缩原则**正确选择（非折中）——见 §8.1 论证。θ₁ 邻域细网格已被理论否决，不预留演进。
8. **收敛判据为离散 θ 比较而非连续性能差 < ε**：θ 相同是更保守的充分判据；且 θ₂==θ₁ 时恰好跳过 PKF#2，无额外代价，设计自洽。

### ❌ 已知风险
9. **计算成本波动**：θ₂≠θ₁ 的周期 PKF ×2（+200-280s）。缓解：重训间隔 5 摊薄 + θ₂==θ₁ 高频时增量极小；
10. **第 2 轮评估噪声**：F₁（15-19 特征）上 3 窗 AUC 差异小，θ 翻转可能是评估噪声而非真实改善。缓解：保持 3 窗平均（已有）+ 日志记录 θ₁/θ₂ 各自评估分数，供回测绩效交叉验证。

### 8.1 为什么否决"θ₁ 邻域微调"（V2 演进）——理论论证

**抽象世界**：无噪声评估下，θ₁ 邻域细网格严格不劣于复用 c1-c4（网格越细越逼近 θ*，coarse-to-fine 直觉成立）。

**现实世界（本项目条件）三个因素使其更差**：
1. **评估噪声压过邻域差异**：评估 = 3 窗 ≈ 18K 样本，弱信号（AUC 0.52-0.55）下标准误 ~0.003-0.004；c1-c4 真实 spread 仅 0.005-0.01（同量级），θ₁ 邻域候选差异更小（0.001-0.003，远低于噪声）→ 局部寻优选中噪声峰值；
2. **GBDT 响应面平坦**：合理区间内超参性能差 < 1-2%，邻域微调真实收益差 0.1-0.3%，被噪声（0.3-0.4%）淹没；
3. **winner's curse**：邻域 N 次比较选最优 = 在噪声上采样取最大正误差；候选差异越小，噪声主导概率越高。

**理论框架**：这是统计决策的**收缩原则**——估计噪声大时最优决策是向先验（c1-c4 的结构分档 = 超参空间先验锚点）收缩，而非信任噪声峰值。V2 违反收缩原则，等价于噪声大时用无约束 OLS 而非岭回归。

**V2 更优的三个必要条件（均不满足）**：① 响应面在网格间隙陡峭；② 评估噪声 << 候选差异（可分辨）；③ 邻域真实收益 > 噪声。三者同时满足（强信号 AUC>0.58、评估样本 >10 万）时才需细网格——届时再评估，**现在不预留演进**。

**替代监测项**（非功能预留）：若未来回测显示 HP-Search 候选间 AUC 差异稳定 >0.01 且评估噪声 <0.002，则重新评估细网格引入。

### 总体判定
**符合业界实践层标准的迭代式模型选择**。相对方案 B 是"维度差从 2 倍收敛到 0"的严格化；相对完整嵌套 CV 是计算预算下的标准工程近似。与主流量化机构的"两阶段 + 收敛迭代"实践一致。风险点（计算波动、评估噪声）均有明确缓解手段。
