## 二、★★O-13 · 三列敞口口径勘误（历史记录不可复现的真实原因）

### 2.1 缺陷陈述

历史文书对该口径的**文字描述**是「`daily_values.csv` 的 `position_value/total_value_eod` 的**均值**」
（见跟进日志 D-58 段、以及"三列敞口口径 = 平均敞口 / 单位敞口收益 = 年化÷平均敞口 / 单位敞口回撤 = |MaxDD|÷平均敞口"的表述）。
但**实际实现**是 **比值之和**：

```
平均敞口 = Σ_t position_value_t  /  Σ_t total_value_eod_t          ← 真实口径
平均敞口 = (1/T) · Σ_t ( position_value_t / total_value_eod_t )    ← 文字描述（错误）
```

### 2.2 反推验证（3 个已公布锚点，4 位小数逐位吻合）

| 臂 | 逐日均值口径 | **比值之和口径** | 历史记录 | 结论 |
|---|---|---|---|---|
| `R2A-BASE-df` | 0.3159 | **0.3238** | 0.3238 | ✅ 比值之和吻合 |
| `R2A-L2-df` | 0.3269 | **0.3319** | 0.3319 | ✅ 比值之和吻合 |
| `R2A-OVER_c3` | 0.3509 | **0.3586** | 0.3586 | ✅ 比值之和吻合 |

单位敞口回撤同样验证：`0.1875 / 0.3238 = 0.5791`（历史 **57.92%** ✓）；`0.1965 / 0.3586 = 0.5481`（历史 **54.81%** ✓）。

### 2.3 仍不可复现的一项：单位敞口收益

M8 记录 `c3 8.99% / BASE-df 8.30%`，而「年化 ÷ 平均敞口（比值之和口径）」给出
`12.61% / 11.74%`（差 ≈ **−3pp ≈ 成本量级**）。已试 **10 种候选式**（差值法 / 超额收益 / 剔成本 / 逐日活跃均值 / 中位数 / 位移分母 / Σpos/Σtv 等）**均不吻合**。

**处置（保守可逆）**：
- 工具**照常输出**该列，但**强制并列披露**「历史记录值不可由本工具口径复现」；
- **M10 结论一律以「相对基线的 Δ%」为准**（同口径跨臂可比，口径偏置在差值中大幅抵消）；
- **禁止**把工具数值与历史记录值**跨口径直接比较**。

> **教训（可复用）**：凡"历史公布数字"要复刻时，**必须用已知记录值做锚点断言反推口径**，
