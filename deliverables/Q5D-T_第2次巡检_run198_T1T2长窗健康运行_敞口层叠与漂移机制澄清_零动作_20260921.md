## 三、★核心分析：敞口层叠与漂移机制澄清（本轮新立 R-196）

### 3.1 现象

烟测臂 `trend_floor = 0.50`，按代码 L4407 逻辑，trend 分支**应只输出两档** `{1.00, 0.50}`。但逐日实测敞口分布为：

| 敞口区间 | 天数 | 占比 |
|---|---|---|
| [0.0, 0.1) | **43** | **51.8%** |
| [0.1, 0.3) | 6 | 7.2% |
| [0.3, 0.5) | 6 | 7.2% |
| [0.5, 0.7) | 6 | 7.2% |
| [0.7, 0.9) | 12 | 14.5% |
| [0.9, 1.0) | 10 | 12.0% |

**实测 min = 0.0500，远低于 floor 0.50。**

### 3.2 机制辨析（逐层排除）

| 候选层 | 是否解释低敞口 | 证据 |
|---|---|---|
| `signal_type = trend`（trend 分支） | ❌ 仅产 {0.5, 1.0} | L4407 `new_scale = 1.0 if px>ma else floor` |
| `use_daily_scale = true`（vol 层） | ❌ **被 trend 分支 return 短路** | L4415 `return` ⇒ vol 计算（L4416~4430）**不执行**；且 min_scale 默认 0.15 ≠ 0.05 |
| `drawdown_breaker`（L3 熔断层） | ❌ **已关闭** | 烟测 config L362 `enabled: false`；日志中「熔断」0 命中 |
| **★组合净敞口在两次调仓之间自由漂移** | ✅ **正解** | 见下 |

**正解**：`_daily_vol_scale`（= 趋势档位）**仅在调仓日决定建仓规模**；两次调仓（20 交易日）之间，持仓市值随微盘股价格波动，**敞口（position_value/total_value）自然漂移**，可大幅低于目标档位。烟测敞口剧变点：

```
2024-04-15  0.679 → 0.206     2024-05-06  0.073 → 0.983
2024-06-04  0.480 → 0.161     2024-07-02  0.061 → 0.485
2024-07-04  0.448 → 0.267     2024-07-30  0.051 → 0.492
```

⇒ **每次跳升至 ≈0.48~0.98 = 调仓日按档位建仓**；两跳之间的深跌（→0.05~0.07）= 该段微盘股急跌 + `redeploy_enabled=false`（欠配不再补仓，config L335 `reinvest_enabled: false`）⇒ **敞口只跌不补**。**这是设计行为，非 bug。**

### 3.3 新立 R-196

> **R-196**：**判「分层敞口档位是否生效」不得用逐日敞口值直接核对 floor，必须用「调仓日前后跳变点」。** 逐日敞口 = 档位 × 期内价格漂移 × 欠配不补（`redeploy_enabled=false`），会系统性偏低；用逐日 min 对比 floor 会得出「档位失灵」的**错误结论**。正确核对法：①看 `[E3-敞口]` 事件行给出的 `scale=` 真值；②看调仓日跳变幅度的**量级排序**（floor 0.3 的跳变应约为 floor 0.5 的近 2 倍）。

### 3.4 对 T-1/T-2 判据的影响（前置声明）

- **T-1 有效性闸**（逐日降敞口交易日占比 >20%，**用 `daily_values.csv` 口径**）：烟测实测 **83/83 = 100%** ⇒ 闸的**分母方向**成立，但**该指标对趋势层不具区分度**（因漂移使敞口几乎恒 <1.0）。**T-1 在长窗落臂后须按 R-196 补做「调仓日跳变」口径的旁证**，避免 V1 式「看似通过实则无信息」。
