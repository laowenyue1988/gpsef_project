### 1.2 ⚠️ 三个必须知道的陷阱

1. **`expected_ic` 是假杠杆** —— 配置写 0.05，运行时被 `meta_auc` 覆盖。**扫它等于白烧算力。**
2. **换手约束从未实现** —— 求解器签名注释明写：`prev_weights`（**换手约束未实现**）、`max_ind_dev`（→ 已由 `lambda_ind` 软惩罚替代）、`turnover_bound`（**从未使用**）**已于 2026-09-08 删除**，旧调用方传了也会被 `**kwargs` 静默吸收 + 告警。
   ⇒ **微盘策略最大的成本项（冲击成本）在组合优化层完全没有惩罚项** ⇒ 只能靠 `lambda_l2`（贴近等权）**间接**抑制。
   ⇒ **★ 若 `lambda_l2` 扫描显示"越贴近等权越好"，那就是换手/成本缺口在说话的间接证据**（一条会被记录下来的推论）。
3. **`total_exposure=1.0` 硬编码**（"BARRA 始终全投资约束 Σw=1.0"）⇒ **BARRA 层不控总敞口**，总敞口由 `garch_position.py` 前置决定 ⇒ **职责边界清晰：GARCH 管总敞口，BARRA 管内部配比。**

### 1.3 `baseline` 的真实作用面（别期待过高，但也别低估）

- 作用面**仅** = 「因子偏离基准 B_bench」+「行业权重基准」⇒ **不是**风险模型的估计域，**不是**跟踪误差基准。
- 但配置注释给了**强机制证据**：**`csi800` 下 size 偏离 ~3.7σ，会被 `lambda_dev` 强力压制**（因 csi800 = 沪深300∪中证500，而策略池是**微盘**）⇒ **baseline 选错，会把优化器逼向"压制规模暴露"，与微盘 alpha 直接冲突。**
- ⇒ **`baseline` 是个真参数，但它与 `lambda_dev` 强耦合** —— 二者必须**联合考虑**（这决定了扫参顺序：先 λ_dev 还是先 baseline 要看 Q5C-1 结果）。

## 2. ★ 先说清 BARRA 的天花板（期望管理，必须写明）

调用实参：`solve_barra_weights(preds=probs, selected_codes=codes, ...)`，其中 `codes = list(self.target_weights.keys())`（`strategy.py:3745`）。

> **⇒ 优化器只在「已选中的那 20 只」内部配权 ⇒ BARRA 不能改选股、不能改目标、不能改出场。**

因此：
- **BARRA 能榨出的**：组合构造效率（风险加权、因子/行业暴露控制、集中度）⇒ 主要改善 **★Calmar、|MaxDD|、单位敞口年化**
- **BARRA 榨不出的**：**★Sharpe 里的 α 部分** —— 那由**选股 + 目标定义**决定（即 D-226 / Q5N）
- **⇒ BARRA 与 Q5N 是互补的两条轴，不是替代关系。** 且 BARRA 的天花板由 α 质量决定。

**★ 先验证据（必须同时引用，避免期望过高）**：**Q3 结案时 BARRA 在 2/3 窗被判「机制净负」**（但那是在**未打补丁代码**上、且 baseline 用 csi800）⇒ Q5C-1 正是在干净代码 + 正确 baseline 上**复评这件事**。**所以 Q5C-1 是整条 BARRA 轴的门。**

## 3. 预注册判据

### 3.1 通用（沿用）
`P1 兑现率优先`（Δ单位敞口年化 + Δ★Sharpe 为主判据）｜`P2 IC 并列报但不得作采纳依据`｜`P3 R-105 CI 含 0 只读方向 + CI 形态并列（R-114/R-115）`｜`P4 D-224 不劣于锚点 + D-174 |MaxDD|<20%`｜`P5 分段归因（WD 股灾段/WX 尾部窗/2026）+ 敞口序列 + 止损质量`。

### 3.2 ★ BARRA 轴专属
- **B1（门）**：**Q5C-1 若显示 BARRA 净负或不可辨识 ⇒ 整条 BARRA 轴降级**，不做 Q5C-2 软约束标定，转 Q5N。**这是本设计最重要的一条**（防止对一条先验为负的轴连烧 8 臂）。
- **B2（单调/平台/反转）**：每个软参数先用**双向极端**探方向（2 臂），依据 `单调 ⇒ 沿向补档`｜`平台 ⇒ 立即停（R-111，禁带内细化）`｜`反转 ⇒ 取中间档` 决定是否补第 3 臂。**禁止一开始就铺全网格。**
- **B3（换手代理）**：`lambda_l2` 方向必须记录为**成本缺口的间接证据**（若"越贴近等权越好" ⇒ 支持"换手惩罚缺失是真问题"）。
- **B4（联合约束）**：`baseline` 与 `lambda_dev` 强耦合（§1.3）⇒ **两者不得各自单独定档后直接组合**，定档其一后须复核另一个。
- **B5（假杠杆禁令）**：**禁止扫 `expected_ic`**（运行时被覆盖）；`alpha_scale` 除非有量纲证据，暂不扫。

## 5. ★ 最终路线（定稿 v2）

```
Q5L 收尾（L4 在跑 → 裁决）
  → ★Q5C-1（BARRA on/off × baseline {sh932000, csi800}，2 臂在跑）⇒ 【BARRA 轴的门】
       ├─ 若「净正」⇒ BARRA 升为最高优先：Q5C-2a → 2b → 2c → 2d（每个 2 臂起，自适应）→ Q5C-3 长窗确认 → 采纳裁决
       └─ 若「净负 / 不可辨识」⇒ BARRA 轴降级（B1），直接转 Q5N；BARRA 软约束标定顺延到 Q5N 之后
  → ★Q5N（目标改造，落 smallcap；2 臂）
  → [若 BARRA 降级则在此补做 Q5C-2 软约束标定]
  → Q5D（回撤阈值 + `garch_position.py` 四级阶梯）
  → Q5E（组合终验 + 最终《落地建议书》）
  （Q5V = V10 分支，用户指示"以后再说"，从排期中移出）
```

### 5.1 为何这样排序（三条硬理由）

1. **Q5C-1 已在跑且是门** ⇒ 结论最快到手，用它决定 BARRA 是否值得连投。**不做"先铺满参数再回头看"的浪费。**
2. **Q5N 是唯一能改 α 质量的轴，而 BARRA 的天花板由 α 决定**（§2）⇒ 若 Q5C-1 不支持 BARRA，**先攻 α 才是正解**。
3. **若 BARRA 支持**，则**软约束标定应尽可能靠近终态选股**——但 Q5N 会改选股 ⇒ 所以采用**条件分支**：BARRA 显著为正时接受"标定早于 Q5N"的代价（因为纯组合层、零混杂、结论快且可复算），并在 Q5N 后复核关键档（B4 精神）。

### 5.2 与既有条目的一致性
- **不动标签/不动出场** ⇒ 满足 **D-225**（Q5C 全轴都是纯组合层）。
- **BARRA 作为风控/组合引擎在册启用**（**D-144**：从未被禁用，禁的只是"作为特征"）。
- 启用前 **D-176/D-177 必审 5 项已全过**（Q5C 启动前完成）。
- **Q5D 仍排最后**：GARCH 控总敞口、BARRA 控内部配比（§1.2 第 3 点）⇒ 两者交互，Q5D 阈值应按**最终** |MaxDD| 尺度标定。
