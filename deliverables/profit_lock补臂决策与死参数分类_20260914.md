## 一、先更正我自己：`+54.5%` 是误导性表述

上一轮我给了 `profit_lock` 平移 +1.5 的读数「ALL5 **+54.5%**」。**这个数字在三个层面都有问题**：

### 1.1 它只是「通道 B」，不是总效果（**你的质疑核心**）

**代码级确证**：`profit_lock` 确实进入标签生成链 ——

```
labels.py:651-653   self.pl_sl1 = float(_plk.get('s1_sl', 0.0))     ← 标签器读取 profit_lock
labels.py:1436-1439 传入 simulate_staged_path_fast(...)               ← 标签模拟使用它
          ⇒ realized_ret 变 ⇒ `label_mode: staged_rank`（realized_ret 的**截面分位**）变
          ⇒ 训练目标变 ⇒ **模型变** ⇒ **选股变**
```

⇒ **你说得对：`profit_lock` 会通过「标签通道」起作用，而这恰好是零算力重放无法覆盖的。**

**零算力重放的本质**：它**固定模型与建仓集合**（用 Q1-BASE 臂选出的那 620 笔），**只重新模拟出场路径**。
它测的是：

> 「**如果**这 620 笔建仓不变，只换 profit_lock 规则，它们的实现收益会怎样？」

⇒ 这是 **通道 B（出场执行）**，**不是**真实臂的结果。真实臂 = **A（标签→模型→选股）+ B + C（抽样噪声）**。

**同类先例（D-161b 已实证）**：对 κ 而言，通道 B 的改善**与组合层序关系相反** ——

| 窗 | 通道 B（Q2a 固定模型） | 组合层实测 Δ★Sharpe |
|---|---|---|
| WA | **−0.0437（负）** | 正 |
| WX | +0.0269 | **+0.6902** |

⇒ **通道 B ≠ 总效果，且符号都可能相反。** 因此 `+54.5%` **绝不能**当作预期收益。

### 1.2 它的绝对量级极小（比相对值重要）

| 口径 | BASE | PL_shift+1.5 | 净变动 |
|---|---|---|---|
| ALL5 逐笔均值 | 0.1994% | 0.3113% | **+0.1119 pp** |
| MAIN3 逐笔均值 | −0.9403% | −0.8514% | **+0.0889 pp** |

逐笔收益标准差 ≈ **10.02 pp** ⇒ 净变动仅相当于 **0.011 个标准差**。

**为什么相对值却有 +54.5%？** 因为 ALL5 的 BASE `proxy_sharpe = mean/std = 0.01990` **本身接近 0**
⇒ 分母极小 ⇒ **小数字的百分比**。**这是典型的"近零比值放大"陷阱，我上一轮没有把它讲清楚。**

（同一原因使 MAIN3 的 −0.09071 → −0.08154 显示为 "+10.1%"，绝对量级同样只有 0.089pp。）

### 1.3 标签扰动实测：**也小**

`_probe_label_perturbation.py`（620 笔同源，符号翻转 / 秩相关 / 平均绝对变动）：

| 变体 | 符号翻转% | Spearman ρ | 平均 \|Δrealized_ret\| |
|---|---|---|---|
| PL_shift **+0.5** | **0.00%** | 0.9984 | 0.200 pp |
| PL_shift **+1.0** | **0.00%** | 0.9968 | 0.399 pp |
| **PL_shift +1.5** | **0.00%** | **0.9946** | **0.575 pp** |

⇒ 即便平移 +1.5，**标签原料的排序几乎不动**（ρ=0.995、零符号翻转）⇒ **通道 A 大概率也小**。

**★口径限制**：缓存记录**不含 `ts_code`/`event_date`**（与 `_q2a_build_cache.py` 的文档字符串不符 ⇒ 登记 **R-63**），故**无法**按"同一调仓日截面"算真实分位变化；上表用**逐窗秩相关**作保守代理。

### 1.4 综合 ⇒ 补臂方式必须改

**两条通道的零算力证据都指向"效应量小"** ⇒

- **短窗臂（WD 118 个日频样本）必然测不出** —— D-159 已实证：**连 Δ★Sharpe ≈ 0.2~0.7 的效应，自助法 95% CI 都含 0**。一个 0.011σ 级的逐笔效应更无可能被分辨 ⇒ **短窗臂 = 无用功**。
- **长窗（1315 日频样本、66 次调仓）是唯一有分辨力的仪器**。

**⇒ 修正后决定（替代 D-181 §5.29.4 之第 3 条）**：

| 项 | 原（D-181） | **修正后（D-182）** |
|---|---|---|
| 臂数 | 1 臂 | **1 臂** |
| 窗口 | **短窗**（可并行） | **长窗**（与 Q3-筛 并行以隐藏机时） |
| 预期 | 未标注 | **★预注册：很可能为空结果（null）；null ⇒ 关闭该轴，不再追加** |
| 目的 | 「验证 +54.5%」倾向 | 「**测总效果 A+B+C**」；**不是验证重放值** |
| 基线 | P0 或采纳包 | **采纳包（若无则 P0）＋ PL 平移 +1.5** |

**★为什么仍要跑 1 臂（而非直接放弃）**：
1. **你 09-13 12:59 点名要求** `profit_lock` 与 `pt_after_sl` 配套同步优化；
2. 零算力**无法排除组合层效应** —— 它不建模「**资金回收/复利/敞口时序**」（D-161 §5.12.4），
   而逐笔均值虽小，**持仓笔数众多**（长窗 6150 单）⇒ 组合层影响不能由重放推断；
3. 成本低且**可隐藏**（与 Q3-筛 共享车道）。

## 二、★决定性实验：两处「死参数」的因果识别

### 2.1 代码机理（`labels.py` 内核，Python ~line 100 与 numba ~line 319 一致）

```python
if s_pt3:   pl_sl = pl_sl3      # 优先级阶梯：stage3 > stage2 > stage1
elif s_pt2: pl_sl = pl_sl2
elif s_pt1: pl_sl = pl_sl1      # ★ 需「stage1 PT 已触发 且 stage2 PT 未触发」
else:       pl_sl = _be_pl
eff_sl_i = max(sl_i, pl_sl)
# 另：pt_after_sl 布尔标志仅在「止损事件发生后」置 True，
#     此后 eff_pt_2, eff_pt_3 = pt_after_sl2, pt_after_sl3
```

**基准档位**：`stage1(pt=3.0, sl=−3.0)` / `stage2(pt=3.0, sl=−3.0)` / `stage3(pt=4.0, sl=−4.0)` / `stage4(pt=6.0, sl=−4.0)`

⇒ **两处简并**：`pt1 == pt2 == 3.0`、`sl1 == sl2 == −3.0`

### 2.2 实验设计（破简并以识别因果，`_probe_pl_inertness_cause.py`）

| 设定 | 内容 |
|---|---|
| **D0** | 基准（保留双简并） |
| **D1** | 破 **PT 简并**：`stage1.pt = 2.0`（其余不动） |
| **D2** | 破 **SL 简并**：`stage2.sl = −3.5`（其余不动） |

**判定逻辑**：若某参数在 D0 下输出**逐位相同**（不可达），而在**且仅在**某个破简并设定下出现差异 ⇒ 该简并即其不可达的**根因**。

### 2.3 结果（620 笔，逐位指纹比较）

| 探针 | D0（双简并） | D1（破 PT 简并） | D2（破 SL 简并） |
|---|---|---|---|
| `pl_sl1` ±{0.5, 1.0, 2.0}（5 档） | **全部逐位相同 ⇒ 不可达** | **★全部有差异 ⇒ 变可达** | 全部逐位相同 |
| `pt_after_sl2` ±{0.5, 1.0}（3 档） | **全部逐位相同 ⇒ 不可达** | 全部逐位相同 | **★全部有差异 ⇒ 变可达** |
| `pl_sl2` ±{0.5, 1.0}（对照，3 档） | **有差异（本来可达）** | 有差异 | 有差异 |

### 2.4 判定（因果识别完成，预测全部命中）

| 参数 | 根因 | 性质 |
|---|---|---|
| **`profit_lock.s1_sl`** | **PT 简并 `pt1 == pt2`** | 结构性不可达；**破 PT 简并即复活** |
| **`pt_after_sl.s2_pt`** | **SL 简并 `sl1 == sl2`** | 结构性不可达；**破 SL 简并即复活** |
| `profit_lock.s2_sl`（对照） | —— | 本来就可达（阳性对照，证明实验有效） |

**★范围（合规检查器扩测）**：**109/109 个配置全部命中两处简并** ⇒ **这两个参数在本项目历史上从未生效过**（家族性，非个案）。

## 三、★回答：「死参数」必须分两类，「不进搜索空间」不能一刀切

我上一轮把两类混为一谈 —— **你的质疑成立**。正确区分如下：

| | **类型 I：简并屏蔽（结构性不可达）** | **类型 II：无消费者（代码层永不使用）** |
|---|---|---|
| 例 | **`s1_sl`**（PT 简并）、**`pt_after_sl.s2_pt`**（SL 简并） | `cooldown_periods` / `use_gradual_cooldown` / `use_cooldown_episode_tracking`（D-176 N-3） |
| 机理 | 参数**被读取并传入模拟器**，但分支因**简并**永不可达 | 参数**全文件无任何使用点**（v3.4 以 `recovery_buffer` 取代 cooldown） |
| 与配置的关系 | **条件性**：破简并即复活 | **绝对性**：与配置无关，改它永远无效 |
| 是不是 bug | **不是代码 bug**（优先级阶梯设计正确）；是**配置简并造成的参数屏蔽** | **不是 bug**，是**配置项与实现的脱节** |
| 要不要修 | **不必改代码**。要修的是**"误导"**：①**加自动检测**（已做，见 §3.1）②**Q4 搜索空间排除** ③**★不得删除**（破简并后要复活） | **要处置**（三选一）：**(a) 删键**（推荐）**(b) 实现** **(c) 显式 deprecated ＋ 启动 warn** |
| 处置时限 | Q4 前（防止无用功） | **★Q3 编队前**（见 §3.2） |
| **"不进搜索空间"成立吗** | **只在当前简并配置下成立，不可外推** | **完全成立**，且应更彻底（连配置键都可删） |

### 3.1 已执行的"正确的修"：加自动检测（零代码改动、零风险）

已扩展 **`_check_config_compliance.py`**（S-51 既有工具），新增两条规则：

```
N-20①：stage1.pt_sigma == stage2.pt_sigma (3.00) ⇒ profit_lock.s1_sl (当前 0.00) 不可达
        （`elif s_pt1` 分支被 `elif s_pt2` 恒先命中）⇒ Q4 不得把 s1_sl 列入搜索空间
N-20②：stage1.sl_sigma == stage2.sl_sigma (-3.00) ⇒ pt_after_sl.s2_pt (当前 1.50) 不可达
        （止损事件后残仓被 stage2 止损即刻清掉，eff_pt_2 用不上）⇒ Q4 不得列入搜索空间
```

**实测：109/109 个配置命中** ⇒ 以后**任何人把这两个参数写进搜索网格，排批前会被自动拦下**。

**为什么"加检测"而不是"改代码/删参数"**：
- 改代码没必要 —— 阶梯逻辑**本身是对的**，错的是**配置让某条分支不可达**；
- 删参数有害 —— 一旦将来**破简并**（让 stage1 独立生效），这两个参数会**立刻复活**；
- 而**"文档说它有效、实际无效"**才是真正需要消除的风险 ⇒ **检测 + 标注**正好对症。

### 3.2 类型 II 必须处置 —— 且理由与你 10:15 那条令直接相关

**D-175 的 Q3 机制候选表里写着**：

> `恢复缓冲 / 渐进冷却` ｜ `garch_position.py` ｜ 现状「8 开关全 false」

**但 `use_gradual_cooldown` 属于类型 II（代码层无消费者，D-176 N-3 已查证）** ⇒
**若 Q3 依该表去启用"渐进冷却"，就是纯无用功** —— 正是你 10:15「启用前审计」令要防的情形。

⇒ **登记为硬约束（S-58）：Q3 编队前，类型 II 参数必须三选一处置完毕（删键 / 实现 / deprecated＋warn）；未处置前，D-175 候选表中的"渐进冷却"不得进入任何臂。**
