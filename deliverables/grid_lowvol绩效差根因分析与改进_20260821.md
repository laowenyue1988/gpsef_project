## 二、根因分析（按重要性排序）

### 🔴 根因 1（核心设计缺陷）：网格基准每日重置 = 阴跌市"每日追跌接飞刀"

```python
# strategy.py _run_grid
base_price = float(mdf['open'].iloc[0])   # ← 每只股票每天用"当日开盘价"重建网格
```
- 经典网格的基准 = **首次建仓价**（跨日固定）：价格跌到买入线买 1 格，**反弹回基准以上才触发卖出**，靠"网格区间往返"赚价差。
- 本实现基准 = **当日开盘价、每天重置、跨日无记忆**（execute_day 内 buy_done/sell_done 每日新建）：
  - 股票阴跌：T 日开盘 10 元 → 买 2 格（9.85/9.70）；T+1 日开盘 9.8 元 → **重新以 9.8 为基准再买 2 格**；T+2 开盘 9.6 → 再买……**永远在"当日低点附近买入"，永远等不到反弹回成本**。
  - 卖格（open+0.5σ/1.0σ）只对**当日日内反弹**有效；阴跌股日内反弹稀少 → 买:卖 = 4.1:1。
- 这直接解释了 -43% 的主机制：**持仓不断堆积、现金不断消耗、价格不回头**。

### 🔴 根因 2（策略-市场错配）：低波动因子选出的股票恰是"网格最不擅长"的
- 目标池 90% 是银行/电力/公用事业（601229/600900/601398/601988…），2022-2025 年 A 股这些股票是**慢熊阴跌**（银行息差收窄、防御股无弹性）。
- 网格盈利前提 = **震荡市**（价格在区间往返）；低波动选股的前提 = **持有**（少回撤、长期复利）。**用低波动选股做网格 = 选了"最不震荡"的股票做网格**，逻辑错配。
- 低波股日波动 ~1-1.5%，0.5σ 网格宽度 ≈ 0.5-0.75% 价差，单格利润薄，扣除双边成本（佣金 0.03%+印花税 0.05%+过户费）后所剩无几。

### 🔴 根因 3：无趋势过滤（网格策略业界标配保险丝缺失）
- 业界网格策略必须配"趋势闸门"：趋势向下（跌破 MA20/ADX>25 等）→ **停止买入网格、只卖不买**，甚至清仓等待。
- 本实现完全无此机制：单边下行（2022-08~10、2024-01 -9.5%、2024-06 -8.1%）期间网格照常"每日买 2 格" → 净值逐月下台阶。

### 🟡 根因 4：预警清仓过频 + 换仓成本
- `vol_alert_mult=1.5 × 目标池中位波动`：低波股波动中位数极低 → 日常噪声即触发（pool=200 三年 766 个触发日、日均 3.2 只清仓；pool=2000 日均 7.7 只）。
- 每次预警 = 清仓（卖）+ 补仓（买）2 笔 + 印花税/佣金；9,233 单粗算成本 ~600-800 万（占初始资金 6-8%），叠加"卖在低点再买另一个低波股"的追跌循环。
- **pool=2000 更差的原因**：候选池大 → 混入更多"低波动但无弹性"的深市低价股 → 波动中位数更低 → 预警阈值更易触发（日均 7.7 只）→ 换手与追跌更严重 → 5 个月 -19%。

### 🟡 根因 5：网格仓位无上限（满格停机缺失）
- 每只股票网格买入无"总格数上限"：持续下跌中每天买 2 格，10 只股票可无限吸现金至满仓 → 与根因 1 叠加放大。

## 三、改进方案（业界最佳实践，按优先级）

### P0（必改，直接消灭"只买不卖"）
1. **网格基准固定化（跨日网格）**：基准价 = 首次建仓价（或最近一次"卖出归位"价），价格回到基准以上触发卖出；**每格"一买一卖配对"**（买 1 格后，只有该格卖出才恢复买入资格）→ 恢复经典网格的"区间往返"盈利机制。可保留日内多次触发的优化（同一格日内先买后卖也算配对）。
2. **趋势闸门**：价格 < MA20（或 MA60）→ 网格**只卖不买**；趋势转多才恢复买入。单边下行市彻底止血。

### P1（强烈建议）
3. **网格宽度加宽**：`grid_width_sigma 0.5 → 1.0~1.5`（或绝对价格 2~3%），保证单格毛利润 ≥ 双边成本 5~10 倍（当前 0.75% vs 成本 ~0.17%，余量不足）。
4. **每只持仓网格仓位上限**：每只最多 5 格等分预算，买满停机（不再加仓），只有卖出配对后释放额度。
5. **预警升级**：`vol_alert_mult 1.5 → 2.0`，且改为**连续 N 日（如 3 日）突破才清仓**（滞后确认，滤除噪声）；或改用"跌破 MA20 且波动率跳升"复合条件。

### P2（可选，方向性）
6. **候选池加"震荡/流动性"筛选**：低波动 + 高流动性 + 温和震荡（如 20 日振幅分位数中段）——若坚持网格路线，选"能震荡"的低波股；或
7. **策略路线重估**：低波动因子本质适合"持有型"（等权低波月度调仓，无网格），网格与低波因子结合本身就是错配——可回测"纯低波持有"作为对照基准。

## 四、验证建议

- 修复后先跑 2022-08~2025-05 完整回测，**对照三指标**：① 买:卖格比应回到 ~1:1；② 预警触发频率降 50%+；③ 净值回撤显著收敛。
- 与"等权低波纯持有（无网格）"基准对比，衡量**网格的增量价值**（业界惯例：网格价值 = 网格收益 − 纯持有收益，通常用振荡池验证）。
