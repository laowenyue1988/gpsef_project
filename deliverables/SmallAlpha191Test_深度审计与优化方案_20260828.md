## 1. 绩效事实（分析者视角）

- **最大回撤 -15.97%（2023-11-20 → 2024-06-06，132 交易日）**：不是单日暴跌，是 6 个月阴跌期累计（2024-01 -9.13%、2024-05 -3.86%），区间仓位均值仅 35.7%

### 1.2 模型链路事实

- 训练：240 天窗口 / 72,000 样本（正样本 43,387 = 60.3%，**正样本占比显著高于随机**——因为 staged_binary 标签在微盘高波动下 PT/SL 命中率高）
- 特征：302 原始 → 163 入 CV → **MDA 投票后每期保留 8~22 个**（折内 train 21900/19200 样本）
- 超参：每期 HP-Search 4 候选 × 3 窗 walk-forward，选中 c1~c4 轮换（depth 3~6）
- 预测力：折集成 AUC **0.50~0.58**（均值 ~0.55）；train AUC 0.7033 vs 折集成 OOS AUC 0.5433（**差值 0.16 = 明显过拟合**）
- 门控：AUC 门控 0.52 大部分通过；16:51 期 CV 集成 0.5143 警告但折集成 0.5606 通过（**门控口径不统一，见 §5 质疑 4**）
- 集成：5 折按 fold AUC 加权（w 0.095~0.30）

## 2. 机制解剖：41.6% 仓位的真相（分析者视角）

### 2.1 仓位时间线（2024-01 实证）

```
2024-01-02: 现金 841,160 / 总资产 1,309,481 = 64% 现金（仓位 36%）
2024-01-08: 现金 1,003,475（77%）
2024-01-19: 现金 1,144,662（90%）
2024-01-22: 调仓日 → 满仓 20 只 × 5%（1/22 建仓日志确认）
2024-02-01: 现金 1,136,920 / 总资产 1,192,381 = **96% 现金**（20 只名义持仓仅 4.6% 市值）
2024-02-05(微盘危机): 总资产仅 -0.4% 波动
2024-03-20: 持仓 0、现金 100%（S4 到期/止损全部退出）
2024-03-26: 调仓日重新满仓
```

**机制链条**：
1. 调仓日满仓 20 只（每只 5%，prob 加权）
2. 20 天窗口内分阶段退出高频触发——S1 阈值 2σ（微盘日波动 3-5% → 2σ ≈ 6-10% 价格幅度），20 天内触及概率 ≈ 1-(1-0.317)^20 ≈ **99.9%**，S1 几乎"必然触发"
3. 每次 S1/S2/S3/S4 卖出释放现金；`reinvest_enabled=false` → **现金闲置**至下次调仓（最长 20 天）
4. 平均仓位 = (满仓后指数衰减的积分)/窗口 ≈ **41.6%**

### 2.2 这不是"主动风控"，是"被动现金堆积"

- 没有任何仓位控制系统在起作用（garch_control.enabled=false、barra.enabled=false、tech_filter.enabled=false、V10 gate 禁用）
- 41.6% 纯粹是"分阶段退出卖出 + 现金不投资"的算术结果
- **数学意义**：如果仓位从 41.6% 线性提到 80%（保持同样的单位仓位收益率），总收益约为 105% × (0.80/0.416) ≈ **+202%**（年化 ~34%）——当然波动与回撤同步放大

### 2.3 2024-02 保护 = 该模式的意外红利（辩证：是好是坏？）

- 1 月频繁止盈 → 2/1 现金 96% → 微盘危机几乎无损（-0.4% vs 微盘指数 -20%+）
- **这是"低仓位被动保护"的正面案例**：分阶段退出在暴跌前已经自然降仓
- 但**这不是设计出来的**——是"过早止盈 + 不投资"的副作用。它保护了组合，也浪费了 1 月下旬到 2 月的反弹机会（1/22 满仓后 1/23-1/31 还在涨时被 S1 止盈出局）

## 3. 优势与代价的辩证（审核者视角）

### 3.1 策略的五个真实优势（为什么 Sharpe 1.42 不是幻觉）

1. **标签-交易同规则（L1 staged_binary）**：`simulate_staged_path` 与 `_check_staged_minute` 同语义（10 路径零差异验证）——消除业界最常见的"标签用 A 规则、交易用 B 规则"的评估-部署错位，这是可复现 alpha 的基础
2. **分阶段退出的"截断"在微盘高波动下是有效的**：止损 2373 次把单笔损失限制在 σ 倍数内；hard_sl -6σ 兜底黑天鹅；回撤 -15.97% vs 微盘风格的 -27%~-40%（对比 grid_lowvol smallcap 回撤）——风控结构有效
3. **低信噪比下的保守建模**：S 档浅树（depth 4）+ 强正则（l2=2.0, mcw=25）+ 每期仅 8-22 特征 + 5 折 Purged CV（embargo 21 天）——符合 Prado（AFML §7.4）对重叠标签的处理标准
4. **Meta-labeling 概率排序**（López de Prado AFML §3.6 思想）：不用硬阈值，概率排序取 Top20——AUC 0.55 的弱模型也能通过排序产生有效分层（top20 vs 池内平均的区分）
5. **超参选择的隔离设计**：选择只接触剔除生产 val 后的训练段（消除选择偏倚）、多窗 expanding walk-forward——这是业界（Bergmeir 2018）认可的做法

### 3.2 五个结构性代价（建议者视角的靶子）

| 代价 | 量化证据 | 机会成本 |
|---|---|---|
| C1 仓位 41.6% | 分年度 36-46%，从未超 50% | 满仓收益约为 2.4 倍 |
| C2 S1 过早止盈截断利润 | S1 止盈 1098 次（每次卖 25%），S4 止盈仅 95 次 | 大量右尾利润在 2σ 被截断；微盘 2σ≈6-10% 太紧 |
| C3 高频换手成本 | 订单 5018，佣金+税 ≈ 7.5 万 ≈ 0.75%/年（初始 100 万） | 每笔交易成本 ~0.13%×2，S1 高频触发放大 |
| C4 2024-01 满仓接盘 | 1/22 调仓满仓 → 1/23-1/31 微盘继续下跌 -9.13% | 调仓日无任何趋势过滤 |
| C5 模型过拟合差 | train 0.70 vs OOS 0.54（0.16 差距） | 每期特征/超参在 0.52-0.58 间波动，稳健性存疑 |

### 3.3 辩证总结

> **审核者第一判断**：这个策略的 Sharpe 1.42 是"低仓位 + 高频截断"买来的——它的风险（2024-02 危机）确实被机制吸收了，但代价是收益折半。**优化不是推翻它，而是把"被动低仓位"升级为"条件化仓位"**：正常市况提仓位吃收益，危机市况自动降仓保本。任何"无脑 reinvest=true"或"无脑满仓"都会破坏 2024-02 的保护——这是第一条不可逾越的红线。

## 4. 优化方案（建议者视角，按证据强度排序）

### P0-1：分阶段退出释放现金的"条件化再投资"（最大机会，需谨慎设计）

**现状**：`reinvest_enabled=false`（历史原因：①无日志不可观测 ②分散后 <5000 阈值几乎不执行 ③逻辑矛盾——减仓锁利后又加仓同一只）

**方案**：
- `reinvest_enabled=true` + **目标限定为"候选池内、当前未持仓、且 prob 排名 ≥ 池内中位"的股票**（解决矛盾 ③：绝不加回刚卖出的股票；解决 ②：候选池 300 只中有足够标的）
- 再投资规模 = 释放现金的 **50%（半额再投资）**，保留 50% 现金作为"危机缓冲"——在仓位提升与 2024-02 保护之间取中间态
- 记录 reinvest 交易日志（解决 ①）

**数学论证**：
- 释放现金估算：分阶段卖出 ~3233 笔、合计金额 ~5000 万（orders 中 stage 卖出合计），平均每窗口释放 40-60% 仓位现金
- 半额再投资 → 平均仓位 41.6% → **预计 60-65%**
- 若单位仓位收益率不变，总收益 105% → 约 105×(0.625/0.416) ≈ **+158%**（年化 ~29%）
- 风险：2024-02 时仓位从 4.6% → 约 50%（半额再投资后），危机损失 ≈ 20%×50% = -10%（可接受，因 2 月微盘危机 20 个交易日后 V 反，被再投资仓位吃到反弹）

**审核者质疑**：半额再投资在 V 反市（2024-02、2025-01）会吃到反弹（好），但在阴跌市（2023-11~2024-06）会加仓接刀（坏）——**必须配 P0-2 的趋势闸门**（见下），否则 C4 类损失放大。

### P0-2：S1 阈值 2σ→2.5σ + S2 3σ→3.5σ（减少过早止盈）

**现状证据**：S1 触发 1746 次（止盈 1098/止损 648），20 天窗口 P(≥2σ)≈99.9% → S1 是"必然事件"而非"信号"
**数学论证**：
- 微盘日波动 σ≈3-4%（EWMA 0.94），2σ ≈ 6-8% 价格波动——微盘股 5 天内 6-8% 波动是常态 → S1 高频触发截断正常波动
- 提至 2.5σ：P(≥2.5σ in 5d) ≈ 1-(1-0.0124)^5 ≈ 6%——S1 变成"有选择性的止盈信号"
- 效果：减少 S1 触发 ~60-70%，持仓更久，右尾利润保留
**经济学依据**：微盘股短期动量强（A 股 2024-09 后微盘指数 +50%），过早止盈 = 系统性卖出动量赢家；分阶段退出的"保留长尾"设计（S3/S4 留 40%→20% 仓位）在 2σ 高频触发下从未真正生效（S4 止盈仅 95 次 = 长尾从未被捕获）

**审核者质疑**：S1 阈值提高 → 止损触发也减少 → 单笔亏损可能加大（-2.5σ 才止损 ≈ -8-10%）。但硬兜底 -6σ 仍在，且组合层面止损纪律由 staged 框架保证。**需要 A/B 验证止损分布变化**。

### P0-3：调仓日指数趋势闸门（治理 C4：满仓接盘）

**现状证据**：2024-01 -9.13%（1/22 满仓后 1 月微盘继续跌）；2023-11~2024-06 最大回撤区间
**方案**：调仓日检查微盘代表指数（如中证2000 sh.000852）收盘 < MA20 → 建仓减半（10 只）或推迟；恢复条件 = 指数 ≥ MA20
**依据**：A 股微盘的趋势自相关显著（2024-01 单月 -20%、2024-02 V 反）；20 天调仓窗口内满仓接刀是回撤主要来源
**注意（grid_lowvol 教训）**：趋势闸门易长期锁仓（TREND_DOWN 数月空仓）——本方案只作用于"调仓日建仓规模"而非"持仓中强制清仓"，锁仓成本可控

### P1-1：门控口径统一 + 阈值收紧（治理 C5）

**现状问题**：AUC 门控 0.52 基于"折集成加权 AUC"（一次 CV 集成 0.5143 警告但折集成 0.5606 通过——两个口径并存）
**方案**：
- 门控统一用**折内 OOS AUC 均值**（更保守、无加权扰动）
- 阈值 0.52 → 0.54（当前 46 期 AUC 0.50-0.58，0.54 以下约 1/3 期触发降仓）
- IC 门控（staged_rank 用）保持 0.02
**审核者质疑**：阈值 0.54 会更多期空仓/降仓（牺牲 2025 牛市收益？2025 各期 AUC 若均 >0.54 则无影响）——需统计各期 AUC 与后续收益的关系，避免"过拟合门控"

### P1-2：特征/模型过拟合收窄

- train 0.70 vs OOS 0.54：gap 0.16。选项：①HP-Search 的 eval_rounds 600→400 ②c3/c4 候选（depth 5-6）在低 AUC 期禁用 ③特征投票 vote_min_folds 3→4（更严）
- **审慎**：O1+ 曾因统计不显著被否决——特征层面的微调预期边际收益小，**优先级低于 P0**

### P2-1：风格分散（微盘集中度）

- 现状：100% 微盘 300 池，BARRA/tech_filter 全关——风格单一（2024-02 危机、2025 牛市都是风格事件）
- 方案：候选池 = 微盘 300 ∪ 全市场低波动 200（双风格，20 只持仓 = 12 微盘 + 8 低波）——但**改变选股池是结构性改动，需独立回测验证，不与 P0 混合**

## 5. 审核者最终质疑（对方案自身的批判）

**质疑 1：提高仓位会不会毁了 Sharpe 1.42？**
- 回应：Sharpe = (r_p - r_f)/σ_p。提仓位同时放大收益与波动，**Sharpe 不必然提升**。本方案（半额再投资 + S1 放宽）的目标是"提升绝对收益、保持 Sharpe"，预期 Sharpe 1.4±0.1。**若回测 Sharpe <1.35，回退半额再投资为 30%**——参数化回退机制。

**质疑 2：P0-1 与 P0-2 的方向是否冲突？**
- 回应：不冲突。P0-1 提升资金利用（持仓时间更长），P0-2 提升单笔利润（右尾保留）——两者都减少"无效交易"，方向一致。但**P0-1 单独上会放大接刀风险，P0-2 单独上会提升仓位留存时间同样放大风险**——两者必须与 P0-3（趋势闸门）捆绑为一个完整方案 A。

**质疑 3：2024-02 保护会不会消失？**
- 回应：半额再投资后仓位峰值 60-65%，但**分阶段退出仍会在暴跌初期触发 S1-S4 快速降仓**（跌 2σ 触发止损卖出 25%/35%/20%…）——保护机制仍在，只是起点仓位更高。2024-02 的 -0.4% 会变为约 -8~-12%（可接受，且 V 反被吃到）。
- **若用户对 -8~-12% 不可接受**：提供保守版（再投资 30% + S1 维持 2σ），预期仓位 50%、2024-02 损失 -5~-8%。

**质疑 4：门控口径与 AUC 0.50-0.58 的低信噪比下，模型是否真的在选股？**
- 证据：候选池 300 只 prob 区间 0.50~0.69（max-min ~0.19）——区分度存在但窄；Top20 与池内均值差异 ~0.03-0.05 prob。结合 46 次调仓全部建满、年化 21.7% 的实现——排序有效。但**窄 prob 区间说明模型对尾部事件不敏感，2024-02 类极端依赖的是退出机制而非选股**——这印证了"退出机制是本策略的 alpha 主体，选股是辅助"的结论。

**质疑 5：样本量/过拟合的统计可靠性**
- 46 次调仓、920 持仓、5308 次退出——样本量充足；但每期模型只在 8-22 特征上训练，特征集每期变化（17/22/19/10/8 轮换）——**特征集不稳定的背后可能是因子有效性轮动**，建议输出各期特征选择清单（cfi_importance 已有诊断数据）做因子轮动分析（P3 洞察性工作）。

# 调仓趋势闸门（新增）

  enabled: true
  index_code: sh.000852         # 中证2000（微盘代表）
  ma: 20
  half_position: true           # 指数<MA20 → 建仓减半（10 只）
# 门控收紧
