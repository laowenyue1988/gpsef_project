3. **执行价格序列用固定复权基准日（回测结束日）** ⇒ 收益率不受影响（常数缩放），但 `price_min:3` / `amount_pct:0.1` / 整手取整等**绝对水平判据**存在轻微选池扭曲（D-238）。
4. **退市股（双口径，D-237 + D-244）**：**时点口径** —— 选池/建仓当日**无**已退市/ST/停牌股（实测 **0/0/0**，双重方法核验）⇒ 引擎干净；**跨期口径** —— **主动纳入**"后来退市"股（池 29 只 / 池-日 0.61%；持仓 7 只 / 持仓-日 1.02%）⇒ 抗幸存者偏差正确做法。**"持仓延续到退市日" 0 笔**（最早退市前 311 天清仓）⇒ **退市平价了结的虚假收益未发生**；Q5I-5 降级为"时序合规复核"。
5. **同一回测区间共跑过 30 次全窗回测（Test3）**，累计 511 个臂 ⇒ **多重比较/选择偏差客观存在**；缓解 = 预注册判据 + "不劣于锚点"门槛 + R-111 平台带禁微调 + 负面结论留档 + 置信区间纪律。
6. **D-225 同源性**：标签屏障 ≡ 交易出场 ⇒ **出场参数不可与选股/模型分离**（Jaccard 0.31~0.38）；Q4b 解耦实验**已作废**。
7. **CI 含 0 的对比**只能表述为"在当前样本与方法下不可辨识"；区块重抽打断路径依赖 ⇒ CI 是**保守上界**。
8. **Q5C-1b 结案**：BARRA 轴**已被否定**（W1/W2/W4 FAIL，16/16 CI 含 0），**且是在混淆已部分解开的条件下**（λ_l2 0.3→1.5 确有透传）⇒ 否定的是**机制价值**，不只是路径。
9. **基准口径（D-240）**：绩效主基准 = **沪深300**，**不变更**；`baseline_index_code` 是 **BARRA 风险模型基线档位**，**非绩效对照**，且**已结案**。⇒ **沪深300 主基准下的超额/α 含"微盘因子风险溢价"，不可解读为"选股 α"**；且**基准为价格指数（不含分红）** ⇒ 超额被系统性高估约等于指数股息率（~2~3%/年）。**同域对照只作诊断口径。**
10. **★门槛未达 ≠ 机制有害（D-242 立）**：`|MaxDD|` 越 D-174 门只说明"不符合上线条件"，**不得表述为"该机制被否决 / 无效"**；负向结论必须写明"否定的是路径、还是机制价值"。
11. **★σ 反解已获决定性实证（D-241）**：标签 = 障碍倍数 × 入场日 EWMA 波动率；**8 个出场档反解 σ 均值 1.861%（极差 1.592%~2.044%）vs 日线独立直算 1.942%（两法之比 1.0435）** ⇒ **0.3 的 IC 中约 62% 为波动率可预测性**（详见 §2.13 / D-241）。
12. **尚未接入 Wyckoff 层** ⇒ 全部"191 贡献"结论均为**该池 + 该出场包条件下**的结论，**不可外推到完整两层架构**。

## 7. 运维与纪律（防事故）

### 7.1 进程与内存

| 纪律 | 内容 |
|---|---|
| **单一执行者** | 同一批次只允许**一个执行者**（监督器/启动器）；自动化与其它角色**只读监控 + 分析 + 通知** |
| **全局并发臂 ≤ 3** | 判据 = `results/*/backtest.log` mtime 龄 <300s 且无 `report.json` 的目录数（**排除归档目录**）|
| **内存判据** | **只看「提交余量」**：>10GB 安全；<15GB ⇒ 降 2 臂；<8GB ⇒ 降 1 臂并告警（`ullAvailPhys` **偏乐观，不得单独作依据**）|
| **长驻唯一形态** | **受管后台任务 + `2>&1 \| tee`**，父进程全程存活；**不再尝试任何"脱离"手段** |
| **判活/判完成** | **一律产物信号**（`report.json` / `backtest.log` mtime / 批次日志）+ **起臂后初始化宽限 1500s**；**禁用 PID，也禁用返回码**（`os.execvp` 自我重执行）|
| **判死** | 必须 `tasklist` + 产物信号**多证据交叉** |

### 7.2 实验版本管理三闸门（R-130，`_exp_version.py`）

| 闸门 | 时机 | 拒绝条件 |
|---|---|---|
| `preflight` | **起臂前** | 版本漂移未声明；**已有臂在跑且源码 mtime 晚于该臂起臂时刻** |
| `guard-edit` | **改源码前** | 存在在跑臂（已内置 `_apply_q5n_patch.py`）|
| `audit` | **落臂后 / 读数前** | `provenance` 中途改码 / R-127 四类错误 / 零持仓轮 / 无调仓 ⇒ 判 `VALID/INVALID/INCOMPLETE/RUNNING`，**INVALID 禁止进判据** |

- **登记表**：`_exp_registry.json`（机器）+ `deliverables/EXPERIMENTS.md`（人读）
- **冻结基线**：`_exp_frozen.json`｜`labels.py` `d10de39112025cbe`｜`strategy.py` `816cb66cff028e60`｜`ensemble.py` `062f45a18d4453af`｜`target_transforms.py` `0db37b72f8581b87`；断言 **135/135**

### 7.3 每次实验后的标准动作（**流程硬约束**）

```
落臂 → ① audit（版本/健康）→ ② 深度分析（R-105 + 分段归因 + 交易层）
     → ③ 三件套裁决（分析 + 路线全盘对账 + 裁决，写明否定路径 or 机制）
     → ④ 同步 MEMORY + deliverables → ⑤ 才进入下一阶段
```

**未出三件套不得进入下一阶段。**

### 7.4 外部质询处置（R-133）

**凡外部质询（同行 / 评审 / 朋友），必须先做零算力事实核对（代码 + 配置 + 已有产物）再答复**；答复中凡方向性判断须附**代码位置或实测数字**；**事实有误处须明确纠正（含对我方有利的纠正）**。
