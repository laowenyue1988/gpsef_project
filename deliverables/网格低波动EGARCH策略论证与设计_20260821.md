# 网格 × 低波动 EGARCH 量化交易策略：论证、设计与审核

**基本思路**（用户）：EGARCH 每日盘前预测全市场波动率 → 选未来波动率最低的 N=10 只等权建仓 → 持仓期间每只划分 5 个网格、按 5 分钟线日内网格交易 → 预测到某股波动率超边界（单边行情）→ 开盘清仓并补入波动率最低的新股。
**要求**：业界最佳实践补细节、完整策略、性能、严格无未来、完整目录、审核评估。
**日期**: 2026-08-21 | **状态**: 论证 + 已实现可运行（strategies/grid_lowvol/）

## 一、设计论证（按业界最佳实践展开）

### 1.1 为什么 EGARCH（波动率预测模型选择）

| 模型 | 非对称(杠杆效应) | 长记忆 | 参数估计成本 | 判定 |
|---|---|---|---|---|
| EWMA/RiskMetrics | ✗ | ✗ | 零（无参数） | 基准，太粗 |
| GARCH(1,1) | ✗ | ✓ | 低 | 可作初值 |
| **EGARCH(1,1)** | **✓**（γ 项捕捉"利空推升波动"）| ✓（β）| 中 | **✅ 选定** |
| GJR-GARCH | ✓ | ✓ | 中 | 等价备选 |
| 随机波动率(SV) | ✓ | ✓ | 高（MCMC）| 性能不可行 |

**EGARCH(1,1) 方程**（Nelson 1991）：
$$\ln\sigma_t^2 = \omega + \alpha\big(|z_{t-1}| - \sqrt{2/\pi}\big) + \gamma\, z_{t-1} + \beta \ln\sigma_{t-1}^2,\qquad z_t = r_t/\sigma_t$$
- $\gamma<0$ 表示"负收益（利空）比正收益更推升波动"——A 股下跌市波动率集聚的实证特征；
- **h 步预测**（对未来 $\sigma_{t+1..t+h}$ 的累计）：$\mathbb{E}[\ln\sigma_{t+k}^2]=\omega+\beta\,\mathbb{E}[\ln\sigma_{t+k-1}^2]$（长记忆近似，$k=1..h$），日方差 $\sigma_{t+k}^2=\exp(\cdot)$，**预测累计波动 $\hat\Sigma_{t+1..t+h}=\sqrt{\sum_{k=1}^{h}\sigma_{t+k}^2}$**——这是选股排序的直接输入；
- **估计**：正态 MLE（$z_t\sim N(0,1)$），负对数似然 $\ell=\frac12\sum_t(\ln\sigma_t^2 + z_t^2)$，`scipy.optimize.minimize(L-BFGS-B)`，参数约束 $\beta\in(0.9,0.999)$（平稳性）、$\alpha,\gamma\in(-0.2,0.2)$、$\omega$ 自由；初值由 RV20 与 GARCH 矩估计给出。

### 1.2 全市场性能优化（关键工程决策）

全市场 ~5400 只逐只 MLE 估计 EGARCH 每日一次**不可行**（~5000 × 50ms ≈ 4 分钟/日）。业界两阶段方案：

```
阶段1 已实现波动率初筛 (全市场, 向量化 <1s)
  RV20 = std(r_t..r_{t-19}) × √252  (复权收盘日收益率)
  取 RV20 最低的 K=200 只 → 候选池  (低波动效应的粗过滤, 与低波动因子族同逻辑)
阶段2 EGARCH 精细预测 (仅候选池 200 只, ~5-10s/日)
  对候选逐只 EGARCH(1,1) MLE → 预测未来 h 日累计波动 → 排序取最低 N=10
```

- 两阶段在统计上安全：RV20 与 EGARCH 预测高度正相关（都是"近期波动"的度量），用 RV 做粗筛**不会漏掉** EGARCH 意义上的低波动股（单调关系 + 保守 K=200 ≫ N=10）；
- 候选池每日重算（动态），非静态名单——保持全市场视野；
- **性能预算**：EGARCH 200 只 × ~30ms = **6s/日**；900 日回测 ≈ 1.5h（可接受，且 EGARCH 段可多进程并行——本项目回测强制单线程确定性，故单进程）。

### 1.3 低波动选股的经济学逻辑

与低波动因子族一致（散户追高波动彩票型股票 + 机构排名压力 → 低波动溢价，Ang et al. 2006；A 股实证强于美股）。网格策略叠加低波动选股是经典组合（红利低波 × 网格的机构实践：低波动标的日内波动小、趋势稳定，**网格成交胜率高、滑点小、单边突破概率低**——正好规避网格策略的致命弱点"单边行情击穿网格"）。

### 1.4 网格交易设计（业界最佳实践细化）

**核心参数**（全部入 config）：

| 参数 | 默认 | 依据 |
|---|---|---|
| `grid_levels` | 5 | 用户指定（5 个网格）|
| `grid_width_sigma` | 0.5 | 每格宽度 = 0.5 × EGARCH 预测日σ（σ 自适应：波动率高的股票网格宽、触发少；低的窄、触发密）|
| `grid_band_sigma` | 2.0 | 网格上下界 = 开盘价 ± 2σ（超出视为单边行情——盘前预警已处理，日内再触发则止损出局）|
| `grid_base_price` | open | 网格基准价 = 当日开盘价（日内网格以开盘价为锚，符合 A 股交易习惯）|
| `grid_sell_signal` | high≥上沿线 | 5 分钟 K 线 high ≥ 网格上沿 → 卖出 1 格（底仓）|
| `grid_buy_signal` | low≤下沿线 | 5 分钟 K 线 low ≤ 网格下沿 → 买入 1 格（T+1 锁定次日）|
| `per_grid_fraction` | 1/5 | 每格资金 = 组合资产 × 1/5 × 分配比例 |

**资金与仓位模型**：
- 组合等权分配 N=10 只，每只预算 = 总资产 / N；
- 每只内部：**底仓**（昨日收盘持有的份额，网格卖盘来源）+ 当日网格买入（T+1 锁定，次日并入底仓）；
- 5 格仓位：上 2 格（卖出区，底仓分 2 份依次卖）、下 2 格（买入区，现金分 2 份依次买）、基准格（开盘建仓区）；
- 具体：开盘价建 1 格底仓（总预算 1/5），价格上涨 1 格 → 卖 1 格（底仓减少），下跌 1 格 → 买 1 格；上下各 2 格触发。

**T+1 制度约束**（框架自动执行）：当日买入份额 `buy_date=当日` → broker 拒绝当日卖出；网格卖盘只能用"昨日及以前"的底仓——设计已内嵌此约束，回测与实盘一致。

**触发执行**：5 分钟 K 线按时间顺序处理；每根 K 线内：`high ≥ 上沿线` → 卖出（成交价 = 网格线价，`exec_price_override` + `apply_slippage=False`，因为网格价已是保守触发价）；`low ≤ 下沿线` → 买入（成交价 = 网格线价）；**一根 K 线同一格最多触发一次**（避免高频假触发）；先处理卖出再处理买入（避免同格同 K 线双向）。

### 1.5 波动率预警换仓（单边行情保护）

每日盘前 EGARCH 预测后：
- 对**持仓股**：预测波动 $\hat\sigma_{t+1..t+h}$ > `vol_alert_mult × 目标池中位波动`（默认 1.5 倍）→ 标记"预警清仓"；
- 开盘：以开盘价清仓预警股（`order_value(0, exec_price_override=开盘价)`），同时按"补仓数 = 清仓数"从目标池（最低波动、不在持仓）等权买入；
- 目的：**在单边行情启动前离场**——网格策略的最大风险是"震荡假设失效"，波动率预警是网格的保险丝（波动率大幅抬升 = 网格假设失效的信号，先于价格单边确认）。

### 2.1 核心数据流（每日）

```
before_market_open (T 日盘前, 用 ≤T-1 信息)
  ├─ RV20 全市场初筛 → 候选池 200
  ├─ 候选池逐只 EGARCH(1,1) → 预测未来 h 日累计波动 → 排序 → 目标池 top10
  ├─ 持仓股预警检查 (预测波动 > 1.5×目标池中位) → 清仓清单 + 补仓清单
  └─ 生成当日计划: {清仓: [...], 补仓: [...], 目标池: [...]}

handle_bar (T 日开盘)
  ├─ 换仓执行: 开盘清仓预警股 → 开盘买入补仓股 (等权)
  ├─ 网格初始化: 每只持仓 = 开盘价 + EGARCH σ → 5 格网格线
  └─ 日内网格: 逐根 5 分钟 K 线 (时间序) → 触发则 order_value(网格价)
```

## 三、审核评估（业界最佳实践自查，2026-08-21）

### 3.1 通过项（✅）

### 3.2 已修正的潜在问题（❌→✅，在实现中落地）

| # | 潜在问题 | 修正措施 |
|---|---|---|
| P1 | 全市场 EGARCH 每日 MLE 性能不可行 | 两阶段：RV20 向量化初筛（K=200）→ 候选池 EGARCH（§1.2）|
| P2 | 网格宽度固定则波动率不同的股票触发频率失衡 | 网格宽度 = EGARCH 预测 σ 自适应（`grid_width_sigma=0.5σ`）|
| P3 | 单边行情击穿网格（网格策略致命弱点）| 盘前波动率预警清仓（1.5× 中位）+ 日内 ±2σ 边界止损 |
| P4 | 当日网格买入当日卖出违反 T+1 | 依赖 broker 自动 buy_date 检查；网格卖盘仅底仓（§1.4）+ 策略层今日买入量锁定 |
| P5 | 5 分钟 K 线内多次触发（假高频）| 每根 K 线每格最多触发一次；先卖后买（§1.4）|
| P6 | EGARCH 估计不收敛/边界解 | L-BFGS-B + 参数箱约束 + RV 初值 + 失败回退 RV 排名 |
| P7 | 停牌/无分钟线股票的网格挂起 | 无 5 分钟数据 → 跳过网格（仅持仓）；持仓缺失数据 → 不开新仓 |
| P8 | 预测期 h 与换仓周期不一致 | `vol_horizon_days`（默认 20）即"未来一段时间"，与预警/调仓一致 |
| P9 | **初始建仓缺失（实测发现）** | 首版仅在"预警清仓后补仓"建仓，持仓为空时永不建仓 → 修正为"空位补足 top_n + 预警补仓"合并逻辑（冒烟实测 0 订单 → 修复后 1525 单）|
| P10 | 全市场预加载经 data_provider 大缓存 OOM | 改轻量直读（raw_daily 2 列 + 后复权因子手动前复权），5400 只 ~92s、内存 <100MB |
| P11 | EGARCH 纯 Python 循环过慢（1s/只）| numba njit 加速 → ~5ms/只（含首次 JIT 编译）|

### 3.3 已知局限与观察（如实声明）

1. **引擎日级**：网格的日内执行是"回测模拟"（handle_bar 内按 5 分钟 K 线时序逐笔成交），实盘需对接分钟级执行通道（框架无盘中事件循环）；
2. **K 线触发近似**：用 5 分钟 K 线 high/low 判定网格触发是回测标准近似（实盘用实时价，成交可能更早/更晚）；
3. **EGARCH 正态假设**：未用 t 分布（厚尾），对极端行情预测偏保守——作为**排序**输入影响有限，后续可加 t 分布选项；
4. **预警频率观察（冒烟实测）**：2022-08~10 三个月预警清仓 272 次（印花税主源 254 万），`vol_alert_mult=1.5` 对波动率自然波动偏敏感——建议实盘调参时提高至 2.0 或加"连续 N 日超阈值才清仓"滞后（当前为当日一次性判断）；
5. **样本外验证**：冒烟 3 个月 +8.50%（年化 40.9%，Sharpe 0.91）仅为一个熊市反弹区间，需完整区间（2022-08~2026-05）回测 + 与"等权低波动纯持有"基准对比（网格增量价值 = 网格收益 − 纯持有收益）裁决。

### 3.4 冒烟实测结果（2022-08-01 ~ 2022-10-31，60 交易日）

| 指标 | 值 | 说明 |
|---|---|---|
| 总收益 | **+8.50%**（年化 40.9%）| 熊市反弹区间的低波动防御表现 |
| Sharpe | 0.91 | 单区间，非统计显著 |

```bash
cd /e/quant/gpsef_project

```

**关键参数速查**（config.yaml）：`top_n=10`（低波动持仓数）、`candidate_pool=200`（EGARCH 候选池）、`vol_horizon_days=20`（预测周期）、`grid_levels=5`（网格数）、`grid_width_sigma=0.5`（格宽=0.5σ）、`vol_alert_mult=1.5`（预警倍数）。
