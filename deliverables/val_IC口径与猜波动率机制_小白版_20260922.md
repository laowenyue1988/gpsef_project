## 第一部分 · val_IC 到底在算什么（拆到最细）

### 1.1 一句话

**val_IC = "模型给出的分数" 与 "标准答案（标签）" 之间的 Spearman 秩相关系数，而且是把所有日期、所有股票堆成一大张表之后，只算一次。**

### 1.2 逐步拆解（每一层都能在代码里指到）

**第 0 层：什么时候算？**
每 20 个交易日调仓一次，每次调仓前重训一次（`retrain_interval: 1`）⇒ **全程 66 次重训，val_IC 也就被算了 66 次**。

**第 1 层：样本表怎么来？**（日志原文：`合并后数据形状: (72000, 222), 列数: 222`）
- **前 240 个交易日**（`train_window_days: 240`），每个"训练日"取**当天池内的全部候选股**；
- 实测每组的股票数 = **恰好 300 只**（`平均每组 300.0 只`）⇒ 样本 = **240 × 300 = 72,000 行**；
- 列 = 210 个因子（中性化后）＋ 若干元数据 ≈ **222 列**。

**第 2 层：标准答案 y 是什么？**（`strategy.py:3003`）
> `labels_df['bin'] = labels_df.groupby('date')['realized_ret'].rank(pct=True)`

- 对**每个训练日的 300 只股票**，各自**按自己的止盈止损规则模拟走一遍**，得到 `realized_ret`（已实现收益）；
- 然后**在当天这 300 只里排名**，换算成分位 **bin ∈ (0,1]**（1.00 = 当天最好，0.00 = 当天最差）；
- ⇒ **`y` = "这天这只股票在池内的相对表现分位"**，不是收益数值本身，也不是"涨/跌"标签。
- 实测标签形态：`bin mean=0.502`（分位天然均值 0.5）；`realized_ret` 均值 **+0.0055**、中位 **−0.0365**、范围 **[−0.2009, +0.6181]**。

**第 3 层：模型输出 ŷ 是什么？**
- `label_mode = staged_rank` ⇒ **回归任务**（`reg:squarederror`），模型输出的是**分位预测值**（不是概率、不是三分类）；
- 别被日志里的"三分类标签"误导——那是**三重屏障结局标注**（用于样本加权），**不是模型目标**（D-228 三个易混点之一）。

**第 4 层：怎么切训练/验证？**
**Purged K-Fold（5 折）**：按时间切 5 段，每折用其余 4 段训练，在**本折的验证段**上预测；折与折之间有 **21 天 embargo**（`cv_embargo_days: 21`），防标签重叠泄漏。
每折都会得到一份 **OOS（样本外）的 (y_true, ŷ)**。

**第 5 层：IC 到底算几次、怎么聚合？**（`ensemble.py:635-647` + `3003-3006`）

```python
# 评估函数：回归模式 ⇒ 一次 Spearman
def _ic(y_true, y_pred):
    return float(spearmanr(y_true, y_pred)[0])

# 每折：在本折验证段上算一次（折内 pooled）
cv_aucs[i] = _ic(该折的 y_true, 该折的 ŷ)

# 5 折跑完：
self.meta_auc  = Σ w_i · cv_aucs[i]     ← w_i = max(0, IC_i) / Σ max(0, IC_j)   【"折集成 IC"】
self.xgb_val_auc = _ic(concat(5 折的 y), concat(5 折的 ŷ))                       【"全局 pooled IC"】
```

- **`meta_IC`（门控实际用的那个）** = **5 折 IC 的加权平均**，权重 ∝ 该折 IC（IC 越高的折，话语权越大）；
- **`xgb_val_auc`** = 把 5 折的 OOS 样本**拼成一个大数组后再算一次 Spearman**（≈7.2 万行）；
- **两个都叫 "IC"，但口径不同**——这正是 R-116 要区分的地方。

**实测样例（S17b 第一次重训，日志原文）**：
```
CV折集成完成: 5 模型 (5 active), 耗时 3.5s, meta_IC=0.3482
集成权重: [fold1 IC=0.2924 w=0.232, fold2 IC=0.0129 w=0.010, fold3 IC=0.1415 w=0.112,
           fold4 IC=0.4392 w=0.348, fold5 IC=0.3748 w=0.297]
[模型门控] 折集成 meta_IC=0.3482
```
⇒ 可见**折间差异极大**（fold2 只有 0.0129、fold4 到 0.4392），`meta_IC` 是**加权平均**后的值。

**第 6 层：这个数拿去干嘛？**
- **门控**：`meta_IC < ic_gate_threshold(0.02)` ⇒ **空仓**（`strategy.py:3800-3818`；实测采纳包 66/66 次全部放行，IC 在 0.2420~0.3482）；
- **诊断日志**（人看的）；
- **不参与**当次选股排序（选股用的是模型对当天 300 只的预测值）。

### 1.3 所以"谁和谁的相关性"？

| | 是什么 | 取值范围 |
|---|---|---|
| **A 端（y_true）** | **标签 `bin`** = 事件日当天，池内 300 只按"分阶段退出模拟收益 `realized_ret`"排出的**分位** | (0,1] |
| **B 端（y_pred）** | **模型预测的分位值**（回归输出） | 实数（近似 0~1） |
| **相关方式** | **Spearman 秩相关**（只看排序是否一致，不看数值大小） | −1 ~ +1 |
| **样本组织** | **跨日期、跨股票全部堆平**（pooled）；不是"每天单独算再平均" | — |

## 第二部分 · 为什么说这个 0.3 主要是在"猜波动率"

### 2.1 四步讲清楚（承接上一次的讲法，但这次每一句都有实测支撑）

**① 标签是"标准答案"，标准答案 = 让每只股票按自己的止盈止损规则走一遍，看最后赚多少。**
出场线全部是 **σ 的倍数**：止损 −1.8σ / −2.4σ、止盈 +4.5σ / +6.0σ / +9.0σ、硬止损 −6σ。

**② σ 是"尺子"：σ = 这只股票买入前的日常波动（入场日 EWMA 日波动率）。**
用 σ 当尺子，是为了让"稳股"和"妖股"的止损难度相当。
**实测确认这把尺子真的在用**（`_label_vol_test.py`，5,590 笔卖单）：
- 从每笔成交反解 **隐含 σ = 收益 ÷ 该档倍数**，跨 8 个出场档**结果一致**：
  **止损侧中位 2.020% vs 止盈侧中位 1.783%，比值 0.882 ⇒ PASS**（若尺子没在用，两组会差很远）。

**③ 关键一步：止损时亏多少 = 1.8 × 它自己的 σ。**
而**实测每 100 个样本里有 72.6 个是止损出场**：
```
退出分布 = {stop_loss: 52260, profit_take: 10591, expire: 9149}   ⇒ 72.6% / 14.7% / 12.7%
```
> 这不是偶然：随机游走下"先碰 −1.8σ 再碰 +4.5σ"的概率 = 4.5 / (4.5 + 1.8) = **71.4%**，与实测 72.6% 几乎一致 **✓**（因为止损线离得近、止盈线离得远）。

**④ 于是结论出来了**：
对占比 **72.6%** 的那批样本，`realized_ret ≈ −1.8 × σ`（或 −2.4σ）。
⇒ **它们的排名，基本上就是"σ 从大到小"的排名**（σ 越大，亏得越多，排得越靠后）。
⇒ **标签的截面排序，很大程度上是"波动率的排序"。**

**而波动率有一个致命特点：它极易预测。** 波动率有"聚集效应"（今天波动大，明天大概率还大），用过去的价格数据就能相当准地估出来。
⇒ **模型只要学会"把波动率排对序"，IC 就能拿到很高——而它完全不需要预测收益。**

**够不够"排得开"？够。实测 σ 的截面离散度很大**（`_label_vol_test.py`）：
- **CV(σ) = 0.405**｜中位 1.951%｜**P10 = 1.326% / P90 = 2.998%**｜**P90/P10 = 2.26 倍**
⇒ 有充足的排序空间，"猜波动率"能吃到相当大的一块 IC。

### 2.2 量化：这 62% 是怎么算出来的（这一步最关键）

我们做过一个**直接把波动率成分从标签里抽掉**的实验（Q5N 的 N2 臂，目标变换 `fwd_ret_orth` / `orth_vol`）：

| 标签版本 | 滚动样本外 IC |
|---|---|
| **N0｜原始标签**（就是本文第一部分讲的那个 `bin`） | **0.2798** |
| **N2｜把波动率成分正交剥离后的标签** | **0.1050** |

⇒ **1 − 0.1050 / 0.2798 = 62.5%**

**读法**：模型在原始标签上拿到的预测力里，**约 62% 在"把波动率成分抽掉"之后就消失了** ⇒ 这部分**本质是"波动率可预测性"**，不是"收益可预测性"。
（出处：D-236；D-241 用 σ 反解双路交叉 1.861% vs 1.942%、比值 1.0435 进一步确证"标签 = 障碍倍数 × 入场日波动率"。）

### 2.3 ★必须分清的两件"偏高"（否则会把话说反）

| 说法 | 对不对 | 说明 |
|---|---|---|
| **"0.3 的 IC 比业界基准高很多，所以可能是泄漏"** | ❌ **站不住** | ①**口径不同**：我们报的是 **pooled Spearman**，业界学习器上界 0.11~0.15 也是同口径——但 `_ic_caliber_demo.py` 实测 **pooled / 逐日截面 = 0.15 ~ 1.00×**（含日级漂移时低至 **0.15×**）⇒ **我们的 pooled 是"偏低"的读数，真实逐日截面 IC ≥ 0.30**。②**66/66 轮 OOS IC 全为正**、跨折稳定 ⇒ **不是泄漏**。③泄漏另有专门检验（同日标签置换 Q5I-3a）。 |
| **"0.3 的 IC 高得'虚'——它主要衡量的是波动率预测力"** | ✅ **成立** | 依据就是 2.1 + 2.2：**标签本身 ≈ σ 的放大版**（72.6% 走止损），而 σ 极易预测 ⇒ **62% 的 IC 来自"猜波动率"**。 |

**一句话**：**这个 0.3 既不是泄漏、口径上还偏低；但它衡量的东西，大部分不是"选股赚不赚钱"，而是"波动率能不能被排对序"。**

### 2.4 ★与 Q5R 波 1 实测的互证（同一天刚出结果）

这解释了为什么**Q5R 波 1 会出现"收益没差别、只有风险有差别"**：

| | 真实策略 | 最好随机臂 R1 |
|---|---|---|
| 年化 | 15.855% | **15.963%**（≈ 相同） |
| 年化波动 | **13.684%** | 16.424% |
| \|MaxDD\| | **15.124%** | 16.645% |
| 单位敞口年化 | **37.337%** | 32.850% |

**⇒ 两条独立证据指向同一件事**：
**模型的"预测力"（IC 0.3）主要是波动率信息；它在组合上的变现方式是"波动更低、回撤更小、每块钱仓位的效率更高"，而不是"选出更会涨的股票"。**
（这与 D-252「`★Sharpe = 单位敞口年化 / 单位敞口波动`，改善必须来自降分母」完全一致。）

### 2.5 这件事的实际含义（对你）

1. **不要把 IC 0.3 当成"选股 alpha 0.3"来用**——它会把预期收益能力高估（我们已把它排除出采纳判据：P2「IC 不得作采纳依据」）。
2. **判据应该是"IC 的兑现率"**（D-226）：IC 再高，如果变成不了组合收益，就没意义。Q5R 波 1 正是在检验这一点。
3. **如果想真正提高"选股 alpha"**，方向不是"再找更会预测收益的因子"，而是**先把标签里的波动率成分压掉**（这正是 N2/Q5P′ 那条线），否则模型会一直"优先学波动率"。
4. **同时这也解释了为什么"压波动率目标敞口"那条路（Q5D/Q5N-R）反而有害**：波动率在微盘股里与后续收益**正相关**（D-262：池指 Spearman +0.1055、策略自 +0.1639），所以"波动大就减仓"= 系统性卖在反弹前。
