### 7.2 ★小白版四问（D-269 强制）

**① 这段在解决什么问题？**
我们在测一件事：策略选出的 20 只股票，**在它们内部再按"波动越低、买得越多"重新分配仓位**，能不能把整体收益质量（不是收益绝对值）提上去。这个改动叫 `vol_penalty`（波动率惩罚），力度由一个旋钮 `strength` 控制。**跑之前必须先证明一件事：这个旋钮真的拧动了、而且只拧动了它一个东西** —— 否则后面看到任何差异都说不清是谁造成的。

**② 用了什么办法？**
三个实验组，**只改一个旋钮**：`strength = 0.25 / 0.50 / 1.00`（分别对应上限：温和 / 中等 / 纯逆波动率）。三组用**完全相同的股票池、相同的起始日期、相同的随机种子**。
验证手段有三层：
- **行为层**：日志里每次调仓会打一行 `[Q5P′] vol_penalty λ=…`。这一行出现 = 改动生效；不出现 = 没生效（那实验作废）。
- **守恒层**：同一行里有 `Σw 1.0000→1.0000`，`Σw` 是"所有持仓权重加总"。**前后都是 1.0000 = 总仓位没被改动**（改的只是"这 20 只之间谁多一点谁少一点"）。
- **纯净度层（本轮新增）**：同一行里有 `σ_sel中位`。"σ"是波动率（价格上下晃动的剧烈程度），"σ_sel中位" = **选中这 20 只股票的波动率中位数**。如果三组的这个数字**一模一样**，就说明**三组选的是同样的 20 只股票**，旋钮只改了"这 20 只之间怎么分钱"。

**③ 结果是什么？**
- **生效行**：三组各 4 / 5 / 4 行，合计 **13 行**，**异常 0 行、跳过 0 行**。
- **守恒**：**13 / 13 全部 `1.0000→1.0000`**（总仓位一动不动）。
- **纯净度**：**4 轮里，三组的 `σ_sel中位` 逐位完全相同**（1.7974% / 1.9235% / 1.9283% / 1.6317%）⇒ **三组选的是同一批股票**，证实无误。
- **旋钮真的在起作用（剂量-反应）**：看 `max_w`（最大那只股票的权重），**每轮都是 `λ=0.25 的增量 < λ=0.50 < λ=1.00`，4 轮 4/4 严格单调**（例：第 3 轮 +0.0056 < +0.0147 < +0.0363）。`HHI`（集中度指标）同向单调 4/4。
- **所以怎样**：这套实验的"地基"是牢的 —— 生效了、只改了一件事、改动方向和力度都对。**现在可以放心等它跑完 66 轮出结果。**
