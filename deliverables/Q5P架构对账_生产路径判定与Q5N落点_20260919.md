## 1. 直接回答 Q5P 四问

### 问①：V10→meta 路径的可跑性？为何 `v10_gate_enabled=false`、`recommended_by_date` 被置空？

**实测证据链**：

| 证据 | 出处 | 读数 |
|---|---|---|
| E1 `recommended_by_date = {}` 初始化 | `strategy.py:3083` | **被逐日填充**，非「恒空」 |
| E2 填充逻辑 | `strategy.py:3090-3102` | 调 `_get_primary_recommendations_for_date` ⇒ 非空则 `recommended_by_date[sample_date] = daily_recommended` |
| E3 该函数实现 | `strategy.py:1885-1888` ⇒ `_read_v7_snapshot` | **从 `pool_mode` 池取全量股票**，非 V10 推荐 |
| E4 `_read_v7_snapshot` 返回 | `strategy.py:1430-1438` docstring + 各分支 | `return (codes, {})` ⇒ **`pred_dict` 恒为空 dict** |
| E5 `pred_dict` 消费者 | `strategy.py:2464` `v10_has_signal = bool(pred_dict)` ⇒ `False` | `:2494` 打印 `[B5] pred_dict 为空(smallcap 无 V10), v10_pred 常数特征不入特征池` |
| E6 运行时实证 | `backtest.log` × 59 次 | `[R3-1 A2] V10 pred_rank RankIC vs bin = nan`；`v10_pred_raw: min=0.5000, max=0.5000, std=0.0000` |
| E7 `v10_gate_enabled=false` 的作用面 | `strategy.py:3562` | 仅控制**调仓日的「V10 空快照 ⇒ 清仓顺延」闸**，**与 meta 标签路径无关** |

**⇒ 回答**：V10→meta 路径**未「被显式旁路」，而是「V10 信号根本不进入本批次」**：

1. `v10_gate_enabled=false` 关的是**交易时段门控**（选股为空则清仓顺延），**不是** meta 标签输入；
2. `pred_dict` 为空**不是配置开关的结果**，而是 `_read_v7_snapshot` 的**结构性返回**：
   该函数的职责被重定义为「**第一层选股池提供器**」（`pool_mode` 参数化），
   `pred_dict` 作为**兼容位保留但恒空**（docstring 明写「pred_dict: 空 dict (无 V10 pred, 下游 v10_pred_raw 特征中性 0.5)」）；
3. V10 快照数据虽齐备 1236 日（2021-07-01 ~ 2026-08-04），但**当前代码链路没有任何消费者**：
   `recomd_snapshot_dir` 配置项**已注释标注「[Small] 不再使用（微盘池不依赖V10快照）」**。

**⇒ 定性**：这是**架构层的有意替换**（V7 快照器从「V10 推荐读取器」改造为「池构造器」），
而非「已实现但被临时关掉的开关」。**「可跑性」问题不成立** —— 要跑 V10→meta 需**新增**消费者代码，不是「打开开关」。

### 问②：哪条是生产路径？

**判定：`smallcap` 市值池 = 生产路径。**

**三条独立证据**：

| # | 证据 | 读数 |
|---|---|---|
| P1 | 配置显式注释 | `config_exp_*.yaml:21-22`：`recomd_snapshot_dir` = 「[Small] 不再使用（微盘池不依赖V10快照）」；`v10_gate_enabled: false` = 「[Small] V10上游信号门控已禁用（无V10快照依赖）」 |
| P2 | 池由市值决定 | `config:24` `smallcap_pool_size: 300`「微盘池: dynamic_pool候选池中 **T−1 市值最低**的股票数」；`pool_cache_tag: o3_20260910` |

⇒ 元标记的事件集**就是市值池**，V10 与之无关。

**旁证**：`data/smallcap_pool_cache_o3_20260910.parquet`（704KB，mtime 2026-09-13）**实际存在并被使用** ⇒ 池构造链路**活的**。

### 问④：是否需要补 sizing 通道（校准概率 → 仓位函数）？

**判定：不需要。**

**理由（三条）**：

1. **`staged_rank` 是回归/排序目标，不是二分类**。实测标签分布为**连续分位值**：
   `标签数据形状: (72000, 6)` ＋ `标签(分位)统计: mean=0.502 std=0.289 min=0.003 max=1.000`（59 次一致）
   ⇒ 标签取值域 `(0, 1]`，**非 `{0, 1}`**。
2. **无概率 ⇒ 无校准 ⇒ 无 sizing 落点**。Sizing 通道的存在前提是「已校准的二分类概率」；
   排序目标直接输出分位，**经过的是 rank/排序层，不是概率层**。
3. **现有仓位机制已完整**：
   - `barra.enabled=false` ⇒ **等权**（组合层）；
   - `barra.enabled=true` ⇒ `barra_solve(probs)` 优化（组合层）；
   - `garch_position.py` **四级阶梯**（Q5D 排期中）⇒ **position sizing 的等价物已在路线内**。

**⇒ 定性**：Sizing 通道**不是「元标记唯一独有机制」，而是「二分类元标记路径的独有机制」**。
本批次走**排序路径**，该机制**不适用**；且 Q5D 的 garch 阶梯**已覆盖**「仓位随风险调制」这一诉求。

## 2. ★ 对 §7.3 的修正（本对账最重要的发现）

### §7.3 原论断（**已被推翻**）

> 「`strategy.py:3083` `recommended_by_date = {}` ⇒ **空字典** ⇒ `_assign_meta_labels_staged` / `_v2` 均因空字典**回退 legacy 三重屏障标签**。
> 而这两条路径的注释明写：『**Meta 模型学习的是「V10信号在当前环境下是否会盈利」**』」
> ⇒ 结论：「**V10→meta 这条真正的元标记路径，在代码里「已实现、数据齐备，但在当前批次被显式旁路」**。」

### 实测反驳（**两条独立反证**）

**反证 R1 — 日志实证「未回退」**：

| 检查项 | 期望（若回退） | **实测** |
|---|---|---|
| `[L1/L2] recommended_by_date 为空，fallback 到 A1 标签` warning 计数 | ≥1（每日/每 fold） | **0**（三臂全部为 0） |
| `[A1] recommended_by_date 为空，fallback 到全市场...` | ≥1 | **0** |
| `[历史回放完成]` 行 | `0/240 ... 跳过 240` | **`240/240 个训练日有样本，跳过 0 个`**（59 次一致） |
| `[L1/L2] 标签模式=staged_rank` 行 | 不打印 | **打印**：`分阶段退出模拟 (S1=2.75σ/30%, ...)` |

⇒ `recommended_by_date` **必然非空**（否则 warning 必触发）。**未走 fallback。**

**反证 R2 — 标签形态实证**：

- 回退 legacy 三重屏障 ⇒ 标签应为 `{0, 1}`（或 `{-1,0,1}`）**离散**取值；
- **实测**：`标签(分位)统计: mean=0.502 std=0.289 min=0.003 max=1.000`，
  且分布 dict 为 **~300 个互异浮点键 × 各 240 次** ⇒ **连续分位**、每日 300 个样本各占一个分位档。

⇒ **标签是 `staged_rank` 的连续分位输出，不是 legacy 三重屏障的离散标签。**

### 根因分析：`strategy.py:3083` 的注释是**误导源**

```python
recommended_by_date = {}  # [R3-1 A1] {sample_date: [code_list]}
```

**该行是「初始化」，不是「终值」**。§7.3 把**初始化语句**误读为**恒定赋值**，
从而得出「空字典 ⇒ 回退」的推断 —— 但**逐日填充发生在 `:3102`**，且 `_read_v7_snapshot` 按
`pool_mode` 返回 **300 只池内股票** ⇒ **恒非空**。

**⇒ 这是一次「静态读码覆盖运行时实证」的典型误判**（教训：**初始化行不得作为终值证据**）。

### 保留的正确部分（§7.3 未被否定的内容）

| §7.3 论断 | 状态 |
|---|---|
| 「V10 数据齐备 1236 日，但当前批次不使用」 | ✅ **成立**（仅机制解释需修正：非「显式旁路」而是「结构性不接入」） |
| 「若生产架构是 V10→meta，则 Q5N 改完也用不上」 | ✅ **成立**（前提性风险提示，结论导向 Q5P 正确） |
| 「`[R3-1 A2] V10 pred_rank RankIC = nan`」 | ✅ **成立**（59 次） |
| 「**需要做架构对账**」 | ✅ **成立**（本文件即交付物） |
| 「`recommended_by_date = {}` ⇒ 空字典 ⇒ 回退 legacy」 | ❌ **推翻** |

**⇒ 结论表述**：**否定的是「回退 legacy」这一「路径」**，
**不否定**「做架构对账」这一**决策价值**（该决策**正确且必要**，只是**其中一个输入论断有误**）。

## 3. Q5N 落点与目标形态建议

### 3.1 落点：**维持 `smallcap`**

**依据**：问②已判定生产路径 = `smallcap`；且 §7.4 担忧的「改完用不上」**不成立**（V10 路径当前不存在）。

### 3.2 目标形态：**维持 `rank(residual(realized_ret) ⊥ rank(vol))`**

**依据**：问④已判定无 sizing 通道需求 ⇒ **不引入二分类+校准形态**。

### 3.3 ★ 新增建议：N2 的目标函数需按「连续目标 + 排序」重新表述

**触发**：`staged_rank` 标签是**连续分位**（非二分类）⇒ §7.3 对 N2 的描述
「`rank(同周期前瞻收益 ⊥ {vol, 市值})`」**方向正确**，但需澄清一个**口径歧义**：

| 候选表述 | 含义 | 建议 |
|---|---|---|
| A. 对**前瞻真实收益**做正交化后排序 | 直接用 future return 作目标 | ⚠️ **须核 PIT**：前瞻收益仅用于**训练期标签**，不进入特征 ⇒ 可用，但须断言 |
| B. 对**分阶段实现收益 `realized_ret`** 做正交化后排序 | 与交易规则同口径（de Prado 标签-执行对齐） | ✅ **推荐**（与 `staged_rank` 现状一致，无口径切换） |

**建议采 B**：避免「标签口径切换」引入的混杂（当前所有已落臂均用 `realized_ret`）。
**若采 A**，须在预注册中**显式声明口径变化**并过零影响闭合验证。

### 3.4 ★ 新增发现：Q5N 闸⑦（fallback 改 `raise`）的**紧迫性下调**

**原判**：闸⑦ 要求把「`staged_*` + 空 `recommended_by_date` ⇒ warning+fallback」改为 `raise`。

**实测**：**该 fallback 分支在当前配置下永不触发**（`recommended_by_date` 恒非空，反证 R1）。

**⇒ 修正建议**：
- 闸⑦ **仍应做**（fail-closed 纪律：静默口径切换永久禁止）；
- 但**等级从【高】降为【中】**：它不是「当前正在发生的风险」，而是「**未来配置变更时的隐患**」；
- **优先级让位于**：闸②（时间戳备份）、闸④（零影响闭合验证）、闸⑤（配置断言）。
