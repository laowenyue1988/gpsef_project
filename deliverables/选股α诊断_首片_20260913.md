## 一、关键口径澄清（防止误读）

日志中 `meta_auc` / `基线AUC` 实为 **AUC − 0.5 的 "edge" 口径**（值域约 ±0.14），**不是 AUC 本身**。
→ 换算：**有效 AUC = 0.5 + edge**。

## 二、★发现 1：长窗模型判别力 ≈ AUC 0.522（近乎随机）

| 项 | 数值 |
|---|---|
| PKF 重训次数（长窗 65 档对应） | **63** |
| edge 均值 | **+0.0216** ⇒ **有效 AUC ≈ 0.5216** |
| edge 中位 | +0.0240 |
| edge 范围 | **−0.1017 ~ +0.1375**（波动极大） |
| edge > 0 占比 | **73.0%** |
| 分三段均值（早/中/晚） | −0.002 / +0.042 / +0.025 ⇒ **无衰减，中后期反而略升** |

**解读**：
1. **模型有微弱但弱小的判别力**（AUC 0.52，随机=0.50）；73% 的重训为正，说明不是"完全无效"。
2. **否证了"模型能力随时间衰减"的假设**——后段（2024 危机后）edge +0.025，高于前段 −0.002。
3. **波动极大**（−0.10 ~ +0.14）⇒ 单次重训的判别力极不稳定，**依赖单次模型的判断风险高**。

**旁证**：MDA-OOS 基线 AUC edge 均值 **+0.0400**（n=330，含重复）⇒ 特征层本身也仅 AUC≈0.54。

## 三、★发现 2：门控并未造成"半仓"（R-18 部分澄清）

- `ic_gate_threshold: 0.02`（staged_rank 回归模式）；实际门控用**折集成 IC**（≈0.035）
- **64 次放行 / 5 次空仓**（"空仓"仅占 7%）⇒ **IC 门控不是低敞口的主因**

## 四、★发现 3：R-18 敞口缺口分解（长窗实测）

| 指标 | 数值 |
|---|---|
| 平均敞口 | **46.32%** |
| 中位敞口 | 44.52% |
| 零敞口（FLAT）天数 | **103 / 1315（7.8%）** |
| 剔除空仓日后平均敞口 | **51.09%** |

**分年敞口**：

| 年 | 平均敞口 | 零敞口天数 |
|---|---|---|
| 2021 | 38.6% | 40/185 |
| 2022 | 47.8% | 0/242 |
| 2023 | **57.8%** | 0/242 |
| **2024** | **26.6%** | **68/242** |
| 2025 | **61.2%** | 0/243 |
| 2026 | 42.8% | 15/161 |

**解读**：
1. **GARCH 目标敞口（约 0.8）× 实际 51%（剔空仓）之间仍有 ≈29pp 缺口** ⇒ 缺口**不全来自熔断与门控**，需进一步归因（候选：分批止盈止损造成的逐步退出 → 资金滞留现金；derisk 减仓；20 日调仓间隔内的自然衰减）
2. **2024 年是敞口崩塌年**（26.6%、68 天空仓）⇒ "指数 −2.2%、策略 −24.6%"的结构再添一层解释：**不只是选股差，而且是"该在场时不在场"**
3. 2025 年敞口最高（61.2%）且无空仓 —— 值得作为"机制在正常 regime 下如何表现"的对照样本
