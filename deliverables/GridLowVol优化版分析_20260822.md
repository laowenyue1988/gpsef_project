## 五、补充完整风控方案（P0 组合闸门 + P1 回撤熔断 + **分层仓位恢复**，2026-08-22 03:32）

### 5.1 组合状态机

```
状态: 0=NORMAL(满仓运营) → 1=TREND_DOWN(只卖不买) → 2=HALF(半仓) → 3=FLAT(空仓)
```

### 5.2 触发（保守优先：同时满足时取最保守状态）

| 信号 | 条件 | 目标状态 |
|---|---|---|
| 回撤熔断-深度 | 净值回撤 > 8%（距峰值） | **FLAT(3) 清仓** |
| 回撤熔断-中度 | 净值回撤 > 5% | **HALF(2) 半仓** |
| 组合趋势 | 沪深300 收盘 < MA60 | **TREND_DOWN(1) 只卖不买** |
| 正常 | 均未触发 | NORMAL(0) |

### 5.3 仓位恢复（用户指出的关键缺口——市场信号 + 峰值重置 + 滞后带 + 趋势确认）

> **2026-08-22 recover 修复**：原方案 FLAT→HALF 依赖"净值回撤收窄至 <3%"——但空仓后
> `total_value = cash + 0 持仓`（引擎无现金利息），净值完全冻结，回撤恒为常数（如 -8%），
> 恢复条件永不可达 → **触发空仓 = 永久空仓（吸收态死锁）**。
> 修复：恢复信号改为**市场趋势确认**（沪深300 ≥ MA60 连续 N 日），FLAT 恢复时**峰值重置**
> （回撤基线归零重新起算）；触发侧加状态守卫（已在 FLAT 不重复触发熔断，保证恢复分支可达）。

| 当前状态 | 恢复条件 | 恢复至 | 设计理由 |
|---|---|---|---|
| FLAT(3) | 沪深300 ≥ MA60 **且连续 3 日确认** → 进入 HALF，**同时重置 `_peak_value`=当前净值**（回撤基线归零） | HALF(2) | 空仓期等市场企稳信号再入场；先半仓试探不追高；基线重置让回撤计数重新开始 |
| HALF(2) | 沪深300 ≥ MA60 **连续 3 日确认** **且** 净值回撤 <1.5%（双条件） | NORMAL(0) | 趋势转暖 + 净值回血双确认才满仓 |
| TREND_DOWN(1) | 沪深300 ≥ MA60 **且连续 3 日确认** | NORMAL(0) | 滤除假突破 |

**三大防振荡机制**：
1. **滞后带（hysteresis）**：触发阈值 5%/8% vs HALF→NORMAL 恢复阈值 1.5%——净值需从峰值回升 ≥3.5pp 才满仓，避免在阈值附近反复降/升仓（业界均值回归/回撤风控标准做法）；
2. **分层恢复**：空仓→半仓（半仓预算建仓）→满仓分两步，每步独立确认；FLAT→HALF 后需重新累计 3 日确认才能到 NORMAL；
3. **趋势确认**：FLAT/HALF/TREND_DOWN 恢复统一要求指数连续 3 日站上 MA60，防假突破；峰值重置的潜在风险（基线变低）由分层恢复 + 趋势确认 + HALF 锁底仓三重缓解。

### 5.4 执行与无未来保证

| 状态 | 盘前 | 开盘 |
|---|---|---|
| NORMAL | 正常选股/预警 | 正常建仓 + 网格 |
| TREND_DOWN | 正常选股（不建仓）| 组合级只卖不买（网格 allow_buy=False + 个股 base_locked 底仓保护）|

- **无未来**：净值回撤用前一交易日 total_value 与历史峰值；指数趋势用 ≤T-1 沪深300 收盘；确认天数基于历史交易日；
- **恢复执行**：FLAT→HALF 峰值重置后，以半仓预算重新建仓（恢复来源 HALF 允许建仓）；HALF→NORMAL 恢复满仓预算建仓；TREND_DOWN→NORMAL 恢复网格买入。
