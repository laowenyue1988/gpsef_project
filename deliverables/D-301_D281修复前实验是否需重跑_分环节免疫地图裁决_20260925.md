## §2 取证二：免疫地图（本轮新发现，是论证的核心）

**关键区分**：D-281 改的是 **`amount`（成交额）** 的复权方向（`×1/f → ×f`）。**价格（OHLC）一直是 `×f`，方向本来就正确**（D-299 已完整实证）。因此——

> **凡是只用价格（或指数、或组合净值）的环节，一律免疫；只有用到 `amount`/`vwap` 派生量的环节才不免疫。**

逐环节代码级核实：

| 环节 | 是否用 `amount`/`vwap` | 证据 | 免疫 |
|---|---|---|---|
| **① 池排序（T−1 市值最低 300 只）** | 用 **`raw_daily` 的原始** `amount`/`turn` | `strategy.py:110-134` `_compute_total_mv_chunk`：`pd.read_parquet(fp, columns=['ts_code','trade_date','amount','turn'])` ⇒ **原始未复权**，且 `total_mv = amount*100/turn` | ✅ |
| **② 标签（σ + 屏障 + 结局）** | **完全不用** | **`labels.py` 中 `amount` 出现 0 次｜`barriers.py` 中 0 次**；σ 明确"直接从 close 计算收益率"（`all_returns = np.diff(adj_close)/adj_close[:-1]`） | ✅ |
| **③ 出场/交易执行** | 只用价格 | 阈值 = `entry×(1±k·σ)`；成交价 = 阈值价；`amount` 在 `strategy.py` 的 25 次出现中，**无一处进入出场判定** | ✅ |
| **④ BARRA 风险模型构建** | 全取 `raw_daily` | **Z16 实证**：重建 20260115 后三文件 **md5 全等**、逐列 **max\|Δ\| = 0** | ✅ |
| **⑤ 风控/熔断/敞口层** | 用指数与组合净值 | `garch_control` 用指数波动率；`drawdown_breaker` 用组合回撤 | ✅ |
| **⑥ ★因子特征（191 列中的 40 列）** | **用 `vwap`/`amount` 派生** | 这 40 列正是"被检测到变化"的列 | ❌ **不免疫** |

**⇒ 唯一的不免疫环节 = ⑥ 因子特征 ⇒ 影响路径只有一个：`因子特征 → XGBoost 打分 → Top-20 选股`。**

**★这个区分为什么重要**：它把"要不要重跑"从"整条链路都变了"缩小为"**只有选股打分那一环变了**" ⇒ 于是**所有以"标签/出场/风控"为主变量的实验族，其结论在结构上不受影响**（见 §5 分诊表）。

## §6 裁决与处置

### 6.1 裁决

**不重跑任何修复前代际的实验。** 三条合取理由：
1. **影响面被精确限制在"因子特征 → 选股打分"一环**（§2 免疫地图：其余五环代码级免疫）；
2. **该环的净效应实测低于噪声地板**（§3：|Δ★Sharpe| 0.08~0.15 < 2σ **0.2482**；`meta_IC` 差 **2.4e−4**；日收益相关 **0.978**；CI 含 0）⇒ 按 **R-164**，**判 "inconclusive"，既不得据此要求重跑，也不得判"否证"**；
3. **最根本的结论已在新口径上重建**（波 2.5C N=21 ⇒ **p = 0.0455**；新基线 `dump_full`）⇒ **"模型有没有用"不需要回到旧口径再问一遍**。

**成本对照**：修复前代际实验约 **485/545 臂**（89.0%，D-294 实测）；全量重跑 **≥2,000 小时机时**（3 并发 ≈28 天）⇒ 换取"低于噪声地板"的差异，**收益/成本比极差**。

### 6.3 ★新立纪律 R-174（口径变更的影响面必须"分环节"判定）

**规则**：凡发生**数据管线口径变更**（缺陷修复／快照重算／换数据源／换基准日），"是否需要重跑历史实验"的判断**必须先建立"分环节免疫地图"**——
①**逐环节**列出该变更影响的**派生量**（本例 = `amount` 及其派生 `vwap`）；
②**逐环节**核实该环节是否消费该派生量（**代码级**：grep + 读实现，**不得凭印象**）；
③**只对"不免疫"的环节**做净效应实测（**唯一变量对照臂**）；
④**以实测净效应的 |Δ| 对照噪声地板（2σ）与 MDE** 判"可辨识 / inconclusive"；
⑤**不得**用跨代际的合成差异（如"新基线低 6.59%"）作为净效应证据（**R-148**）。

**理由**：本轮若无这张地图，就会在"D-281 动了三分之一权重（28.3%）"与"实测 Δ 低于噪声地板"之间无从调和；有了地图即可解释：**动的是"因子特征"这一环，而该环的净效应被"候选池同质化"吸收掉了**。

**自检问句**：「**这次口径变更影响的是哪个派生量？链路上哪些环节真的用了它？我有没有逐环节 grep 过？**」

## §7 小白版四问（D-269 强制）

### ① 这段在解决什么问题？

你发现之前修过一个数据 bug（**成交额的复权乘反了**，2026-09-22 修好）。修好之后，**很多实验是在"修好之前"跑的**。于是有一个自然的问题：**那些老实验要不要全部重跑一遍？** 重跑很贵（约 545 个实验、2000 多小时机器时间、约 1 个月），不重跑又怕结论文不对题。

### ② 用了什么办法？

三件事，都不烧机器：

**（一）数清楚"这个 bug 到底动了多少东西"。** 结果：一共 221 个因子列里动了 **40 个**（18%）。更要紧的是——我去翻了模型自己的"重要性清单"（66 轮，每轮一份），发现**这 40 列里有 26 列真的被模型用上了**，**占模型总重要性的 28.3%**，其中有一个叫 `alpha_095_FFD` 的还是**第 3 重要的因子**。**所以这个 bug 绝不是"边角改动"。**

**（二）查清楚"哪些环节真的用到了这个 bug 影响的量"。** 这个 bug 影响的是**成交额**。于是我把整条链路逐个环节去代码里 grep：
- **池排序**（选最小 300 只）：用的是**原始数据里的成交额**，不走复权 ⇒ **不受影响**
- **标签**（标准答案）：`labels.py` 和 `barriers.py` 里**"成交额"这个词出现 0 次**，波动率是从**收盘价**算的 ⇒ **不受影响**
- **出场/成交**：只用价格 ⇒ **不受影响**
- **风险模型（BARRA）**：只从原始数据取数 ⇒ **不受影响**
- **风控/熔断/仓位层**：用指数和组合净值 ⇒ **不受影响**
- **只有"因子特征 → 模型打分 → 选 20 只"这一环受影响** ✅

**（三）做一次"干净"的对照实验。** 其实这个对照**已经做过了**（09-23 波 2.5A 的 A/B 臂）：用**同一份配置、同一个窗口**，只把因子快照换成"修好前的"和"修好后的"，跑两个完整回测。我直接去读了这两个臂的原始结果。

### ③ 结果是什么？

| 看什么 | 结果 |
|---|---|
| 模型的**打分能力**（IC） | **几乎一模一样**：5 轮配对，**差 0.0002** |
| **选出的 20 只股票** | **变了近一半**：重合度只有 **0.54**，**没有一天是完全一样的** |
| **赚了多少钱** | **几乎一样**：日收益相关性 **0.978**，最大单日差 **0.91%**，年化差 **0.16 个百分点** |
| **Sharpe 差多少** | **+0.08 ~ +0.15**，而我们的"噪声地板"是 **0.2482** ⇒ **没超过噪声地板**，置信区间也**包含 0** |

**为什么会这样**：那 300 只微盘股**本来就长得很像**（都是最小市值），模型给它们的打分**挤在一起**。所以"稍微扰一下分数"，就足以把"选谁"重新洗牌一半，**但换进来的和被换掉的那几只，接下来走势几乎一样** ⇒ **名单变了，赚钱路径没变。**

**④ 所以结论**：**不用重跑。** 但**不是因为"没影响"**，而是因为——**影响被精确地关在"选股打分"这一个环节里**，而**实测这一环的影响低于我们的分辨能力**；同时，**最根本的那个问题（"模型到底有没有用"）已经用修好后的数据重新做过了**（21 个随机对照臂，**全部没打过基线，p = 0.0455**）。

**只花一笔钱**：**"出场档位"这一族值得重测一次**（4 个臂、约 11 小时，就是路线里的**波 3.5**）—— 因为它**离决策最近、成本最低**，而且它是**唯一**"标签端免疫但选股端不免疫"的混合族。其余一律不重跑。

### ④ 这对你意味着什么？

- **省下约 2000 小时机时（≈28 天）**，且**不损失任何已登记的结论方向**。
- **你之前那些实验的结论仍然可用**，但**引用时必须带一句"这是修复前口径"** —— 这条限制本来就在做（R-148），现在有了更细的版本。
- **★否定的是"重跑"这条路径，不是"那些实验的价值"**：它们建立的机制认识（比如"放宽止损=隐性加杠杆""微盘越波动越涨""模型贡献是降波动不是提收益"）**都是结构性的、与数据口径无关**。
- **新增一条纪律（R-174）**：以后**任何数据口径变更**，都**必须先做"分环节免疫地图"再决定要不要重跑**，**不许用"新基线低了多少"这种跨代际的混杂数字当证据**。
- **顺带修掉一个小缺陷**：A/B 的自助置信区间在 L=42 时**只切出 1 个区块**（退化为一个点，会假报"不含 0"）⇒ 已登记为工具待修项（按 R-154 应标 `insufficient_blocks`）。
