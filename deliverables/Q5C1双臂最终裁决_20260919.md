## §7 ★★ 核心发现：干预面被混淆（配置干净 ≠ 干预干净）

### 7.1 实证（零成本，全部来自已落臂日志）

| 指标 | REF（barra off） | sh932000 | csi800 |
|---|---|---|---|
| **调仓后持仓数**（66 次调仓的分布） | **20**（63 次 20、1 次 19、2 次 21） | **10~14（众数 12）** | **10~13（众数 11）** |
| **HHI**（众数） | **0.0500**（= 1/20，等权） | **0.094**（等效 **10.6 只**） | **0.095**（等效 **10.5 只**） |
| **`max_w=0.100` 出现次数**（66 次调仓） | **0** | **147** | **162** |
| `Barra CorrectedSoft Converged`（众数） | — | 12/20 | 11/20 |

### 7.2 机制解读

调用实参（`strategy.py:3742-3765`）是 `solve_barra_weights(preds=probs, selected_codes=codes)` —— 求解器**只在已选中的 20 只内部配权**。而 `barra.enabled` 是一个**双态开关**：

| | barra off（REF） | barra on（Q5C-1） |
|---|---|---|
| 权重来源 | `target_weights = {}` ⇒ **等权**（`strategy.py:3677`） | **求解器输出** |
| 持仓数 | **20** | **~10.4** |
| HHI | 0.05 | 0.094~0.095 |
| max_weight 约束 | 约束不存在（无优化） | **高频绑死**（147/162 次） |

求解器目标（`barra_constraint.py:376-395`）：
```
P = 2·(λ_risk·Σ + λ_dev·BᵀB + λ_l2·I),   q = −alpha − 2·λ_dev·(B·B_bench) + q_ind
w* = argmin ½wᵀPw + qᵀw   s.t.  0 ≤ w ≤ max_weight,  Σw = 1
```
`−alphaᵀw` 项把解推向**角点**（高 alpha 股吃满 `max_weight`）；`risk_aversion=0.5` 下的风险/正则项不足以对抗它 ⇒ **解被 `max_weight=0.10` 绑死**：10 只 × 10% = 100% ⇒ 等效持仓 ≈ 10 只。

### 7.3 结论（本批最重要的一条）

> **Q5C-1 的干预不是「在等权 20 只上叠加风险层」，而是「用 cap 绑定的 ~10.4 只集中组合替换 20 只等权组合」。**
> 配置层只改 1~2 键，**运行期干预面却是三件事同时变**：权重来源 + 持仓数 + 集中度。

⇒ **Q5C-1 只回答了一个问题：「20 只等权 → ~10.4 只集中」是否有益」；答案：两基准上均无正贡献（不可辨识）。**
⇒ **它没有回答「BARRA 作为风险叠加层是否有益」** —— 因为在该参数下，求解结果**并不体现风险层**，而只体现集中化。

## §8 裁决

### 裁定 1：**B1 门触发**（预注册，不得事后更改）
两臂均**不可辨识**且均**未达「三取并」正** ⇒ 按 `BARRA轴参数标定设计与最终路线_20260919.md` 的 **B1**：
- **不启动原 Q5C-2 的 8 臂软约束标定**
- **BARRA 轴降级**，下一阶段转 **Q5N**

### 裁定 2：**否定的是「路径」，不是「机制价值」**（D-147 五步闭环要求）
- **否定路径**：`barra.enabled=true` + `risk_aversion=0.5` + `max_weight=0.1` + `lambda_dev=0.2` + `lambda_l2=0.3` —— 该具体配置的实际效果 = **20 只→10.4 只集中化**，在 sh932000 与 csi800 两条基准上**均无正贡献**、均不可辨识。
- **不否定机制**：**「cap 不绑定的近似等权解 + 风险/因子 tilt」这一形态从未被检验**（§7）。B1 的隐含前提「Q5C-1 干净隔离 BARRA on/off」在**行为层不成立** ⇒ **不可据此宣称「BARRA 无效」**。
- **与 D-219/R-116 一致**：集中化唯一明显改变的是**风险预算的分配**，而 D-219 已证「敞口/风险旋钮**无法显著改变风险调整后收益**」；本批是同一现象的又一次确认。

### 裁定 3：**Q5C-2 重设计为 1 臂「混淆清除探针」（Q5C-1b），排在 Q5N 之后**
**取消**原 8 臂（4 软参数 × 双向极端）设计。理由：原设计基于「求解结果体现风险层」的前提；该前提在 `risk_aversion=0.5` 下不成立 ⇒ **8 臂会全部落在同一个 cap 绑定混淆内**，是纯算力浪费 —— **这恰是 B1 想防止的事**。缩减为 1 臂，是**服务于 B1 的目的**，而非绕过 B1。

**排期理由（效率论证，与读数方向无关）**：BARRA 是**选股后的配权层**，其解依赖模型的 `preds` 与选股结果。
- 若 Q5N 胜出（目标变更 ⇒ 模型/选股变更）⇒ 探针**必须在新目标上重跑**；
- 若 Q5N 未胜出 ⇒ 目标不变 ⇒ 探针**只跑一次**。
⇒ **探针一律排在目标定案之后，全程只跑一次**。若现在先跑，Q5N 胜出时会白跑一臂（概率非零）⇒ **Q5N 前置是严格更优的顺序**。

**探针预注册判据（现在写死，不得事后更改）**：
| # | 判据 | 内容 |
|---|---|---|
| **W1（有效性闸，最优先）** | 探针必须**真的松开 cap**：`HHI ≤ 0.075`（等效 ≥13.3 只）。**若 HHI 仍 ≥0.09 ⇒ 判定「BARRA 在本题不存在非集中形态」，永久否决该轴，不再追加任何臂。** | |
| **W2（主判据）** | Δ★Sharpe ∧ Δ★Calmar ∧ Δ单位敞口 **三取并** 正 | |

| **W5** | 分段归因（WD/WX/2026）+ 敞口序列 + **持仓数/HHI 分布**（本批新增必备，防混淆复发） | |

**探针参数选择（零算力预筛）**：`risk_aversion` ↑（0.5→2.0）与 `lambda_l2` ↑（0.3→1.0）**双路都拉向分散**（`P = 2(λ_risk·Σ + λ_dev·BᵀB + λ_l2·I)`；`λ_l2·‖w‖²` 在 `Σw=1` 下**直接趋向等权**）⇒ 取**更直接松开 cap** 的 `lambda_l2` 为主候选；起臂前须先做**离线小规模求解预筛**（不跑回测）确认 HHI 能降到 ≤0.075，否则换 `risk_aversion` 或双管齐下。**禁止直接起臂试错。**

**静默窗已开启**：活跃臂 **0 / 3**，提交余量 **61.5GB**（≫10GB 安全线）。Q5N 的七道闸门按 `Q5N目标改造批次设计与路线插入_20260918.md` 执行。
