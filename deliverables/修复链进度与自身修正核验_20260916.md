## §2 ★对「10 处补丁是否真的落盘」的独立复核（发现并修正了我自己的一个假阳性）

我写了只读校验器 `_verify_patches_applied.py` 做独立复核（不依赖编排器的自报）。

### 2.1 第一版（v1）结果：**8 PASS / 2 FAIL** ← **这是我校验器的假阳性，不是补丁的问题**

v1 判据是「`new` 在位 且 `old` 已消失」。A2、P2 两条被判 FAIL（`old` 仍"出现"）。
追查根因：

```
A2: old 是 new 的子串? True     new 是 old 的子串? False   old 出现次数 = 1, new 出现次数 = 1
P2: old 是 new 的子串? True     new 是 old 的子串? False   old 出现次数 = 1, new 出现次数 = 1
```

⇒ **A2 / P2 两条补丁的 `old` 文本本身就是 `new` 的子串**。打上补丁后，`old` 的"出现"只是它被包含在 `new` 里面 ⇒ **v1 判据错误（假阳性）**。
且 v1 的自证只覆盖了第 1 条补丁（A-1，恰好不存在该重叠）⇒ **自证覆盖不足，未能自查出**（这正是常青纪律第 6 条「工具必须带自证」要防的情形）。

### 2.2 修正版（v2）：**10 PASS / 0 FAIL，自证 10/10**

判据改为：**补丁已应用 ⟺ ① `new` 在位 ② 「不在 `new` 内部」的 `old` 残留数为 0**（实现：先把所有 `new` 片段挖空，再数 `old`）。
自证改为**对全部 10 条补丁逐条反向构造**（把 `new` 还原成 `old`，必须被判"未应用"）⇒ 判别力覆盖 100%。

```
补丁    new在位  old残留  判定
A-1/A-2/A-3/A2/A3/B/N/O/P1/P2   YES   0   PASS   （10/10）
汇总: PASS 10 / FAIL 0
自证（全 10 条覆盖）: PASS 10 / FAIL 0
old ⊂ new 的补丁（v1 会假报 FAIL）: ['A2', 'P2']
```

⇒ **结论：10 处补丁全部真实落盘且 `old` 无残留（除被 `new` 包含外）。**
