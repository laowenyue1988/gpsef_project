# §2 PIT 复核：✅ 严格遵循

## 2.1 机制层（4 条构造性论证）

| # | 论证 | 代码依据 |
|---|---|---|
| **P1** | **逐日窗口 = [D−400d, D]**，右侧封闭于 D，无任何未来 bar | `snapshot_fast.py:687-689`（`searchsorted(all_dates, D, side='right')`） |
| **P2** | **每股的整个窗口取自「同一个基准日」的一次加载** —— 分段股用其所属段的加载（基准=段末日），其余用主加载（基准=ce）。**不存在"同一窗口混用两个基准"** | `:705-712`（`if _is_seg_stock(code): df = seg_data[...] else: df = data_by_code[code]`，随后整窗切片 `df[win_start..D]`） |
| **P3** | **`smooth_bf` 在"段"内恒定**（段的定义就是 T 恒定的最大区间）⇒ 对任意股票、任意日 D，都有 `smooth_bf(D) = smooth_bf(基准日)` ⇒ **`f(D) = 1`** ⇒ **每个交易日的复权基准恒等于当日** ⇒ 前复权口径与 D 严格对齐，**无未来除权信息进入历史价** | `compute_action_segments:203-220` + `_is_seg_stock:697-699` |
| **P4** | **除权分段是"修正"而非"引入"**：若不分段（全部用基准 ce），则对 D 在 (ce 之前且其后有除权) 的股票，其**当日价格会被乘以 `smooth(D)/smooth(ce) < 1`**，破坏当日截面可比性。分段把基准拉回段末日 ⇒ `f(D)=1` ⇒ 修复 | `:586-598` |

# §4 ★缺陷：`amount` / `vwap` 的复权方向相反

## 4.1 代码事实

```python
# local_provider.py:257-266
for col in ['open','high','low','close']:
    df_merged[col] = df_merged[col] * (df_merged['backAdjustFactor'] / back_factor_T)   # × f
if 'amount' in df_merged.columns:
    df_merged['amount'] = df_merged['amount'] * (back_factor_T / df_merged['backAdjustFactor'])  # × 1/f ← 反向
if 'volume' in df_merged.columns and 'amount' in df_merged.columns:
    df_merged['vwap'] = df_merged['amount'] / (df_merged['volume'] + 1e-10)
```

令 `f = smooth_bf(t)/smooth_bf(T)`：**价格 × f，amount × 1/f ⇒ `vwap = amount/volume` 被 × 1/f**。
⇒ **`vwap` 与 `close` 的相对量纲差 `f²`。**

# §8 小白版四问

**① 这次查了什么？**
查"策略每天用的因子表"是不是**只看当天及以前的数据**（不能偷看未来），以及**除权除息有没有被正确处理**（分红送股那天价格会假跌，必须还原）。

**② 怎么查的？**
①把生成因子的代码从头读到尾，确认每天只用 `[当天往前 400 天, 当天]`、且每只股票整个窗口只用**一个**复权基准日；②挑 5 只有真实分红的股票，把 `原始价 → 复权因子 → 平滑因子 → 复权价` 每一步的中间数字都打出来，与策略实际用的数据逐位对比；③用"除权日"这个最容易出错的时点做交叉验证。

**③ 结果？**
- **不偷看未来：合格。** 用"当天做基准"和"用 20 天后做基准"算出来的价格**一模一样**（差 0.000000000000000）。
- **除权处理（价格）：合格。** 例如 `sh.600000` 在 2024-07-18 原始价跌 2.99%，复权后只剩 +0.57%——分红造成的假跌被准确剔除；5 只股票的快照数值都能被**逐位复算**出来（误差 0）。
- **★但发现一个真错误**：成交额（`amount`）的复权**方向反了**——价格乘 `f`，成交额却乘 `1/f`，导致"均价"（`vwap`）与价格**差 `f²`**。证据：`vwap` 本该永远落在当天最低价与最高价之间，现在 **5 只股票分别有 175/165/16/145/252 天越界**；把成交额改成乘 `f` 后**越界归零**。影响 **39 个因子（20.5%）**，且在 **77.1%** 的样本日上实际生效。

**④ 对你意味着什么？**
- **好消息**：PIT 没问题，历史结论不会因为"偷看未来"而失效；价格链也完全正确。
- **需要处理的**：这 39 个因子的历史数值有一部分是"用不一致的均价"算出来的。**不是泄漏、不是策略逻辑错**，但会让 XGBoost 在用到这些因子时看到一点噪声/伪信号。
- **怎么做**：改两行代码 → 重算 1315 天快照 → 对比"改前/改后"这 39 列的变化（其余 151 列应**一动不动**）。**但现在有 3 个实验臂在跑，按纪律不能动代码**，所以我先把它落档、等你确认后再排期。
