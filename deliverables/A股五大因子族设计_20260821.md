# A 股五大因子族设计文档（低波动 / 质量 / 价值 / 红利 / 现金流）

**依据**: 知乎《真剑圣》回答核心观点——A 股不存在"永远有效"的因子，但存在"长期有经济学逻辑支撑、统计上显著、且理解成本可控"的因子家族；长期实证指向五个方向：**低波动、质量、价值、红利、现金流**；动量/成长在 A 股需谨慎；因子会失效，靠"可验证流程 + 淘汰制"管理。  
**设计目标**: 每族 ≥20 个因子，每因子给出经济学解释、数学公式、伪代码、数据来源；最终接入既有 alpha191 量化管线（截面 Winsorize/Z-score → 行业+市值中性化 → PKF 特征筛选 → 回测验证）。  
**日期**: 2026-08-21 | **状态**: 待用户审核

## 〇、总纲：设计原则与使用纪律

### 0.1 对齐文章观点的七条设计原则

| # | 原则           | 本设计的落实                                                          |
| - | ------------ | --------------------------------------------------------------- |
| 1 | 经济学逻辑优先于统计挖掘 | 每因子必须给出行为学/制度性根源（散户偏好、机构排名压力、确定性溢价、会计稳健性等）                      |
| 2 | 理解成本可控       | 因子全部可用「基础数据字段 + 1~2 个算子」表达，杜绝黑箱组合                               |
| 3 | 统计显著以长期为锚    | 验收标准用 IC/IR 与 10 年+ 穿越牛熊的分层单调性（见附录 C），不要求"每年都赚"                 |
| 4 | 去极值 + 标准化是底线 | 全部因子在接入管线前必须过截面 Winsorize + Z-score（对齐现有 `_neutralize_factors`） |
| 5 | 因子池是淘汰出来的    | 建议首期每族选 4~6 个种子因子入池（合计 ≤25），跑 1 年淘汰最差 3 个再补充                    |
| 6 | 警惕失效与拥挤      | 对经典因子族（尤其低波动、红利）监测 IC 时序与拥挤度；A 股小盘反转/大盘动量分化，族内因子按截面中性化后使用       |
| 7 | 权重固定、不频繁择时   | 因子权重一经回测确定即固定，禁止按月度情绪调权（文章原话：频繁调权重等于没有策略）                       |

### 0.2 统一符号约定

| 符号                                  | 含义                                                                                   |                                        |       |
| ----------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------- | ----- |
| $P_t, C_t, H_t, L_t, O_t, V_t, A_t$ | 收盘/最高/最低/开盘/成交量/成交额（t 为交易日）                                                          |                                        |       |
| $r_t = C_t/C_{t-1}-1$               | 日对数收益近似（伪代码用 pct_change）                                                             |                                        |       |
| $R_{t,k}$                           | 持有 k 日收益 $C_{t}/C_{t-k}-1$                                                           |                                        |       |
| $\bar{x}_n, \sigma_n$               | n 期滚动均值 / 样本标准差                                                                      |                                        |       |
| $\text{rank}_t(x)$                  | 当日截面排名（行业内或全市场，按使用场景）                                                                |                                        |       |
| $\text{MV}_t$                       | 总市值；$\text{EV}=$ 市值+净债务；$\text{BV}, \text{Sales}, \text{NI}, \text{OCF}, \text{FCF}$ | 账面权益/营收/净利润/经营现金流/自由现金流（FCF=OCF−CapEx） |       |
| $\text{DPS}$                        | 每股现金分红；$\text{D/P}$                                                                  | 股息率                                    |       |
| $\text{IC}$                         | 截面秩相关（因子 vs 未来收益）                                                                    | $\text{IR}=\overline{IC}/std(IC)$      | 因子稳定性 |

伪代码统一用 pandas 风格，算子沿用项目 `factors.py` 已有函数名（`ts_mean/ts_std/ts_delta/ts_rank/rank/decay_linear`），每因子附"截面构造"骨架：

```
snapshot: 每交易日 T，用 T 日及之前数据算因子值（严格无未来）
fwd_ret:  用 T+1 ~ T+20 收益做标签（回测时）
```

### 0.3 数据来源分级标注

- **[本地]** = 项目 `data/` 已有：日线 OHLCV（`factors`/`back_adjust_factors`）、`fundamental_ml_v2_snapshots`（55 字段，清单见附录 A）、`dividend_data`（每股现金分红含税/派息日）、`industry_map.parquet`、`market_value_cache`/快照内 `total_mv`。
- **[外部-财报]** = 需从财报/数据商补充（本地面板无的字段，如 CapEx、现金流量表明细、利息费用、分析师数据）。
- **[外部-可选]** = 增强型数据（无则用族内替代因子，不影响族完整性）。

## 一、低波动族（Low Volatility）—— 22 个

**经济学逻辑（族）**：行为学上散户过度追逐高波动/彩票型股票（偏好效应 + 过度乐观），机构存在排名压力推高高 beta 标的；制度上 A 股波动率集聚与涨跌停约束使低波动组合在长期获得风险调整后超额（Low-Volatility Anomaly，Ang et al. 2006；A 股实证广泛支持）。**方向**：族内因子数值越大 → 预期未来收益越高，全部做**正向化**（原始量负相关的取倒数或负号），统一为"越大越好"。

### LV-01 已实现波动率倒数

- **经济学解释**：20 日已实现波动率是风险定价的核心代理；低波动溢价在 A 股强于美股，且与散户偏好高度相关。
- **公式**：$\text{LV1} = \left[ \sqrt{252}\cdot\sqrt{\tfrac{1}{n-1}\sum_{i=1}^{n}(r_{t-i+1}-\bar r_n)^2} \right]^{-1}$，$n=20$
- **伪代码**：`rv20 = C.pct_change().rolling(20).std() * sqrt(252); lv01 = 1.0 / rv20`
- **数据来源**：[本地] 日线收盘价

### LV-02 下行波动率倒数（Downside Vol）

- **经济学解释**：投资者损失厌恶使下行风险溢价更高；仅负收益的波动率捕捉"崩盘风险"，比总波动更贴近尾部定价。
- **公式**：$\text{LV2} = \left[\sqrt{252}\cdot\sqrt{\tfrac{1}{n^-}\sum_{r_i<0} r_i^2}\right]^{-1}$，$n^-=$ 负收益天数
- **伪代码**：`neg = r[r<0]; lv02 = 1.0 / (sqrt(252) * sqrt((neg**2).sum()/max(len(neg),1)))`
- **数据来源**：[本地] 日线收盘价

### LV-03 上行/下行波动比

- **经济学解释**：上行波动与下行波动之比高 = 收益分布"右偏"（涨得稳、跌得少）——彩票偏好反面，风险调整后更优。
- **公式**：$\text{LV3} = \dfrac{\sigma_{r>0}}{\sigma_{r<0}}$（正收益波动 / 负收益波动）
- **伪代码**：`up_std = r[r>0].std(); dn_std = r[r<0].std(); lv03 = up_std/(dn_std+1e-10)`
- **数据来源**：[本地] 日线收盘价

### LV-04 波动率稳定性（Vol-of-Vol 倒数）

- **经济学解释**：波动率本身不稳定的股票 = 风险状态频繁切换，难以估值与风控；波动率稳定者更易获得确定性溢价。
- **公式**：$\text{LV4} = \left[ std_{t-59..t}(\text{RV}_{20})\right]^{-1}$（60 日滚动波动率的标准差）
- **伪代码**：`rv = r.rolling(20).std(); lv04 = 1.0 / rv.rolling(60).std()`
- **数据来源**：[本地] 日线收盘价

### LV-05 特异波动率倒数（Idiosyncratic Vol）

- **经济学解释**：对市场回归的残差波动 = 公司特有风险，理论上被分散化，但 A 股散户持有集中 → 特异性风险被过度定价，残差波动低者溢价高（Ang et al. 2006 IVOL anomaly）。
- **公式**：$\epsilon_t = r_t - \hat\alpha - \hat\beta\, r_{m,t}$；$\text{LV5} = \left[\sqrt{252}\,std_{20}(\epsilon)\right]^{-1}$
- **伪代码**：`beta, alpha = lstsq(r_m.reshape(-1,1), r); eps = r - alpha - beta*r_m; lv05 = 1.0/(eps.rolling(20).std()*sqrt(252))`
- **数据来源**：[本地] 日线收盘价 + 指数日线（`index_daily`，用沪深300或中证500）

### LV-06 市场 Beta 倒数

- **经济学解释**：高 beta 股票在下跌市放大损失，低 beta 提供防御；低 beta 异常（low-beta anomaly, Black 1972, Baker et al. 2011）源于杠杆约束下投资者抬高高 beta 需求。
- **公式**：$\beta = \dfrac{Cov(r, r_m)}{Var(r_m)}$（60 日）；$\text{LV6} = 1/\beta$（β<0 时置 0 保护）
- **伪代码**：`beta = r.rolling(60).cov(r_m)/r_m.rolling(60).var(); lv06 = 1.0/beta.where(beta>0)`
- **数据来源**：[本地] 日线收盘价 + `index_daily`

### LV-07 Beta 稳定性

- **经济学解释**：beta 随时间漂移大的股票 = 风险属性不稳定；稳定低 beta 的可预测性带来溢价。
- **公式**：$\text{LV7} = \left[std_{t-119..t}(\beta_{20})\right]^{-1}$（120 日滚动 beta 的标准差）
- **伪代码**：`b20 = r.rolling(20).cov(r_m)/r_m.rolling(20).var(); lv07 = 1.0/b20.rolling(120).std()`
- **数据来源**：[本地] 日线收盘价 + `index_daily`

### LV-08 振幅倒数（ATR 归一化）

- **经济学解释**：真实波幅（含跳空）比收益波动更直接反映日内风险；振幅低 = 交易成本友好 + 情绪平稳。
- **公式**：$\text{TR}_t=\max(H-L,\;|H-C_{t-1}|,\;|L-C_{t-1}|)$；$\text{LV8}=\left[ATR_{20}(TR)/P_t\right]^{-1}$
- **伪代码**：`tr = max(H-L, (H-C.shift()).abs(), (L-C.shift()).abs()); atr = tr.rolling(20).mean(); lv08 = 1.0/(atr/C)`
- **数据来源**：[本地] 日线 OHLC

### LV-09 滚动最大回撤倒数

- **经济学解释**：最大回撤是投资者实际体验的"痛苦"度量；低回撤 = 持有体验好 = 行为上不易被洗出（与红利低波产品的市场认可一致）。
- **公式**：$\text{LV9} = \left[\min_{s\in[t-59,t]}\left(\tfrac{C_s}{\max_{u\le s}C_u}-1\right)\right]^{-1}$（60 日最大回撤）
- **伪代码**：`roll_max = C.rolling(60).max(); mdd = C/roll_max - 1; lv09 = 1.0/(-mdd.rolling(60).min())`
- **数据来源**：[本地] 日线收盘价

### LV-10 尾部风险倒数（5% CVaR）

- **经济学解释**：5% 条件在险价值衡量左尾平均损失；尾部风险低 = "跌不深" = 确定性溢价（对应对冲/保险需求）。
- **公式**：$\text{LV10} = \left[-\tfrac{1}{\lfloor 0.05n\rfloor}\sum_{r_i \le q_{0.05}(r)} r_i\right]^{-1}$（n=60 日）
- **伪代码**：`q = r.rolling(60).quantile(0.05); cvar = r[r<=q].rolling(60).mean(); lv10 = 1.0/(-cvar)`
- **数据来源**：[本地] 日线收盘价

### LV-11 收益分布偏度（负偏溢价）

- **经济学解释**：正偏 = 彩票型收益（大量小赚+偶尔暴涨），散户偏爱导致高估；负偏或低正偏股票被低估，反转溢价（Boyer et al. 2010 skewness premium）。
- **公式**：$\text{LV11} = -\text{Skew}_{60}(r)$（负偏度为正因子）
- **伪代码**：`lv11 = -r.rolling(60).skew()`
- **数据来源**：[本地] 日线收盘价

### LV-12 收益峰度倒数（薄尾偏好）

- **经济学解释**：高峰度 = 极端事件频发（尾部厚）；低峰度 = 分布温和，风险可预期性高。
- **公式**：$\text{LV12} = \left[\text{Kurt}_{60}(r)\right]^{-1}$
- **伪代码**：`lv12 = 1.0 / r.rolling(60).kurt()`
- **数据来源**：[本地] 日线收盘价

### LV-13 波动率聚集度倒数（|r| 自相关）

- **经济学解释**：波动率聚集（GARCH 效应）强 = 风险状态难测；聚集度低 = 波动平稳。
- **公式**：$\text{LV13} = \left[Corr(|r_t|, |r_{t-1}|)_{60}\right]^{-1}$
- **伪代码**：`a = r.abs(); lv13 = 1.0 / a.autocorr().rolling(60).mean()`（逐股时序计算）
- **数据来源**：[本地] 日线收盘价

### LV-14 波动率趋势（短/长波动比倒数）

- **经济学解释**：短期波动低于长期 = 波动处于下行通道（风险释放中）；反之风险积聚。
- **公式**：$\text{LV14} = \sigma_{20} / \sigma_{120}$（<1 表示波动收敛，正向化即取此比值倒数语义：比值小者优 → 直接用比值）
- **伪代码**：`lv14 = r.rolling(20).std() / (r.rolling(120).std()+1e-10)`
- **数据来源**：[本地] 日线收盘价

### LV-15 换手率波动倒数（协同低波）

- **经济学解释**：换手率波动 = 投机情绪起伏；换手稳定 = 持仓结构稳定（与低波动协同，捕捉"安静股"）。
- **公式**：$\text{LV15} = \left[std_{60}(V_t/\text{float\_shares}_t)\right]^{-1}$（float 不足用 V 的 std 近似）
- **伪代码**：`turn = V / float_shares; lv15 = 1.0/turn.rolling(60).std()`
- **数据来源**：[本地] 成交量 + [外部-可选] 流通股本（无则用 `1/std(V).rolling(60)` 退化版）

### LV-16 隔夜/日内风险比倒数

- **经济学解释**：A 股隔夜跳空（涨跌停/信息冲击）与日内波动之比高 = 信息驱动风险大；日内相对稳定的股票更可交易。
- **公式**：$\sigma_{gap,t}=\sqrt{mean_{20}\left(\left(\tfrac{O_t}{C_{t-1}}-1\right)^2\right)}$；$\text{LV16} = \sigma_{intraday}/\sigma_{gap}$（日内波动/隔夜波动）
- **伪代码**：`gap = O/C.shift()-1; intra = (C/O-1).abs(); lv16 = intra.rolling(20).std()/(gap.rolling(20).std()+1e-10)`
- **数据来源**：[本地] 日线 OHLC

### LV-17 日收益绝对偏离倒数

- **经济学解释**：$\sum|r-\bar r|$ 是 L1 风险度量，对极端值稳健；低绝对偏离 = 稳定收益流。
- **公式**：$\text{LV17} = \left[\tfrac{1}{n}\sum_{i=1}^{n}|r_{t-i+1}-\bar r_n|\right]^{-1}$，$n=60$
- **伪代码**：`lv17 = 1.0 / r.sub(r.rolling(60).mean()).abs().rolling(60).mean()`
- **数据来源**：[本地] 日线收盘价

### LV-18 长期波动率倒数（120 日）

- **经济学解释**：长期波动率更稳定地刻画公司风险等级，减少短期噪音（与 20 日互补）。
- **公式**：$\text{LV18} = \left[\sqrt{252}\cdot std_{120}(r)\right]^{-1}$
- **伪代码**：`lv18 = 1.0 / (r.rolling(120).std()*sqrt(252))`
- **数据来源**：[本地] 日线收盘价

### LV-19 非流动性调整波动（Amihud 波动成分倒数）

- **经济学解释**：单位成交额引起的价格波动大 = 流动性差且定价脆弱；"波动/流动性"联合度量更贴近真实可交易风险。
- **公式**：$\text{Amihud}_t = \dfrac{|r_t|}{A_t}$；$\text{LV19} = \left[std_{60}(\text{Amihud})\right]^{-1}$
- **伪代码**：`amihud = r.abs()/A; lv19 = 1.0/amihud.rolling(60).std()`
- **数据来源**：[本地] 日线收盘价 + 成交额

### LV-20 波动率冲击衰减速度

- **经济学解释**：大波动后衰减快的股票（冲击吸收快）风险恢复能力强；衰减慢 = 风险持续高企。
- **公式**：$\text{LV20} = \rho\big(|r|_t, |r|_{t-1}\big)^{-1}$ 的替代：用 5 日后 |r| 与当日 |r| 的比值倒数：$\left[\frac{mean_5(|r_{t+1..t+5}|)}{|r_t|}\right]$ 的时序均值倒数
- **伪代码**：`imp = r.abs(); ratio = imp.rolling(5).mean()/imp; lv20 = 1.0/ratio.rolling(60).mean()`
- **数据来源**：[本地] 日线收盘价（注：公式内不引入未来，rolling 左对齐即可）

### LV-21 涨跌停触达频率倒数（A 股特有）

- **经济学解释**：频繁触涨跌停 = 投机资金主导 + 流动性扭曲；A 股特有的制度风险。
- **公式**：$\text{LV21} = \left[1 + \text{count}_{120}(r_t \ge 0.095 \text{ or } r_t \le -0.095)\right]^{-1}$
- **伪代码**：`limit = ((r>=0.095)|(r<=-0.095)).astype(int).rolling(120).sum(); lv21 = 1.0/(1+limit)`
- **数据来源**：[本地] 日线收盘价

### LV-22 已实现波动率分位（自身历史分位倒数）

- **经济学解释**：当前波动率处于自身历史低位 = 风险状态偏低；分位化消除公司间波动水平差异（截面可比性更强）。
- **公式**：$\text{LV22} = 1 - \text{rank}_{250}\left(RV_{20,t}\right)$（当前 RV 在自身 250 日分布中的分位，取倒数语义）
- **伪代码**：`pct = rv20.rolling(250).apply(lambda x: (x.iloc[-1]<=x).mean()); lv22 = 1.0 - pct`
- **数据来源**：[本地] 日线收盘价

> **族内去冗余提示**：LV-01/02/05/18 高度相关（不同窗/口径的波动率），LV-06/07 同源 beta，LV-11/12 同属高阶矩——进入 PKF 时聚类会自动合并，建议人工首期挑 5~6 个跨子方向代表：LV-01（总波动）、LV-05（特异波动）、LV-09（回撤）、LV-11（偏度）、LV-14（波动趋势）、LV-21（A股制度）。

## 二、质量族（Quality）—— 23 个

**经济学逻辑（族）**：质量 = 公司盈利的**水平、稳定性与真实性**。行为学上市场对复杂会计信息反应不足（underreaction）；制度上 A 股财报质量分化大，盈余管理普遍 → 高质量公司持续被低估（Novy-Marx 2013 gross profitability；Piotroski 2000 F-score）。**方向**：族内全部正向化，数值越大 → 预期收益越高。

### QL-01 ROE（净资产收益率）

- **经济学解释**：股东资金创造回报的能力，质量因子核心；高 ROE 公司有经济护城河（巴菲特标准）。
- **公式**：$\text{QL1}=\dfrac{NI_{TTM}}{BV_{avg}}$
- **伪代码**：`ql01 = ni_ttm / bv.rolling(2).mean()`
- **数据来源**：[本地] `fundamental_ml_v2` 的 `roe` 字段直接取用

### QL-02 ROA（总资产收益率）

- **经济学解释**：全部资产（含负债）的回报效率，杠杆中性的盈利质量指标。
- **公式**：$\text{QL2}=\dfrac{NI_{TTM}}{TotalAssets_{avg}}$
- **伪代码**：`ql02 = ni_ttm / ta.rolling(2).mean()`
- **数据来源**：[本地] 部分支撑（需 `total_assets`）；缺失时用 `roe * equity_ratio` 近似

### QL-03 毛利率（Gross Margin）

- **经济学解释**：定价权与成本结构的直接体现（Novy-Marx：毛利率高 = 商业模式优，盈利增长更持久）。
- **公式**：$\text{QL3}=\dfrac{Sales-COGS}{Sales}$
- **伪代码**：`ql03 = gross_margin`（[本地] 字段直接取用）
- **数据来源**：[本地] `fundamental_ml_v2.gross_margin`

### QL-04 净利率（Net Margin）

- **经济学解释**：费用控制能力；高净利率 = 盈利含金量高（相对毛利率更能反映费用纪律）。
- **公式**：$\text{QL4}=\dfrac{NI}{Sales}$
- **伪代码**：`ql04 = npm`（[本地] 字段直接取用）
- **数据来源**：[本地] `fundamental_ml_v2.npm`

### QL-05 经营利润率（Operating Margin）

- **经济学解释**：主业盈利（剔除投资收益/非经常损益），衡量核心经营质量。
- **公式**：$\text{QL5}=\dfrac{EBIT}{Sales}$
- **伪代码**：`ql05 = (ni + interest_exp + tax) / sales`（[外部-财报] 利息/税；简化可用 `npm * (1 + 非经常占比修正)`）
- **数据来源**：[本地] 近似 + [外部-财报] 利润表明细

### QL-06 ROE 稳定性

- **经济学解释**：高而稳的 ROE 优于高而波动的 ROE——可预测性溢价 + 盈余管理嫌疑更低。
- **公式**：$\text{QL6}=\left[std_{5y}(ROE)\right]^{-1}$
- **伪代码**：`ql06 = 1.0 / stab_roe`（[本地] 字段 `stab_roe` 为波动，直接取倒数）
- **数据来源**：[本地] `fundamental_ml_v2.stab_roe`

### QL-07 毛利率稳定性

- **经济学解释**：毛利率稳定 = 竞争格局稳定（定价权稳固）；毛利率剧烈波动 = 竞争恶化或成本失控。
- **公式**：$\text{QL7}=\left[std_{5y}(GM)\right]^{-1}$
- **伪代码**：`ql07 = 1.0 / stab_gm`（[本地] 字段 `stab_gm`）
- **数据来源**：[本地] `fundamental_ml_v2.stab_gm`

### QL-08 ROE 趋势（Delta ROE）

- **经济学解释**：ROE 上行 = 经营拐点（改革/产品周期/行业出清）；市场对改善反应滞后。
- **公式**：$\text{QL8}=\text{ROE}_{t}-\text{ROE}_{t-4q}$
- **伪代码**：`ql08 = delta_roe`（[本地] 字段直接取用）
- **数据来源**：[本地] `fundamental_ml_v2.delta_roe`

### QL-09 应计比率反向（Accruals）

- **经济学解释**：应计利润（NI−OCF）高 = 盈余管理嫌疑（Sloan 1996 accrual anomaly）；低应计 = 现金流支撑的真实盈利。
- **公式**：$\text{QL9}=-\dfrac{NI_{TTM}-OCF_{TTM}}{TotalAssets}$
- **伪代码**：`ql09 = -accruals`（[本地] 字段已为应计，取负号正向化）
- **数据来源**：[本地] `fundamental_ml_v2.accruals`

### QL-10 盈利现金含量（OCF/NI）

- **经济学解释**：每元净利润对应的经营现金流；>1 = 盈利是真金白银，<0.5 = 纸面利润。
- **公式**：$\text{QL10}=\dfrac{OCF_{TTM}}{NI_{TTM}}$
- **伪代码**：`ql10 = ocf_eps_ratio`（[本地] 字段直接取用；若为其 EPS 口径，用 `ocf_ttm/ni_ttm` 重算更准）
- **数据来源**：[本地] `fundamental_ml_v2.ocf_eps_ratio` / 现金流量表

### QL-11 Piotroski F-Score

- **经济学解释**：9 项财务信号综合（盈利性/杠杆流动性/运营效率），经典基本面质量打分（Piotroski 2000），高 F 公司价值股中显著跑赢。
- **公式**：$\text{QL11}=\sum_{k=1}^{9}\mathbb{1}[s_k>0]$（ROA>0, CFO>0, ΔROA>0, Accrual<0, ΔLev<0, ΔLiquidity>0, 无稀释, ΔGM>0, ΔTurnover>0）
- **伪代码**：`ql11 = f_score`（[本地] 字段直接取用，已按 9 项计分）
- **数据来源**：[本地] `fundamental_ml_v2.f_score`

### QL-12 杠杆率反向（资产负债率）

- **经济学解释**：高杠杆 = 财务风险与再融资压力；低杠杆公司抗周期能力强（质量防御属性）。
- **公式**：$\text{QL12}=1-\dfrac{TotalDebt}{TotalAssets}$
- **伪代码**：`ql12 = 1.0 - debt_ratio`
- **数据来源**：[本地] 部分（需 `debt_ratio`）；缺失用 `1/(1+debt_to_equity)` 近似

### QL-13 利息覆盖率

- **经济学解释**：EBIT/利息费用衡量偿债安全边际；覆盖不足 = 盈利被财务费用吞噬。
- **公式**：$\text{QL13}=\dfrac{EBIT}{InterestExpense}$
- **伪代码**：`ql13 = ebit / interest_exp`（[外部-财报] 利息费用）
- **数据来源**：[外部-财报] 利润表/附注（本地无利息字段）

### QL-14 资产周转率

- **经济学解释**：Sales/TotalAssets = 资产使用效率；高周转 = 轻资产运营/渠道效率（杜邦第三因子）。
- **公式**：$\text{QL14}=\dfrac{Sales_{TTM}}{TotalAssets_{avg}}$
- **伪代码**：`ql14 = sales_ttm / ta.rolling(2).mean()`
- **数据来源**：[本地] 部分（需 total_assets）；可 `npm*roa` 反推

### QL-15 杜邦分解综合分

- **经济学解释**：ROE = 净利率×周转×杠杆；三项均高分 = 高质量高增长，综合分消除单项畸变。
- **公式**：$\text{QL15}=z(NPM)+z(Turnover)+z(EquityMult)^{-1}$（倒数化杠杆）
- **伪代码**：`ql15 = zscore(npm) + zscore(turnover) - zscore(debt_ratio)`
- **数据来源**：[本地] 合成（npm + 周转 + 杠杆）

### QL-16 盈利波动率反向

- **经济学解释**：营收/利润增长波动大 = 商业模式不稳定；低波动增长 = 可预测性溢价。
- **公式**：$\text{QL16}=\left[std_{5y}(\Delta Sales)\right]^{-1}$
- **伪代码**：`ql16 = 1.0 / rev_growth_vol`（[本地] 字段 `rev_growth_vol`）
- **数据来源**：[本地] `fundamental_ml_v2.rev_growth_vol`

### QL-17 亏损风险反向

- **经济学解释**：历史亏损频率高 = 盈利脆弱；从不亏损的公司财务稳定性强。
- **公式**：$\text{QL17}=1-\dfrac{\#\{NI_t<0\}_{5y}}{20}$
- **伪代码**：`ql17 = 1.0 - loss_risk`（[本地] 字段 `loss_risk`）
- **数据来源**：[本地] `fundamental_ml_v2.loss_risk`

### QL-18 增长质量（增长×现金含量）

- **经济学解释**：高增长 + 高现金含量 = 真实增长；高增长 + 低现金含量 = 应收堆出来的增长。
- **公式**：$\text{QL18}=\text{rev\_growth}\times\min(1,\tfrac{OCF}{NI})$
- **伪代码**：`ql18 = rev_growth * ocf_ni.clip(upper=1.0)`
- **数据来源**：[本地] `rev_growth` + `ocf_eps_ratio`

### QL-19 再投资效率

- **经济学解释**：单位新增资产创造的 ROE 增量；再投资效率高 = 资本配置能力强（增长有质量）。
- **公式**：$\text{QL19}=\dfrac{\Delta ROE}{\Delta BV/BV}$
- **伪代码**：`ql19 = delta_roe / delta_bv`（[本地] `delta_bv` 字段）
- **数据来源**：[本地] `fundamental_ml_v2.delta_roe` + `delta_bv`

### QL-20 现金转换周期反向（CCC）

- **经济学解释**：CCC = DIO+DSO−DPO；营运资金效率高（短 CCC）= 现金流生成快，占用资金少。
- **公式**：$\text{QL20}=-\left(DIO+DSO-DPO\right)$
- **伪代码**：`ccc = dio + dso - dpo; ql20 = -ccc`（[外部-财报] 存货/应收/应付周转）
- **数据来源**：[外部-财报] 资产负债表 + 利润表（本地无周转明细）

### QL-21 商誉/资产反向（Goodwill）

- **经济学解释**：商誉占比高 = 并购溢价风险（减值炸弹）；低商誉 = 内生增长更真实。
- **公式**：$\text{QL21}=1-\dfrac{Goodwill}{TotalAssets}$
- **伪代码**：`ql21 = 1.0 - goodwill/ta`（[外部-财报] 商誉字段）
- **数据来源**：[外部-财报] 资产负债表（本地无）

### QL-22 股东权益增长率

- **经济学解释**：BV 增长 = 留存收益积累，体现内生造血能力（高质量成长）。
- **公式**：$\text{QL22}=\dfrac{BV_t}{BV_{t-1}}-1$
- **伪代码**：`ql22 = delta_bv`（[本地] 字段）
- **数据来源**：[本地] `fundamental_ml_v2.delta_bv`

### QL-23 毛利率×周转率（GPM × Turnover）

- **经济学解释**：高毛利 + 高周转的组合罕见 = 强定价权 + 强运营效率同时具备（Novy-Marx gross profitability 的强度版本）。
- **公式**：$\text{QL23}=\text{GM}\times\text{AssetTurnover}$
- **伪代码**：`ql23 = gross_margin * turnover`
- **数据来源**：[本地] `gross_margin` + 合成周转

> **族内去冗余提示**：QL-01/02/15 同根（ROE 系），QL-03/04/05 同根（利润率系），QL-06/07/16/17 同根（稳定性系）——建议首期挑：QL-01（ROE）、QL-09（应计）、QL-11（F-Score）、QL-03（毛利率）、QL-12（杠杆）、QL-18（增长质量）。

## 三、价值族（Value）—— 21 个

**经济学逻辑（族）**：价值 = 相对内在价值便宜。行为学上投资者对近期增长过度外推（representativeness），对困难期公司过度悲观；制度上 A 股个人投资者占比高、信息不对称大 → 低估修复周期更长、幅度更大（Fama-French HML；A 股价值因子长期有效但 2019-2021 成长占优、2022-2023 价值回归，属典型周期性）。**方向**：全部正向化（贵 = 小，便宜 = 大），数值越大 → 预期收益越高。

### VL-01 盈利收益率（E/P）

- **经济学解释**：市盈率倒数的经济学含义是"每元股价的盈利回报率"，直接可比无风险利率；低 PE = 便宜（经典价值锚，Fama-French）。
- **公式**：$\text{VL1}=\dfrac{EPS_{TTM}}{P}$
- **伪代码**：`vl01 = 1.0 / pe`（[本地] 字段 `pe`）
- **数据来源**：[本地] `fundamental_ml_v2.pe`

### VL-02 账面市值比（B/P）

- **经济学解释**：清算价值视角的便宜度；高 B/P = 市场对公司资产定价保守（HML 核心；A 股银行/周期股典型）。
- **公式**：$\text{VL2}=\dfrac{BV}{MV}$
- **伪代码**：`vl02 = 1.0 / pb`（[本地] 字段 `pb`）
- **数据来源**：[本地] `fundamental_ml_v2.pb`

### VL-03 市销率倒数（S/P）

- **经济学解释**：营收不受会计利润操纵影响；对亏损股（PE 无意义）唯一可用的价值锚。
- **公式**：$\text{VL3}=\dfrac{Sales_{TTM}}{MV}$
- **伪代码**：`vl03 = sp`（[本地] 字段 `sp`）
- **数据来源**：[本地] `fundamental_ml_v2.sp`

### VL-04 经营现金流价格比（OCF/P）

- **经济学解释**：现金流最不易被操纵（相对净利润）；现金收益率高 = 真实便宜（价值+现金流交叉）。
- **公式**：$\text{VL4}=\dfrac{OCF_{TTM}}{MV}$
- **伪代码**：`vl04 = cfy`（[本地] 字段 `cfy`）
- **数据来源**：[本地] `fundamental_ml_v2.cfy`

### VL-05 自由现金流价格比（FCF/P）

- **经济学解释**：FCF 剔除维持性资本开支，是股东可支配现金；FCF/P 高 = 估值安全边际最扎实。
- **公式**：$\text{VL5}=\dfrac{OCF_{TTM}-CapEx_{TTM}}{MV}$
- **伪代码**：`fcf = ocf_ttm - capex_ttm; vl05 = fcf / mv`（[外部-财报] 资本开支）
- **数据来源**：[外部-财报] 现金流量表 CapEx（本地无，`cfy` 为退化替代）

### VL-06 息税前盈利收益率（EBIT/EV）

- **经济学解释**：企业价值口径（含净债务）比市值口径更公平——不同杠杆公司的盈利回报可比（Greenblatt 2010 magic formula 核心）。
- **公式**：$\text{VL6}=\dfrac{EBIT_{TTM}}{EV},\quad EV=MV+NetDebt$
- **伪代码**：`vl06 = ebit_ttm / (mv + net_debt)`（[外部-财报] 净债务）
- **数据来源**：[外部-财报] 净债务（本地部分支撑）

### VL-07 企业价值倍数倒数（1/EV/EBITDA）

- **经济学解释**：EBITDA 近似经营现金流（不含折旧摊销），EV/EBITDA 低 = 并购估值视角便宜。
- **公式**：$\text{VL7}=\dfrac{EBITDA_{TTM}}{EV}$
- **伪代码**：`vl07 = ebitda_ttm / (mv + net_debt)`（[外部-财报]）
- **数据来源**：[外部-财报] EBITDA

### VL-08 股息率（D/P）

- **经济学解释**：最"硬"的价值信号——现金分红不可造假；高股息 = 低估 + 股东回报意愿（价值×红利交叉，详见族四）。
- **公式**：$\text{VL8}=\dfrac{DPS_{TTM}}{P}$
- **伪代码**：`vl08 = dps_ttm / close`（[本地] dividend_data + 价格）
- **数据来源**：[本地] `dividend_data` + 日线价格

### VL-09 历史估值分位反向（PE 自身分位）

- **经济学解释**：当前 PE 处于自身 10 年分位的低位 = 相对自身历史便宜（跨期可比，消除行业 PE 水平差异）。
- **公式**：$\text{VL9}=1-\text{rank}_{2500}(PE_t)$（PE 在自身 10 年分布的分位）
- **伪代码**：`vl09 = 1.0 - pe_pct`（[本地] 字段 `pe_pct`）
- **数据来源**：[本地] `fundamental_ml_v2.pe_pct`

### VL-10 PB 历史分位反向

- **经济学解释**：PB 分位对 ROE 结构性变化更敏感，与 PE 分位互补。
- **公式**：$\text{VL10}=1-\text{rank}_{2500}(PB_t)$
- **伪代码**：`vl10 = 1.0 - pb_pct`（[本地] 字段 `pb_pct`）
- **数据来源**：[本地] `fundamental_ml_v2.pb_pct`

### VL-11 估值改善（Delta E/P）

- **经济学解释**：E/P 上升 = 盈利改善或价格下跌创造价值；"变便宜"信号比"一直便宜"更强（价值动量交叉）。
- **公式**：$\text{VL11}=\left(\dfrac{EPS_{TTM}}{P}\right)_t-\left(\dfrac{EPS_{TTM}}{P}\right)_{t-4q}$
- **伪代码**：`vl11 = ep - ep.shift(4q)`
- **数据来源**：[本地] `pe` 合成（季度对齐）

### VL-12 PEG 反向

- **经济学解释**：PE 相对盈利增速的合理性；低 PEG = 增长与估值匹配（成长价值平衡，Peter Lynch）。
- **公式**：$\text{VL12}=\dfrac{g_{EPS}}{PE},\quad g=$ 未来/历史 3-5 年盈利增速
- **伪代码**：`vl12 = eps_growth / pe`（增速用历史 5 年 CAGR 近似，避免未来函数）
- **数据来源**：[本地] `pe` + 历史 EPS 序列

### VL-13 Graham 数

- **经济学解释**：格雷厄姆防御性估值 $\sqrt{22.5\times EPS\times BVPS}$ 衡量内在价值锚；价格低于 Graham 数越多越安全。
- **公式**：$\text{VL13}=\dfrac{\sqrt{22.5\times EPS\times BVPS}}{P}$
- **伪代码**：`graham = sqrt(22.5*eps*bvps); vl13 = graham / close`
- **数据来源**：[本地] `pe`/`pb` 反推 EPS、BVPS

### VL-14 托宾 Q 反向（资产重置成本）

- **经济学解释**：Q = MV/重置成本；Q 低 = 资产市场定价低于重置成本（周期股/破净股价值回归逻辑）。
- **公式**：$\text{VL14}=\dfrac{BookValue}{MV}$
- **伪代码**：`vl14 = 1.0/pb`（BV/MV 即 PB 倒数，与 VL-02 同源——作为不同窗口版本保留）
- **数据来源**：[本地] `pb`（PB 为 Tobin Q 的会计近似）

### VL-15 周期调整盈利收益率（CAPE 反向）

- **经济学解释**：用 10 年平均盈利平滑周期（Shiller CAPE）；周期股在盈利顶部 PE 最低但最贵，CAPE 修正此偏差。
- **公式**：$\text{VL15}=\dfrac{\overline{EPS}_{10y}}{P}$
- **伪代码**：`cape_ep = eps.rolling(10y).mean() / close; vl15 = cape_ep`
- **数据来源**：[本地] 历史 EPS 序列（需 10 年，[外部-财报] 补充早期数据）

### VL-16 行业相对估值

- **经济学解释**：行业内相对便宜（相对 PE/PB 分位）消除行业间估值水平系统性差异（银行 vs 医药），A 股行业分化极大时尤其重要。
- **公式**：$\text{VL16}=\text{rank}_{ind}(E/P)$（行业内 E/P 排名）
- **伪代码**：`vl16 = df.groupby('industry')['ep'].rank(pct=True)`
- **数据来源**：[本地] `industry_map.parquet` + `pe`

### VL-17 价值陷阱规避（E/P × 质量）

- **经济学解释**：便宜 + 高质量（盈利稳定）才值得买；便宜 + 恶化（价值陷阱）会持续下跌——交叉因子过滤陷阱（Piotroski 组合思想）。
- **公式**：$\text{VL17}=\text{VL1}\times z(\text{QL1})$
- **伪代码**：`vl17 = ep * zscore(roe)`
- **数据来源**：[本地] `pe` + `roe`

### VL-18 股东收益率（E/P + 股息率）

- **经济学解释**：总股东回报视角（盈利 + 分红），覆盖留存与分配，比单一 E/P 更全面。
- **公式**：$\text{VL18}=\dfrac{EPS_{TTM}+DPS_{TTM}}{P}$
- **伪代码**：`vl18 = (eps_ttm + dps_ttm)/close`
- **数据来源**：[本地] `pe` 反推 EPS + `dividend_data`

### VL-19 账面价值增长调整（ΔB/P）

- **经济学解释**：B/P 上升（净资产增长快于股价）= 内在价值在积累而价格未反映。
- **公式**：$\text{VL19}=\left(\dfrac{BV}{MV}\right)_t-\left(\dfrac{BV}{MV}\right)_{t-4q}$
- **伪代码**：`vl19 = bp - bp.shift(4q)`
- **数据来源**：[本地] `pb` 合成

### VL-20 盈利修正价值（分析师 EPS 上修）

- **经济学解释**：分析师上调盈利预测 = 基本面预期改善，价值 + 预期差双重信号（post-revision drift）。
- **公式**：$\text{VL20}=\dfrac{\Delta EPS\_est_{1m}}{EPS\_est}$（1 个月 EPS 预测上修幅度）
- **伪代码**：`vl20 = eps_est.pct_change(21)`（[外部-可选] 分析师数据）
- **数据来源**：[外部-可选] 分析师一致预期（无则跳过，不阻塞族）

### VL-21 长期盈利收益率（10 年均值盈利/价格）

- **经济学解释**：区别于 CAPE 用"当前价/长期盈利"，此因子用长期盈利直接贴现，衡量可持续盈利视角的便宜度（Graham 式）。
- **公式**：$\text{VL21}=\dfrac{\overline{EPS}_{10y}\times payout}{P}$（可选乘派息率增强稳健）
- **伪代码**：`vl21 = eps.rolling(10y).mean()*payout_ratio / close`
- **数据来源**：[本地] 历史 EPS + `dividend_data`

> **族内去冗余提示**：VL-01/08/18 同根（盈利/股息收益率），VL-02/14 同根（PB），VL-06/07 同根（EV 口径），VL-09/10 同根（历史分位）——建议首期挑：VL-01（E/P）、VL-02（B/P）、VL-05（FCF/P，外部数据齐备后）、VL-06（EBIT/EV）、VL-16（行业相对）、VL-17（价值陷阱规避）。

## 四、红利族（Dividend）—— 21 个

**经济学逻辑（族）**：红利 = 确定性溢价的直接载体。行为学上市场对"到手的现金"与"账面利润"定价不同，分红降低代理成本（Jensen 1986 FCF 假说）、传递盈利质量信号（signaling）；制度上 A 股 2024 年起监管鼓励分红、中证红利指数长期跑赢 → 红利因子兼具价值与防御双重属性。**方向**：全部正向化，数值越大 → 预期收益越高。

### DV-01 TTM 股息率

- **经济学解释**：过去 12 个月每股分红/股价——红利因子最核心的原始量（A 股红利风格基准）。
- **公式**：$\text{DV1}=\dfrac{DPS_{TTM}}{P}$
- **伪代码**：`dv01 = dps_ttm / close`（[本地] `divid_data` 按除权日滚动 12 个月）
- **数据来源**：[本地] `dividend_data`（`dividCashPsBeforeTax`）+ 日线价格

### DV-02 派息率（Payout Ratio）

- **经济学解释**：DPS/EPS = 利润分配比例；高派息 = 回报股东意愿强 + 盈利真实（假利润派不出息）。
- **公式**：$\text{DV2}=\dfrac{DPS_{TTM}}{EPS_{TTM}}$
- **伪代码**：`dv02 = dps_ttm / eps_ttm`
- **数据来源**：[本地] `dividend_data` + `pe` 反推 EPS

### DV-03 股息覆盖倍数（EPS/DPS）

- **经济学解释**：每元分红的盈利支撑（覆盖>2 = 分红可持续，<1 = 透支）；可持续性比水平更重要。
- **公式**：$\text{DV3}=\dfrac{EPS_{TTM}}{DPS_{TTM}}$
- **伪代码**：`dv03 = eps_ttm/dps_ttm`（>0 保护）
- **数据来源**：[本地] `dividend_data` + `pe`

### DV-04 连续分红年数

- **经济学解释**：分红历史长度 = 分红承诺可信度；连续 5/10 年分红 = 政策稳定（A 股"长期分红"公司稀缺）。
- **公式**：$\text{DV4}=\#\{y: DPS_y>0\}_{10y}$
- **伪代码**：`dv04 = (annual_dps>0).sum()`（10 年窗口）
- **数据来源**：[本地] `dividend_data`（需 10 年历史，[外部-财报] 补早期）

### DV-05 股息增长率（DPS CAGR）

- **经济学解释**：分红持续增长 = 盈利成长 + 回报提升双引擎（红利成长风格）。
- **公式**：$\text{DV5}=g_{DPS,5y}=\left(\dfrac{DPS_t}{DPS_{t-5y}}\right)^{1/5}-1$
- **伪代码**：`dv05 = (dps_t / dps_5y_ago)**0.2 - 1`
- **数据来源**：[本地] `dividend_data` 年度对齐

### DV-06 股息稳定性（DPS 变异系数倒数）

- **经济学解释**：DPS 波动小 = 分红纪律强（宁稳勿变）；波动大 = 可能随利润周期大起大落。
- **公式**：$\text{DV6}=\dfrac{\mu_{DPS}}{\sigma_{DPS}}$（5 年）
- **伪代码**：`dv06 = dps.annual.mean()/dps.annual.std()`
- **数据来源**：[本地] `dividend_data`

### DV-07 红利收益率贡献度（股息占总回报比）

- **经济学解释**：长期回报中分红贡献占比高的公司，回报结构更依赖现金流而非估值扩张（更可预测）。
- **公式**：$\text{DV7}=\dfrac{\sum DPS_{5y}}{\text{TR}_{5y}}$（TR 含再投资的总回报）
- **伪代码**：`dv07 = dps.sum(5y) / (close_t/close_5y_ago + dps.sum(5y)/close_5y_ago)`
- **数据来源**：[本地] `dividend_data` + 价格

### DV-08 红利质量（股息率 × 盈利质量）

- **经济学解释**：高股息 + 高现金含量（OCF/NI）才可持续；防止"高股息陷阱"（盈利恶化但仍分红）。
- **公式**：$\text{DV8}=\text{DV1}\times \min(1,\tfrac{OCF}{NI})$
- **伪代码**：`dv08 = dv01 * ocf_ni.clip(upper=1)`
- **数据来源**：[本地] `dividend_data` + `ocf_eps_ratio`

### DV-09 红利增长潜力（可持续增长率）

- **经济学解释**：Gordon 模型视角，g = ROE×留存率；高 ROE + 合理留存 = 未来分红能力提升。
- **公式**：$\text{DV9}=\text{ROE}\times(1-\text{payout})$
- **伪代码**：`dv09 = roe * (1 - payout)`
- **数据来源**：[本地] `roe` + `dividend_data`

### DV-10 派息政策一致性（派息率稳定性）

- **经济学解释**：派息率围绕目标值稳定 = 明确的分红政策（管理层承诺）；大幅摆动 = 无政策可言。
- **公式**：$\text{DV10}=\left[std_{5y}(payout)\right]^{-1}$
- **伪代码**：`dv10 = 1.0/payout.rolling(5y).std()`
- **数据来源**：[本地] `dividend_data` + `pe`

### DV-11 分红覆盖充足率（OCF/DPS）

- **经济学解释**：经营现金流对分红的覆盖（>2 倍安全）；覆盖不足 = 借钱/变卖资产分红。
- **公式**：$\text{DV11}=\dfrac{OCF_{TTM}}{DPS_{TTM}}$
- **伪代码**：`dv11 = ocf_ttm / (dps_ttm * shares)`（[外部-财报] 股本）
- **数据来源**：[本地] `ocf_per_share` + `dividend_data`

### DV-12 红利低波复合

- **经济学解释**：红利 × 低波动双因子（中证红利低波指数逻辑）——确定性溢价 × 防御属性，1+1>2 的经典组合。
- **公式**：$\text{DV12}=z(\text{DV1})\times z(\text{LV1})$
- **伪代码**：`dv12 = zscore(dv01) * zscore(lv01)`
- **数据来源**：[本地] 合成

### DV-13 行业相对股息率

- **经济学解释**：行业内股息率排名（银行/公用 vs 成长行业不可直接比）；行业内高股息 = 行业内被低估。
- **公式**：$\text{DV13}=\text{rank}_{ind}(D/P)$
- **伪代码**：`dv13 = df.groupby('industry')['dv01'].rank(pct=True)`
- **数据来源**：[本地] `industry_map.parquet` + `dividend_data`

### DV-14 股息率趋势（D/P 变化）

- **经济学解释**：股息率上升 = 价格下跌或分红提升——"变得更便宜/更慷慨"的边际信号。
- **公式**：$\text{DV14}=\left(\dfrac{DPS}{P}\right)_t-\left(\dfrac{DPS}{P}\right)_{t-12m}$
- **伪代码**：`dv14 = dv01 - dv01.shift(252)`
- **数据来源**：[本地] `dividend_data` + 价格

### DV-15 风险调整股息率（D/P ÷ 波动率）

- **经济学解释**：每单位波动的分红回报——红利 × 风险调整，识别"高股息但不折腾"的股票。
- **公式**：$\text{DV15}=\dfrac{D/P}{\sigma_{20}\sqrt{252}}$
- **伪代码**：`dv15 = dv01 / (r.rolling(20).std()*sqrt(252))`
- **数据来源**：[本地] 合成

### DV-16 稳定派息识别（连续 N 年股息率>阈值）

- **经济学解释**：连续 3 年股息率 > 2% 的"稳定派息股"识别——机构红利组合的构建口径。
- **公式**：$\text{DV16}=\min_{k=0..2}\mathbb{1}[D/P_{t-k\cdot12m} > 0.02]$
- **伪代码**：`dv16 = (dv01.rolling(3y).min() > 0.02).astype(float)`
- **数据来源**：[本地] `dividend_data` + 价格

### DV-17 分红+回购总回报率

- **经济学解释**：总股东回报（分红 + 回购）比单看分红更全面（A 股回购增多，机构口径 TRS）。
- **公式**：$\text{DV17}=\dfrac{DPS+BuybackPS}{P}$
- **伪代码**：`dv17 = (dps_ttm + buyback_ps)/close`（[外部-可选] 回购数据）
- **数据来源**：[外部-可选] 回购公告（无则 `dv01` 退化）

### DV-18 除权除息后表现（填权能力）

- **经济学解释**：除息后股价能填权 = 市场认可分红价值；长期填权率高的公司分红质量高。
- **公式**：$\text{DV18}=\text{mean}_{5y}\left(\dfrac{P_{t+60}}{P_{ex-div}}\right)$（除息日后 60 日收益均值）
- **伪代码**：`dv18 = post_exdiv_ret.rolling(5y).mean()`（需除权日标记，[本地] `dividRegistDate`）
- **数据来源**：[本地] `dividend_data`（`dividRegistDate/dividPayDate`）+ 价格

### DV-19 特别分红/高送转克制（现金分红纯度）

- **经济学解释**：现金分红为主（而非送转股/公积金转增）的公司回报更真实；高送转常伴随炒作。
- **公式**：$\text{DV19}=\dfrac{DPS_{cash}}{DPS_{cash}+PS_{stock}+PS_{reserve}}$
- **伪代码**：`dv19 = cash_ps/(cash_ps+stock_ps+reserve_ps)`（[本地] 字段 `dividCashPsBeforeTax/dividStocksPs/dividReserveToStockPs`）
- **数据来源**：[本地] `dividend_data`

### DV-20 盈利派息缺口反向（DPS - 每股收益）

- **经济学解释**：分红超过盈利（DPS>EPS）= 透支型分红，不可持续；缺口为负才健康。
- **公式**：$\text{DV20}=EPS_{TTM}-DPS_{TTM}$（留存为正）
- **伪代码**：`dv20 = eps_ttm - dps_ttm`
- **数据来源**：[本地] `pe` 反推 EPS + `dividend_data`

### DV-21 现金分红率趋势（分红增速 vs 盈利增速）

- **经济学解释**：分红增速超过盈利增速 = 管理层自信信号；落后 = 回报意愿下降。
- **公式**：$\text{DV21}=g_{DPS,3y}-g_{EPS,3y}$
- **伪代码**：`dv21 = dps_growth_3y - eps_growth_3y`
- **数据来源**：[本地] `dividend_data` + `pe` 序列

> **族内去冗余提示**：DV-01/08/12/15 同根（股息率系），DV-02/03/10/20 同根（派息率系），DV-04/06/16 同根（持续性系）——建议首期挑：DV-01（TTM 股息率）、DV-04（连续分红年数）、DV-08（红利质量）、DV-12（红利低波）、DV-19（现金分红纯度）。

## 五、现金流族（Cash Flow）—— 22 个

**经济学逻辑（族）**：现金流 = 盈利真实性 + 财务弹性的最终裁判。会计利润可被应计/减值/公允价值操纵，经营现金流与自由现金流最难造假；行为学上市场对现金流信息反应滞后（cash flow anomaly）；制度上 A 股应收/存货暴雷频发 → 现金流因子在 A 股有额外信息增量。**方向**：全部正向化，数值越大 → 预期收益越高。

### CF-01 经营现金流收益率（OCF/P）

- **经济学解释**：每元市价的经营现金流回报；现金流口径的价值锚（与 VL-04 同式，此处归族并强调现金流视角）。
- **公式**：$\text{CF1}=\dfrac{OCF_{TTM}}{MV}$
- **伪代码**：`cf01 = cfy`（[本地] 字段）
- **数据来源**：[本地] `fundamental_ml_v2.cfy`

### CF-02 自由现金流收益率（FCF/P）

- **经济学解释**：扣除维持性资本开支后的股东可支配现金流收益率——估值安全边际最硬指标（Damodaran 首选）。
- **公式**：$\text{CF2}=\dfrac{OCF_{TTM}-CapEx_{TTM}}{MV}$
- **伪代码**：`cf02 = (ocf_ttm - capex_ttm)/mv`（[外部-财报] CapEx）
- **数据来源**：[外部-财报] 现金流量表（本地 `ocf_per_share` 支撑 OCF 部分）

### CF-03 盈利现金含量（OCF/NI）

- **经济学解释**：每元净利润对应的经营现金流；>1 真金白银，<0.5 纸面繁荣（与 QL-10 同源，族内重复以强调，PKF 聚类自动去重）。
- **公式**：$\text{CF3}=\dfrac{OCF_{TTM}}{NI_{TTM}}$
- **伪代码**：`cf03 = ocf_eps_ratio`（[本地] 字段）
- **数据来源**：[本地] `fundamental_ml_v2.ocf_eps_ratio`

### CF-04 自由现金流含金量（FCF/NI）

- **经济学解释**：FCF 对净利润的比率；高 = 盈利完全转化为自由现金（无资本开支黑洞）。
- **公式**：$\text{CF4}=\dfrac{OCF_{TTM}-CapEx_{TTM}}{NI_{TTM}}$
- **伪代码**：`cf04 = (ocf_ttm-capex_ttm)/ni_ttm`
- **数据来源**：[外部-财报] CapEx + [本地] NI

### CF-05 经营现金流/营收（现金利润率）

- **经济学解释**：每元营收产生的经营现金流；高 = 收入质量好（应收少、回款快）。
- **公式**：$\text{CF5}=\dfrac{OCF_{TTM}}{Sales_{TTM}}$
- **伪代码**：`cf05 = ocf_ttm/sales_ttm`
- **数据来源**：[本地] 部分（OCF 每股 + 营收合成）

### CF-06 自由现金流/营收（FCF Margin）

- **经济学解释**：营收的现金留存能力；高 FCF margin = 商业模式现金流强（SaaS/公用事业特征）。
- **公式**：$\text{CF6}=\dfrac{OCF_{TTM}-CapEx_{TTM}}{Sales_{TTM}}$
- **伪代码**：`cf06 = (ocf_ttm-capex_ttm)/sales_ttm`
- **数据来源**：[外部-财报] CapEx + [本地] 营收

### CF-07 自由现金流/EBITDA（现金转化率）

- **经济学解释**：EBITDA 向 FCF 的转化率；高 = 折旧摊销少、营运资本占用低、资本开支轻。
- **公式**：$\text{CF7}=\dfrac{FCF_{TTM}}{EBITDA_{TTM}}$
- **伪代码**：`cf07 = fcf_ttm/ebitda_ttm`
- **数据来源**：[外部-财报] EBITDA

### CF-08 经营现金流/总资产（现金回报率）

- **经济学解释**：全部资产的现金生成效率——现金流版 ROA（杠杆中性）。
- **公式**：$\text{CF8}=\dfrac{OCF_{TTM}}{TotalAssets_{avg}}$
- **伪代码**：`cf08 = ocf_ttm/ta.rolling(2).mean()`
- **数据来源**：[本地] 部分（需 total_assets，[外部-财报] 补）

### CF-09 自由现金流/总资产

- **经济学解释**：FCF 资产回报率，衡量"资产创造自由现金"的能力（成长质量视角）。
- **公式**：$\text{CF9}=\dfrac{FCF_{TTM}}{TotalAssets_{avg}}$
- **伪代码**：`cf09 = fcf_ttm/ta.rolling(2).mean()`
- **数据来源**：[外部-财报] CapEx + [本地] 资产

### CF-10 每股经营现金流（OCFPS）

- **经济学解释**：每股口径的经营现金流，直接与股价配比（A 股财报披露标准指标）。
- **公式**：$\text{CF10}=\dfrac{OCF_{TTM}}{Shares}$
- **伪代码**：`cf10 = ocf_per_share`（[本地] 字段）
- **数据来源**：[本地] `fundamental_ml_v2.ocf_per_share`

### CF-11 现金/市值（现金持有）

- **经济学解释**：账面现金占总市值比高 = 净现金公司（防御 + 潜在回报能力）；A 股"类现金"低估值标的。
- **公式**：$\text{CF11}=\dfrac{Cash_{TTM}}{MV}$
- **伪代码**：`cf11 = cash/mv`（[外部-财报] 货币资金）
- **数据来源**：[外部-财报] 资产负债表（本地无货币资金字段）

### CF-12 净债务/OCF 反向

- **经济学解释**：净债务对经营现金流的倍数 = 偿债年限；低 = 财务弹性强（危机中存活能力）。
- **公式**：$\text{CF12}=\left[\dfrac{NetDebt}{OCF_{TTM}}\right]^{-1}$（净债务<0 视为最优，置大值）
- **伪代码**：`cf12 = 1.0/(net_debt/ocf_ttm).clip(upper=10)`
- **数据来源**：[外部-财报] 净债务

### CF-13 FCF 稳定性

- **经济学解释**：FCF 波动小 = 现金流的可预测性高（稳定现金流溢价）。
- **公式**：$\text{CF13}=\left[std_{5y}(FCF)\right]^{-1}$
- **伪代码**：`cf13 = 1.0/fcf.rolling(5y).std()`
- **数据来源**：[外部-财报] FCF 序列

### CF-14 FCF 趋势（ΔFCF）

- **经济学解释**：FCF 同比增长 = 现金创造力改善（经营拐点的现金流确认）。
- **公式**：$\text{CF14}=\dfrac{FCF_{TTM}-FCF_{TTM-4q}}{|FCF_{TTM-4q}|}$
- **伪代码**：`cf14 = fcf_ttm.pct_change(4q)`（注意符号保护）
- **数据来源**：[外部-财报] FCF 序列

### CF-15 现金流覆盖利息

- **经济学解释**：OCF/利息费用 = 现金口径的偿债能力（比 EBIT 覆盖更严格，不可被折旧美化）。
- **公式**：$\text{CF15}=\dfrac{OCF_{TTM}}{InterestExpense}$
- **伪代码**：`cf15 = ocf_ttm/interest_exp`（[外部-财报] 利息费用）
- **数据来源**：[外部-财报] 利润表/附注

### CF-16 现金流覆盖股息

- **经济学解释**：OCF/DPS 现金支出（与 DV-11 同源，族内重复以强调现金流视角）。
- **公式**：$\text{CF16}=\dfrac{OCF_{TTM}}{DPS_{TTM}}$
- **伪代码**：`cf16 = ocf_per_share/dps_ttm`
- **数据来源**：[本地] `ocf_per_share` + `dividend_data`

### CF-17 应计比率反向（Accruals，现金流版）

- **经济学解释**：NI−OCF 的资产占比；低应计 = 现金流支撑的盈利（Sloan 经典，与 QL-09 同式，现金流族核心成员）。
- **公式**：$\text{CF17}=-\dfrac{NI_{TTM}-OCF_{TTM}}{TotalAssets}$
- **伪代码**：`cf17 = -accruals`（[本地] 字段）
- **数据来源**：[本地] `fundamental_ml_v2.accruals`

### CF-18 现金转换周期反向（CCC）

- **经济学解释**：营运资金周转效率（与 QL-20 同式）；短 CCC = 现金回收快，占用少。
- **公式**：$\text{CF18}=-\left(DIO+DSO-DPO\right)$
- **伪代码**：`cf18 = -(dio+dso-dpo)`（[外部-财报] 周转明细）
- **数据来源**：[外部-财报] 资产负债表 + 利润表

### CF-19 资本开支强度反向（低 CapEx/Sales）

- **经济学解释**：CapEx/营收低 = 轻资产模式，自由现金留存高；重资本开支公司现金流被吞噬。
- **公式**：$\text{CF19}=1-\dfrac{CapEx_{TTM}}{Sales_{TTM}}$
- **伪代码**：`cf19 = 1.0 - capex_ttm/sales_ttm`
- **数据来源**：[外部-财报] CapEx

### CF-20 自由现金流增长（FCF 同比）

- **经济学解释**：FCF 增速 = 现金创造能力的扩张（区别于 CF-14 的边际变化，此处用年化增速）。
- **公式**：$\text{CF20}=\dfrac{FCF_{TTM}}{FCF_{TTM-1y}}-1$
- **伪代码**：`cf20 = fcf_ttm/fcf_ttm_1y_ago - 1`
- **数据来源**：[外部-财报] FCF 序列

### CF-21 经营现金流波动率反向

- **经济学解释**：OCF 波动大 = 经营现金流不稳定（季节/周期/项目制）；稳定 = 可预测。
- **公式**：$\text{CF21}=\left[std_{5y}(OCF)\right]^{-1}$
- **伪代码**：`cf21 = 1.0/ocf.rolling(5y).std()`
- **数据来源**：[外部-财报] OCF 序列

### CF-22 现金流盈利能力（OCF/股东权益）

- **经济学解释**：现金口径的 ROE——股东投入的现金回报（比会计 ROE 更"硬"）。
- **公式**：$\text{CF22}=\dfrac{OCF_{TTM}}{BV_{avg}}$
- **伪代码**：`cf22 = ocf_ttm/bv.rolling(2).mean()`
- **数据来源**：[本地] `ocf_per_share` + `pb` 反推 BV

> **族内去冗余提示**：CF-01/02/10/11 同根（收益率系），CF-03/04/17 同根（含金量系），CF-08/09/22 同根（资产回报系），CF-13/14/20/21 同根（稳定性/趋势系）——建议首期挑：CF-01（OCF/P）、CF-02（FCF/P）、CF-03（OCF/NI）、CF-17（应计）、CF-12（净债务/OCF）。
