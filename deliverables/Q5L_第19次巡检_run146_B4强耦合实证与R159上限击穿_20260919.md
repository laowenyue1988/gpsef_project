## 三、★本轮实质发现②：新候选 **R-159** —— `max_weight` 软上限被后处理重归一致**系统性击穿**（≤~1%）

### 3.1 触发

Q5C 两臂日志中 `max_w` 并非恒为 0.100：

| 臂 | `max_w=0.100` | `max_w=0.101` | **超限占比** |
|---|---|---|---|
| `csi800` | 69 | 15 | **17.9%** |
| `sh932000` | 72 | 21 | **22.6%** |

而配置 `barra.max_weight: 0.10`，且 QP 侧约束为 `0 ≤ w ≤ max_weight, Σw = 1`
⇒ **QP 输出不可能 >0.10** ⇒ 0.101 **必来自后处理**。

### 3.2 机制（静态代码推演，`strategies/wyckoff20/barra_constraint.py:452-465`）

```
weights = np.maximum(weights, 0)           # 非负
weights = np.minimum(weights, max_weight)  # ★ clamp 到上限 0.10
weights = weights / weights.sum()          # ★★ 重归一 —— 可把 w 推回 0.10 之上
weights[weights < min_weight] = 0          # 剔除 <0.01 微仓
weights = weights / weights.sum()          # ★★ 再次重归一 —— 再放大一次
```

**定量**：设剔除前微仓（<0.01）占比 `s_low`，重归一因子 = `1/(1-s_low)`：

| `s_low` | 因子 | `0.1000 →` |
|---|---|---|
| 0.001 | 1.00100 | 0.1001 |
| 0.005 | 1.00503 | 0.1005 |
| **0.0099** | **1.01000** | **0.1010** |

⇒ 观测到的 **0.101 与 `s_low ≈ 1%` 精确吻合** ⇒ 机制确证（非 QP 数值误差）。

### 3.3 连带发现（口径一致性，E4）

`Converged: k/20` 的 k 计数条件是 `weights > 0.001`，而后处理剔除阈值是 `min_weight = 0.01`
⇒ **k 包含了 [0.001, 0.01) 的「将被剔除仓」** ⇒ **k 不能再被直接读作最终持仓数**
（实测 k∈[10,15]，均值 12.1/11.6）—— 该口径错位**仅影响读数解释**，不影响权重落地。

### 3.4 定性、等级与处置

- **R-159（新）**：`max_weight` 软上限被后处理重归一致系统性击穿，幅度 **≤≈1%**（0.100→0.101）。
- **等级【低】**：幅度 0.1pp，**不改变任何 Sharpe/Calmar/MaxDD/单位敞口口径结论**，不影响 D-174。
- **影响面**：① 该副作用**仅存在于 barra-on 路径**（barra-off 为等权 1/n，无 QP 后处理）；
  ② **B2 中 max_weight 敏感性解读须修正**：真·有效上限 = `max_weight/(1-s_low)`；
  ③ 将来若扫 `max_weight=0.20`，同比例 0.200→0.2020，**单调性判据不受影响**。
- **处置**：**禁在跑期改动**（D-141）⇒ 登记入**合并改造清单**（与 R-144/R-145/R-148/R-156/R-157/R-158 同批，
  于启动器**自然退出**后执行）；**同时登记为 B2 定档前置检查项**（定 `max_weight` 档前确认是否需修）。
