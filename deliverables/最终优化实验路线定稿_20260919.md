## 1. 本次核验（两项，均有硬证据）

### 1.1 ✅ D-225 同源性核验：**通过（P0 风险排除）**

**风险来源**：代码里存在**静默回退路径** ——
`_assign_meta_labels_staged` 入口：`if recommended_by_date is None or not recommended_by_date: logger.warning("[L1/L2] … fallback 到 A1 标签"); return self._assign_meta_labels(...)`，
而调用点 `strategy.py:3083` 写作 `recommended_by_date = {}`。
**理论后果极严重**：标签静默降级为 legacy 三重屏障（`pt_mult 6.3 / sl_mult 4.7`），而**交易端仍用 staged（4.5 / −1.8）** ⇒ **D-225 被破坏、且无任何报错**。

**实测核验（Q5C 在跑臂 + S17b 主采纳臂）**：

| 检查项 | 结果 |
|---|---|
| `recommended_by_date 为空 / fallback 到 A1 / fallback 到全市场` 计数 | **0 / 0**（两臂均为 0）|
| 日志实证标签路径 | **`[L1/L2] 标签模式=staged_rank: 分阶段退出模拟 (S1=4.5σ/25%…`** ⇒ staged 生效且 **S1=4.5σ 与交易端一致** |
| `窄池+分阶段标签（排序/回归目标）: 240 个训练日` 出现次数 | **28 / 66 次**（每训练窗口各一次）|

**⇒ 结论：guard 真实存在但未被触发**（调用前 `recommended_by_date` 已由窄池填充）；**D-225 未被破坏，无需修复**。
**但应加固**：把「静默降级」改为「显式失败」（见 §4 第⑦道闸门）。

### 1.2 ★ 组合权重现状：**等权**（`sizing` 通道未单独启用）

- `strategy.py:3677` `self.target_weights = {}  # 非元标注模式用等权`；`max_meta_selected: 20` = 取分位前 20
  ⇒ **预测值只用于「选谁」，不用于「给多少」**。
- **但当 BARRA 启用时**（`strategy.py:3742-3765`），`probs = target_weights` 会被送入
  `barra_solve(max_weight=0.1, risk_aversion=0.5)` ⇒ **权重改由「预测值 × 风险模型」优化得到**。

**⇒ 关键推论：`Q5C`（BARRA 轴）实质上正在跑「预测值 → 权重」这条 sizing 轴**（`barra` on/off 同时改变了**权重来源**）：
**不应另开 sizing 批次**（避免重复实验）；**待 Q5C 结论出来后再判定是否需要独立立项**。

### 3.1 相对上一版路线的四处调整（附理由）

| 调整 | 内容 | 理由 |
|---|---|---|
| **① Q5P 撤销** | 原「架构对账（含生产路径判定）」**取消为独立批次** | 两个产出均已闭合：**生产路径**由用户澄清（smallcap）；**D-225 正确性核验**由本次实测完成（**通过**）。⇒ 保留 = 浪费一个批次 |
| **② Q5N 落点明确** | 明确跑在 **`smallcap` 路径** | 用户确认该路径是产品候选；若落 V10 则改完用不上 |
| **③ 不新增 sizing 批次** | 不加「排序 → 权重」独立批次 | **`Q5C`（BARRA）已在跑该轴**（`barra_solve(probs)`）⇒ 避免重复 |
| **④ Q5D 升格** | 由「Q5N 之后」改为**紧接 Q5N** | 它是唯一**直接对着硬门槛 \|MaxDD\|**、且**完全未激活**的机制（D-145 八开关全 false；Q3 结案为「未被检验」≠「无效」）|

### 3.2 为何 Q5N 仍前置于 Q5D（顺序硬约束不变）

Q5D 的阈值须按**胜出包的 \|MaxDD\| 尺度**标定（8%/12%/16%）；而 **Q5N 若胜出会改写选股与敞口路径**
⇒ 阈值与阶梯参数须在**新目标**上重标。**⇒ Q5N 必须前置。**
