## 2. 裁决结果

### H1（遗漏风格因子解释负 alpha）：**双窗口均未获支持**
| 证据 | 数值 |
|---|---|
| ε_adj 与组合候选暴露回归 R² | 轮1 全窗 **0.19%** / E0' 窗口 **2.2%**（t 全部 <1.5） |
| 2024-09-24 政策市后负 ε | 轮1 **−3062bp** / E0' **−2546bp**，期间候选暴露全部常态（idio_vol≈0.5σ、liquidity≈0.05） |
| 候选因子与官方风格冗余（窗口组合层） | idio_vol↔volatility **+0.95**、liquidity↔idio_vol +0.80 → 官方 5 风格已覆盖候选信息主体 |

### H0（选股端失效）：**占优**
| 证据 | 数值 |

| PKF meta_auc 时序（13 次重训） | 均值 0.524，2024-01-29(危机前) 0.507、2024-07-31 **0.499**、2024-09-27(政策市前) 0.506 |
| 危机窗口 ε | 2024-02 ε 反而 **+619bp**（风格踩踏为主、由回撤熔断承担）；真正的持久负 ε 在 2024-09-24 后，无暴露异常 |

### BARRA 约束适用性：**不启动（维持）**
1. 后段风格总贡献为正（轮1 后段 +5011bp），无可约束的"拖累风格"（vol 后段 −183bp 且逐月乱跳、大亏日贡献≈0）；
2. size 踩踏（2024-02 −628bp/28日）是策略身份暴露（后段正贡献 +2300bp），按"有意性×显著性"矩阵不可约束；
3. 尾部已由回撤熔断（dd_half 10%/dd_flat 15%）承担；
4. BARRA 链路本身存在基准错配（CSI800 vs 微盘池，已列修复方案未实施）——即使要启用也是另一立项。

## 3. 结论与建议方向

**负 alpha 的根因在选股端而非风格暴露/遗漏风格因子**（在 liquidity/str/idio_vol/nls 四个候选维度上检验不通过）。可执行方向（供决策）：
- **A（推荐）策略层修复**：meta_auc 均值 0.524 说明模型判别力弱——方向：标签口径（staged_binary 在暴涨期质量）、候选池（300 微盘在 ST/退市新规后的质量）、特征/训练窗口（含 2024-02 危机样本的标签污染）、超参（S 档已用于 test）；
- B：行业因子测试（需先做行业一级映射 P1 工程）；
- C：BARRA 启用（前置修复 3 缺陷后，按新立项做 A/B）。
