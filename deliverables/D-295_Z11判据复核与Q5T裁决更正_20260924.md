## 4. ★冲突澄清：D-262 与 Z17 **不矛盾**（我先前误读，此处更正）

排查 D-262 的原始出处 `_q5d_signal_direction.py`（第 57~66 行）：

```python
fwd = (close.shift(-h) / close - 1)          # close = 池指 / 策略净值序列
j  = pd.concat([vol.rename('vol'), fwd.rename('fwd')], axis=1)   # ← 同一时间序列的两列
sp = j['vol'].corr(j['fwd'], method='spearman')
q  = pd.qcut(j['vol'], 4, labels=['Q1','Q2','Q3','Q4'])          # ← 按【日期】分组
```

⇒ **D-262 是「时序口径」**：对象 = **池指（sh932000）/ 策略净值本身**，Q1~Q4 是**按池指波动率水平给【日期】分组**，
回答的是「**高波动时段**后续反弹更多吗」⇒ 服务 **`vol_target` 总敞口择时**（该层已由 D-277 关闭整层）。
**「高波组后续收益是最低波组的 4.6~5.6 倍」中的「组」= 时段组，不是股票组。**

**⇒ 与 Z17（截面口径：同一天内、跨股票）对象不同，可以同时成立**：
「**市场波动高的时段，大盘后续反弹更多**」 ∧ 「**波动高的个股，持有期内涨得更少**」。

### 新增纪律 R-166

凡 **σ／波动率 与 收益** 类关系结论，**必须注明是「时序口径」还是「截面口径」**（含对象范围与分组维度）。本次误读即为反面教材 —— 与 R-136「名字 ≠ 算法」同族。

## 7. 小白版四问

**① 这段在解决什么问题？**
昨天我用一个"5 分钟的小检验"（Z11）关掉了一整条研究线（Q5T，本来要跑 6 个实验）。你质疑它关得不对。我去把那个检验**从头到尾查了一遍**。

**② 用了什么办法？**
做了四件事：①**对照原始设计书**，看当时说好要测什么；②**翻代码**看实际测了什么；③**重算它的统计可靠性**（5 个样本够不够）；④**用正确的口径重测一遍**（新写 Z17），并**额外查了基线真实持仓的波动率偏好**（新写 Z18）。

**③ 结果是什么？—— 你的怀疑成立，而且我找到三个独立的问题：**

| 问题 | 实际情况 |
|---|---|
| **测错了时间段** | 设计书说要测"**持有期内**"的收益（和生产代码里的 `fwd_ret_5` 一致），**实际却测了"持有期结束之后的第 21~26 天"**，而且这个改动**从来没登记过**。而"该不该避开高波动股"这个问题，只能用**持有期内**的收益来回答。 |
| **把一个小检验当成了判决** | 就算测对了，它也只是在测"**标签里那个波动率成分**"——而 Q5T 改的是**训练权重**，会连带改变模型和选股。**"成分没用"推不出"改权重没用"**。你说的"标签端和交易端会同步变化、选股结果也会变"，**完全正确**。 |
| **样本根本不够** | 它自称"压力档"的依据只有 **5 天**，而且这 5 天的 `IC(σ)` **正负乱跳**（−0.168／+0.015／+0.208／−0.001／−0.179），95% 置信区间 **[−0.22, +0.17] 跨过 0**、p=0.743。**要看出它想看的效应，至少需要 0.197 的量级，而实测只有 0.025** —— 等于"没有任何证据"被写成了"证明相反"。 |

**④ 那重测之后呢？—— 结论没变，但理由翻天覆地：**

- **正确口径下**（持有期内、不受交易规则污染的收益）：**波动率越高，持有期内涨得越少**（11 个日期合并 `IC(σ)=−0.124`，置信区间 **[−0.237, −0.011] 不含 0**，显著为负）。
- **也就是说：波动率是"负向"因子，"避开高波动股"是对的。** 而 Q5T 要做的事恰恰是**让模型不再回避高波动股** ⇒ **方向错了**。
- 我还查了基线的真实持仓：**它选中股票的波动率只有候选池中位数的 71%**（65 个建仓日里 63 天都是这样，p=2.6e−12）—— **模型确实在系统性地挑低波动股**，而在"波动率是负向因子"这个事实下，**这个偏好是正确的**。
- **顺手纠正一个我自己的误读**：之前记录里有一条"微盘股高波动⇒高后续收益"（D-262，+0.1055），看起来和上面矛盾。我找到它的原始代码，发现它算的是"**整个市场/策略净值在波动高的那段时间，之后涨得更多**"（**按日期分组**，用来判断"该不该择时降仓位"），**不是"哪只股票"的问题**。**两个结论对象不同，可以同时成立**：市场波动大时大盘容易反弹，但个股层面波动大的涨得少。

**⑤ 对你意味着什么？**

- **你的怀疑不只是"合理"，而且直接改掉了一条纪律**：以后任何"要不要关掉一条研究线"的判断，**必须先报样本量、置信区间和"最小能看出的效应"**；**看不出来就只能说"无法判定"，不许说"被证伪"**（新立 R-164）。另外两条：口径必须和生产代码里的同名量**逐字对齐**、偏离必须登记（R-165）；凡是"波动率和收益"的关系，**必须说清是"时间段"层面还是"个股"层面**（R-166）。
- **Q5T 这条线仍然关着，但现在是"论证后关闭"而不是"推断后关闭"** —— 而且**关闭的理由正好相反**：不是"波动率没用"，而是"**波动率有用（负向），标签用对了**"。**否定的是"去耦合"这条路径，不是 σ 信息本身的价值。**
- **省下的钱照旧**（6 个臂、约 2 天机时），但**不是因为"5 分钟就否证了"，而是因为查完之后发现方向确实反了**。
- **意外收获**：这次核查**给下一条主线（Q5P′，按波动率给权重）添了一份独立支持** —— 既然波动率是负向因子，那"给低波动股更多权重"方向是对的。我因此给 Q5P′ 加了一条新判据（P′-6）：**必须同时报"选中/池 波动率比值"，防止把"本来就在挑低波动"的机械效果当成机制贡献**。
