## 四、⚠️ 新发现：D1 的 2024-03-26~04-24 空仓期（v1 遗漏）

### 4.1 事实

- **D1**：2024-03-26 调仓日日志 `[策略分配] AUC=0.5173 < 0.52 → 空仓`——当日旧持仓 20 只全部到期卖出后，**未买入任何新股**，2024-03-26 ~ 2024-04-24 空仓 20 天（`调仓完成，持仓数: 0`、现金 1,091,652 躺平），2024-04-25 恢复；
- **D2**：同期无空仓（R_p=0 天数 0、f_0 NaN 天数 0，positions 有记录）。

### 4.2 与 attribution 口径的联系（summary 413.9 vs daily 346.0 差异根源）

- 空仓 20 天里组合 R_p=0，**截面归因无法分解（coverage=0）→ f_0/风格/ε 全 NaN**；
- `attribution_summary.csv` 的 valid 集合（dropna 5 风格列）把这 20 天剔除 → ε_adj=+413.9bp；
- `daily_attribution.csv` 的 ε_adj 列（=active−Σ风格，空仓时=0−R_b）计入这 20 天的 −67.9bp → +346.0bp；
- **两口径差 67.9bp = 空仓期主动 −R_b 之和**。D2 无空仓期，两口径一致（−1413.1bp）。

### 4.3 空仓期对结论的影响

- 空仓期市场整体小幅上涨（R_b 合计 +67.9bp），D1 空仓**错过了这 67.9bp**（daily 口径计入 −67.9bp）；

- **结论**：空仓期对 D1 是轻微负贡献（错过上涨），不是 D1 表现更好的原因；但它解释了 summary 与 daily 的口径差，**分析中统一使用 daily 口径**（两回测可比）。

**关键事实**：
1. **规模因子收益 2024-09 后确实上升**：size 贡献从 2024Q1~Q3 的负（−1804/−923/−1070bp）转为 2024Q4~2026Q1 的大额正（+1158/+924/+714/+1451bp）；
2. **f_size 符号说明**：BARRA size 因子正收益=大盘跑赢。2024Q4~2025Q2 f_size 为负（−0.0008/日）意味着**小盘跑赢大盘**——组合超配小盘（X_size=−2.39，负暴露=偏小盘）→ 负×负=正贡献 ✓；
3. **同期 ε（特质收益）转负**（2024Q3 后持续 −8~−44bp/日）。

### 5.2 是否"一个上升另一个下降、近似互补"？——是，但需精确表述

**收益分解恒等式**（每季度近似）：
```
Active 超额 = Σ风格贡献 + ε_adj
             = (X_size·f_size + X_beta·f_beta + ...) + ε_adj
```

2024-09 后发生的结构性变化：

```
规模因子收益（f_size 负→小盘溢价强化）↑ → 风格贡献↑（+1158/+924/+714bp）
特质收益（ε）↓ → 选股 alpha 贡献↓（−472/−710/−155bp...）
两者相加 → Active 波动收窄但为正（2024Q4 +819、2025Q1 +654bp）
```

**这不是"能量守恒"式的互补，而是收益来源的切换**：
- **2024-09 前**：市场个股分化度高，风格因子收益弱（f_size 正负交替、幅度 ±0.0008），收益主要来自**选股 alpha（ε 日均 +20~45bp）**——策略靠"选出好股票"赚钱；
- **2024-09 后**：市场进入**风格/板块驱动行情**（小盘风格强化、资金板块轮动），风格因子收益放大（f_size 稳定为负=小盘持续跑赢），收益转向**风格 beta（size 贡献大幅为正）**，但个股层面同涨同跌 → **选股 alpha 空间收窄甚至转负（ε 日均 −8~−44bp）**。

**经济学含义**（这正是业界对 2024-09 后 A 股的标准解读）：
1. **风格化行情中 alpha 让位于 beta**：当资金抱团风格（微盘/小盘/红利/科技轮动）时，截面收益主要由风格/板块驱动，个股特质信息定价权重下降，选股策略的超额收益被压缩；
2. **微盘"壳溢价/游资定价"的特质成分消失**：2024-09 前微小盘个股存在持续的个体溢价（壳价值、游资炒作、事件驱动），2024-09 后该特质成分系统性消失（924 政策后市场定价转向基本面/风格），而小盘整体的风格溢价仍在（甚至强化）——所以"规模因子收益上升（风格层面）+ 特质收益下降（个股层面）"同时成立，**并不矛盾**；
3. **对策略的含义**：该策略赚的钱从"选股 alpha"切换到"小盘风格 beta"——2024-09 后它实际上变成了"小盘风格暴露 + 负选股"的组合，风格贡献为正掩盖了选股恶化（ε 为负）。

### 5.3 为什么不能说"微小盘溢价消失"（修正 v1 表述）

v1 说"微小盘溢价消失"是**不准确的**——准确表述是：
- **小盘风格溢价 2024-09 后强化**（f_size 持续为负=小盘跑赢，size 贡献大幅为正）；
- **微小盘个股的特质溢价消失/逆转**（ε 持续为负）；
- 两者是**不同层面**（风格层面 vs 个股层面），v1 混为一谈，现已澄清。

- **D1**：alpha_095_FFD 的 MDA 重要性多次进 Top-5（如 `alpha_095_FFD_neu=0.006...`），但最终特征集被**聚类代表替换**：`alpha_105_neu (代替: alpha_095_FFD_neu, 簇大小=2)`——D1 的 FeatureClustering 用同簇代表 alpha_105 替代了它；
- **D2**：同样 MDA Top-5 常客，但聚类方向相反：`alpha_095_FFD_neu (代替: alpha_150_neu, alpha_081_neu, alpha_070_FFD_neu, 簇大小=4)`——D2 中 alpha_095_FFD 成为簇代表，最终集 37/47 周期入选；
- **含义**：min_votes=2 扩大了 MDA 投票池 → 簇结构改变 → 聚类代表选择不同 → **D2 的核心特征构成与 D1 显著不同**。alpha_095_FFD 是 D2 的独有主力，若其在 2024-09 后失效（FFD 分数阶差分特征对市场结构变化敏感），则拖累 D2。**建议后续对 alpha_095_FFD 做 IC/收益归因单独验证**（本次仅能确认其为 D2 独有高频特征，无逐特征收益数据无法定量归因）。

## 七、根因归纳（三层）

1. **市场结构层（共同根因，主导）**：924 行情引发风格剧变——小盘风格溢价强化（f_size 转负、size 贡献大正）+ 个股特质溢价消失（ε 转负）+ 微盘流动性危机（2024-12、2025-07）→ 策略的"选股 alpha"系统性失效。特征池换血（Jaccard 0.62-0.65、2024-10-25 大换血 11 特征）与 IC/PSI 正常证明这不是选择器失灵，而是市场环境变化；
2. **因子验证层（D2 特有，放大）**：`min_votes_to_remove: 2` 实质关闭因子验证剔除（SHAP 恒 0、ADV 恒 5、CIC 单票失效）→ MDA 投票池 112→159（+42%）→ 更多不稳定因子入选 → D2 的 ε 每季度更负（α 累计差 −1827bp）；
3. **特征构成层（D2 特有）**：min_votes 差异导致聚类代表选择不同，**alpha_095_FFD 成为 D2 独有主力（37/47）**——该特征在 D1 中被聚类替代、几乎不用，需单独验证其 2024-09 后的有效性。

## 九、结论与建议（未改动任何文件）

### 结论

1. **2024-09 后 α 陡降是两回测共同的市场性现象**：由 924 行情引发的"风格收益上升 + 特质收益下降"（风格化行情，alpha 让位于 beta），叠加 alpha191 因子外推失效——**不是代码缺陷，D1/D2 都有**；
2. **D2 额外恶化 −1827bp（summary 口径）α**：`min_votes_to_remove: 2` 关闭因子验证剔除 → MDA 池 +42% → 更多不稳定因子入选（含 D2 独有主力 alpha_095_FFD）；
3. **D1 的 2024-03-26 空仓期**：门控触发，对 D1 影响轻微（错过 +67.9bp 上涨），非 D1 更好的原因。
