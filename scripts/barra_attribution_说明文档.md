## 一、这个脚本是干什么的

**大白话**：一个投资组合每天赚的钱，不是"一个数"，而是由很多部分组成的——有跟着大盘赚的、有因为押注"小盘股"赚的、有因为"高波动"赚的、还有纯靠选股赚的。**收益归因（attribution）就是把这笔钱按来源拆开**，让你看清：策略到底靠什么赚钱？

**类比**：就像看工资条——税前总收入 = 基本工资 + 绩效 + 奖金 + 补贴。你不知道每个部分的数额，就无法评价"这个月干得好不好"。归因给组合收益做同样的事。

**脚本做什么**（一句话）：
> 输入一份回测结果（每天买了什么、每天赚了多少），输出"收益来源分解表 + 图表"，告诉你：**超额收益里，多少来自市场、多少来自规模/β/价值/动量/波动率这些风格、多少来自纯粹的选股能力（alpha）**。

**输出在回测目录下的 `attribution/` 子目录**：8 个数据文件 + 6 张图 + 1 份报告 + 1 份术语表（详见[第四节](#四输出文件全解与解读方法)）。

## 二、方法论：从收益到归因

### 2.1 三个最基本的收益概念

先约定符号（下文所有公式都用这套符号）：

| 符号 | 含义 | 大白话 |
|---|---|---|
| $R_{p,t}$ | 组合第 $t$ 天的**日收益率** | 你的组合今天赚/亏了几个点 |
| $R_{b,t}$ | **基准**（上证综指）第 $t$ 天的日收益率 | 大盘今天涨/跌了几个点 |
| $Active_t$ | $R_{p,t} - R_{b,t}$，**超额收益** | 今天跑赢/跑输大盘几个点 |

**数学细节**：日收益率定义为当日收盘净值相对前一日的变化率 $R_t = (NAV_t/NAV_{t-1}) - 1$，属于**算术收益**。为什么用算术而不用对数收益，见 [2.7](#27-算术收益-vs-复合收益复利效应)。

---

### 2.2 因子模型：收益分解的基本思想

**直觉**：一只股票的涨跌，从来不是它自己"独立"决定的，通常可以拆成三层：

```
股票 i 今天的收益 = 大盘整体涨跌（所有人共享）
                  + 它所在"风格"的涨跌（小盘股今天整体跑赢？高β股今天整体跑输？）
                  + 它自己特有的事件（公司出了利好/利空）
```

**数学（单只股票）**——这就是多因子模型的基石：

$$r_{i,t} = f_{0,t} + \sum_{j=1}^{J} \beta_{i,j,t}\, f_{j,t} + u_{i,t}$$

- $r_{i,t}$：股票 $i$ 在第 $t$ 天的收益
- $f_{0,t}$：**截距**，即"大盘（市场）本身"的收益
- $f_{j,t}$：第 $j$ 个**风格因子在第 $t$ 天的收益**（如"规模因子收益"：当天小盘股整体相对大盘股多赚多少）
- $\beta_{i,j,t}$：股票 $i$ 对因子 $j$ 的**暴露（exposure）**，即这只股票在多大程度上属于"小盘"、"高β"、"价值"等风格
- $u_{i,t}$：**特质残差**，模型解释不了的部分

**大白话**：$\beta$ 是"你是谁"（性格/属性），$f$ 是"今天这个属性整体值多少钱"（风口），$u$ 是"你自己作出来的额外结果"。

---

### 2.3 如何估计因子收益：每日截面回归（含推导）

**问题**：第 $t$ 天，我们观测到全部股票（例如沪市 2407 只）的收益 $r_{i,t}$ 和它们各自的暴露 $\beta_{i,j,t}$，但**不知道**因子收益 $f_{j,t}$。怎么把 $f_{j,t}$ 反推出来？

**答案**：第 $t$ 天把所有股票放在一起做一个**截面回归**（横截面：同一天、很多只股票），把 $f_{0,t}, f_{1,t}, \dots, f_{J,t}$ 当成待估计的系数。写成矩阵形式：

$$\mathbf{r}_t = \mathbf{X}_t \mathbf{f}_t + \mathbf{u}_t$$

其中 $\mathbf{r}_t$ 是 $N$ 只股票的收益列向量，$\mathbf{X}_t$ 是 $N \times (J+1)$ 的暴露矩阵（第一列全 1 对应截距 $f_{0,t}$），$\mathbf{f}_t$ 是 $(J+1)$ 维待估系数。

**普通最小二乘（OLS）推导**：最小化残差平方和

$$\min_{\mathbf{f}_t} \ \|\mathbf{r}_t - \mathbf{X}_t\mathbf{f}_t\|^2$$

对 $\mathbf{f}_t$ 求导并令其为 0（矩阵微分）：

$$\frac{\partial}{\partial \mathbf{f}_t} (\mathbf{r}_t - \mathbf{X}_t\mathbf{f}_t)'(\mathbf{r}_t - \mathbf{X}_t\mathbf{f}_t) = -2\mathbf{X}_t'(\mathbf{r}_t - \mathbf{X}_t\mathbf{f}_t) = 0$$

得到**正规方程（normal equation）**：

$$\mathbf{X}_t'\mathbf{X}_t \mathbf{f}_t = \mathbf{X}_t'\mathbf{r}_t \ \Longrightarrow\ \hat{\mathbf{f}}_t = (\mathbf{X}_t'\mathbf{X}_t)^{-1}\mathbf{X}_t'\mathbf{r}_t$$

**加权版本（本脚本采用）**：大盘股对"市场收益"的影响理应更大，所以用**市值权重** $w_i$ 加权（大公司占市场权重高）。加权 OLS 等价于把每行乘以 $\sqrt{w_i}$ 后做普通 OLS：

$$\hat{\mathbf{f}}_t = (\mathbf{X}_t'\mathbf{W}_t\mathbf{X}_t)^{-1}\mathbf{X}_t'\mathbf{W}_t\mathbf{r}_t, \qquad \mathbf{W}_t = \operatorname{diag}(w_{1,t},\dots,w_{N,t})$$

**稳健化（Winsorize）**：个别股票可能有极端收益（如停牌复牌、数据错误），会扭曲回归。本脚本先把收益做 **1%/99% 分位截尾（Winsorize）**——小于 1% 分位的收益被"钳"到 1% 分位，大于 99% 分位的被钳到 99% 分位，再进回归。**大白话**：把特别离谱的极端值先按到合理范围，防止一只股票绑架整个市场的因子收益。

> **结果**：每天得到一组 $\hat{\mathbf{f}}_t$，即"当天每个风格值多少钱"（因子收益）。把所有天串起来，就得到每条因子收益的时间序列。

### 2.4 组合暴露：组合在风格上"偏了多少"

**直觉**：上面估出了"风格价格" $f_{j,t}$，还要知道**你的组合暴露在这些风格上多少**，两者相乘才是"你靠这个风格赚了多少"。

**第一步：每只股票的因子暴露**。对持仓股票用本地 `barra_builder`（BARRA 风格因子体系）计算 5 个风格暴露：

| 因子 | 含义 | 备注 |
|---|---|---|
| **size 规模** | 对数市值 | 越大越偏大盘 |
| **beta** | 对市场的敏感度 | >1 涨跌都比大盘猛 |
| **value 价值** | 账面市值比等估值指标 | 高 = 偏价值（便宜） |
| **momentum 动量** | 过去一段时间的涨幅 | 高 = 偏追涨 |
| **volatility 波动率** | 收益波动程度 | 高 = 偏波动 |

**第二步：标准化（关键一步，业界标准做法）**。原始因子值（如市值 500 亿 vs 50 亿）不能直接比较，需要变成"相对基准偏离了几个标准差"：

$$z_{i,j} = \frac{x_{i,j} - \mu_{j}^{w}}{\sigma_{j}^{w}}$$

其中 $\mu_{j}^{w}, \sigma_{j}^{w}$ 是**基准池（沪市全部 A 股）的市值加权均值与标准差**：

$$\mu_{j}^{w} = \frac{\sum_i w_i x_{i,j}}{\sum_i w_i}, \qquad \sigma_{j}^{w} = \sqrt{\frac{\sum_i w_i (x_{i,j}-\mu_j^w)^2}{\sum_i w_i}}$$

**为什么用"基准池市值加权"参数而不是全体等权？** 这是业界（Barra 框架）的核心：基准池本身就是"市场平均"的代表。用它的参数标准化后，**基准池自身的市值加权平均暴露 ≈ 0**，于是"组合暴露 = 组合相对基准的偏离"。例如 size 组合暴露 −2.36 表示：**组合整体比沪市平均偏小盘 2.36 个标准差**，是极强的微盘偏好。

**第三步：组合暴露**。组合的因子暴露 = 持仓股票的暴露按持仓市值加权平均：

$$X_{j,t} = \sum_{i \in \text{持仓}} w_{i,t}\, z_{i,j,t}$$

### 2.5 绝对口径 vs Active 口径（务必看懂的一节）

组合收益有两种分解方式，本脚本同时给出，但**以 Active 口径为最终呈现**：

**绝对口径**（把市场单列）：

$$R_{p,t} = \underbrace{f_{0,t}}_{\text{市场}} + \underbrace{\sum_j X_{j,t} f_{j,t}}_{\text{风格}} + \underbrace{\varepsilon_t}_{\text{特质}}$$

**Active 口径**（相对基准上证综指）：

$$Active_t = R_{p,t} - R_{b,t} = \sum_j X_{j,t} f_{j,t} + \varepsilon^{adj}_t$$

**两者关系（重要恒等式，本脚本逐行误差为 0）**：

$$\varepsilon^{adj}_t = \varepsilon_t + (f_{0,t} - R_{b,t})$$

**这个恒等式的含义**：$f_0$ 是"沪市**市值加权**市场收益"（回归截距，权重向大市值倾斜），$R_b$ 是"**上证综指**收益"（**总股本加权**，超大盘权重股占比极大）。两者是两种不同的"市场平均"，差值 $f_0 - R_b$ 就是**市场口径差异**。它被 Active 口径吸收进 $\varepsilon^{adj}$。

**本回测的实测数字**：$f_0$ 累计 = 5006 bp，$R_b$ 累计 = 2690 bp，差异 **2316 bp**——上证综指按总股本加权，被银行/石油等超大盘权重股拖累，5 年多累计落后市值加权市场约 23 个百分点。策略不持有这些被压制的权重股，因此在"跟上证综指比"的框架下，这部分差异是**策略相对基准的真实超额来源之一**，会计入 alpha（详见[5.3](#53-解读-alpha与特质收益)）。

> **一句话**：绝对口径回答"钱从哪来"，Active 口径回答"相对上证综指，你多赚的钱从哪来"。**评价策略以 Active 口径为准**（你指定的基准）。

### 2.6 特质收益 ε 与 alpha

**定义**（Active 口径）：

$$\varepsilon^{adj}_t = Active_t - \sum_j X_{j,t} f_{j,t}$$

**大白话**：把"风格押注赚的钱"从超额收益里剥掉，剩下的就是**纯粹靠选股**（选中的股票在同类中本身跑得更强）赚的钱——**这就是策略的 alpha**。

**三点必须知道的**：

1. **单日的 ε 不可信**：单日 ε 混合了大量运气/噪声（残差），没有意义；**长期累计的 ε 才体现真实选股能力**。
2. **ε 与 alpha 的关系**：ε 是"选股 alpha + 未解释残差"的合体。本脚本里 Active 口径的 $\varepsilon^{adj}$ 就是该基准下的 alpha 估计。
3. **R² 辅助判断**：$R^2 = 1 - \mathrm{Var}(\varepsilon^{adj})/\mathrm{Var}(Active)$ 衡量的是**风格因子对"每日超额收益的方差（波动）"的解释能力**。**⚠️ 重要：R² 与"贡献占比"是两个正交的统计量——R² 看日度波动（二阶矩/方差），占比看累计水平（一阶矩/均值）。两者可以同时出现"R² 为负 + 风格贡献占 76%"（本回测正是如此），不矛盾**，原因见 [2.7-补充](#277-补充方差与水平分离为什么r²为负与贡献占比不矛盾)。

### 2.7 算术收益 vs 复合收益（复利效应）

**两个"总收益"**：
- **算术累计**：$\sum_t r_t$（把每天收益直接相加）
- **复合收益**：$R = \prod_t (1+r_t) - 1$（每天的钱滚进本金再赚，期末/期初−1）

**复利效应（波动拖累）的数学**：由泰勒展开 $\ln(1+r) \approx r - r^2/2$（$r$ 很小时），

$$\ln(1+R) = \sum_t \ln(1+r_t) \approx \sum_t r_t - \frac{1}{2}\sum_t r_t^2 < \sum_t r_t$$

所以**复合收益通常小于算术累计**，差值 ≈ $\frac{1}{2}\sum r_t^2$（正比于总波动），这就是"波动拖累"。

### 2.7-补充 方差与水平分离：为什么 R² 为负与贡献占比不矛盾

**问题**：本回测同时出现"Active R² = −1.632"和"风格贡献占超额 76%"，看起来矛盾。**不矛盾——它们度量两个正交的维度**：

| | 度量什么 | 数学定义 | 本回测 |
|---|---|---|---|
| **贡献占比** | 累计收益的**水平**（钱从哪来） | $\sum S_t / \sum Active_t$ | 风格占 76% |
| **R²** | 每日收益的**方差/波动**被解释多少 | $1 - \mathrm{Var}(\varepsilon)/\mathrm{Var}(Active)$ | −1.632 |

**为什么能同时成立？用方差恒等式拆开看**（$Active = S + \varepsilon$，$S$=风格贡献）：

$$\mathrm{Var}(Active) = \mathrm{Var}(S) + \mathrm{Var}(\varepsilon) + 2\,\mathrm{Cov}(S,\varepsilon)$$

**本回测实测（精确到浮点）**：
- $\mathrm{Var}(S) = 2.64\times10^{-4}$（风格日波动 σ=162.5 bp）
- $\mathrm{Var}(\varepsilon) = 2.70\times10^{-4}$（特质日波动 σ=164.2 bp）
- $2\,\mathrm{Cov}(S,\varepsilon) = -4.31\times10^{-4}$（**风格与特质强负相关，corr = −0.808**）
- $\mathrm{Var}(Active) = 1.02\times10^{-4}$（组合日波动 σ=101.2 bp）

**解读**：风格贡献与特质收益**日度强负相关（−0.808）**——风格赚的日子特质倾向亏，两者互相抵消，使得组合超额的实际波动（101 bp）**远小于**各成分自身的波动（162/164 bp）。于是 $\mathrm{Var}(\varepsilon) > \mathrm{Var}(Active)$，R² 为负。

**但累计水平完全不同**：风格日均 +3.87 bp × 920 天 = 3562 bp（76%），特质日均 +1.23 bp = 1131 bp（24%）。**均值上风格是主力，方差上风格解释不了波动**——就像"工资主要靠基本工资（水平），但每月工资的波动主要来自绩效（方差）"，两者完全可能并存。

**类比**：你请客的**总账单** 76% 是菜钱（风格），但每次结账金额的**波动**主要是酒水钱（特质）引起的——账单的构成和账单的波动是两回事。

> **给读者的实操提醒**：解读归因时永远同时看两个数——"累计贡献占比"（钱从哪来）和"R²"（每天的波动谁在驱动），只看任何一个都会误读。

**为什么归因必须用算术**（业界标准：BARRA / Morningstar / Brinson 全部如此）：
1. **线性可加是拆分的先决条件**：组合收益 = 持仓加权和，截面回归也是线性模型 → 因子贡献 $X_j f_j$ 可以**相加**，Σ贡献 ≡ 组合收益，误差 0。复合收益 $\prod(1+r)-1$ 是非线性的，数学上无法线性拆分。
2. **日频是标准单位**：每日因子收益 $f_j$ 就是日算术收益，贡献天然是算术量。

**一个反直觉现象（本回测出现）**：Active 算术累计 46.93%，但**复合 Active = 52.49%，复合 > 算术**！这违反"复合≤算术"吗？

**不违反**。"复合≤算术"是对**每期平均**说的（几何平均 ≤ 算术平均，本例依然成立：0.0449% < 0.05%）。而**总复合** $R = e^{\sum \ln(1+r_t)} - 1$ 与总算术 $\sum r_t$ 的比较，还受 $e^x-1$ 的**凸性**影响：当 $\sum \ln(1+r_t)$ 与 $\sum r_t$ 的差距不大时，$e^{0.4137}-1 = 0.5125$ 可以大于 $0.4611$。本例超额收益序列的凸性补偿大于波动拖累，所以复合略高——**两者都是正确口径，方向不固定**。

### 2.8 Carino 链接：把算术归因"接"到复合收益（含推导）

**问题**：算术归因虽然线性可加，但它的累计（Σ日贡献）≠ 复合收益。客户/报告方常问"你归因出来的总和为什么和我看到的复合收益率对不上？"。

**解法（Carino 1999，业界高端归因的标准增强）**：找一个逐日**链接系数** $k_t$，把每天的算术贡献"平滑缩放"后累加，使**链接后的总和精确等于复合收益**。

**推导**：

- 对数收益可加（精确恒等式）：$\ln(1+R) = \sum_t \ln(1+r_t)$
- 对每个单日：$\ln(1+r_t) = r_t \cdot \dfrac{\ln(1+r_t)}{r_t}$
- 代入得：$\ln(1+R) = \sum_t r_t \cdot \dfrac{\ln(1+r_t)}{r_t}$
- 定义**链接系数**：

$$k_t = \frac{R}{\ln(1+R)} \cdot \frac{\ln(1+r_t)}{r_t}$$

- **恒等式证明**：$\sum_t k_t r_t = \dfrac{R}{\ln(1+R)}\sum_t \ln(1+r_t) = \dfrac{R}{\ln(1+R)} \ln(1+R) = R$ ✓

即：把每天收益 $r_t$ 乘上 $k_t$ 再累加，精确得到复合收益 $R$。由于每天贡献分解 $r_t = \sum_j a_{t,j}$（$a_{t,j}$ 为因子 $j$ 当天的算术贡献），因此

$$\sum_j \underbrace{\sum_t k_t\, a_{t,j}}_{\text{因子 j 的链接贡献}} = R$$

**链接后各因子贡献之和 ≡ 复合收益**（本回测恒等误差 8.44e-15，即浮点精度极限）。

**数值细节**：$r_t \to 0$ 时 $\ln(1+r_t)/r_t \to 1$（用极限处理防除零）；$R \to 0$ 时取 $R/\ln(1+R) \to 1$。

**本脚本的 Carino 用于 Active 口径**：$r_t = Active_t$，$R$ = 复合 Active 超额（本回测 52.49%）。输出 `carino_attribution.csv`（每个因子链接后的贡献）与 `carino_link_factors.csv`（每天 $k_t$）。

> **为什么这比直接改复合归因好**：复合收益无法线性分解，强行复合归因会破坏"Σ贡献=总收益"的恒等；Carino 保留算术分解的线性结构，只在**累计时**做一次平滑缩放，两边的好处都有。

---

### 2.9 指标速查（图与验证里出现）

| 指标 | 公式（直觉） | 用在哪 |
|---|---|---|
| **AUC** | 随机抽一对(正,负)样本，模型给正样本打更高分的概率；0.5=瞎猜，1=完美 | 模型验证、AUC 门控 |
| **R²** | $1 - \mathrm{Var}(\text{残差})/\mathrm{Var}(\text{总})$，风格解释超额的占比 | 报告 |
| **Pearson 相关** | $\rho = \dfrac{\sum(x-\bar x)(y-\bar y)}{\sqrt{\sum(x-\bar x)^2\sum(y-\bar y)^2}}$，两序列线性相关度 ∈[−1,1] | 段间相似性矩阵 |
| **IoU** | 两集合交集/并集，∈[0,1]，衡量"位置"重叠 | 段间相似性矩阵 |
| **PSI** | 分布漂移指标，>0.15 认为分布显著漂移 | （特征筛选，脚本外） |
| **交叉验证相关** | 重建暴露 vs 官方快照暴露的截面相关 | 暴露可信度验证 |

### 3.4 关键设计决策（为什么这么做）

1. **基准 = 上证综指**（用户指定）：基准域 = 沪市全部 A 股，暴露标准化参数、因子收益回归域、市值权重全部取自沪市域；
2. **组合侧重算暴露**：持仓（可能含深市微盘股）与 CSI800 无交集，必须用本地 barra_builder 对持仓股重算暴露，与基准池同一标准化体系；
3. **市场收益用真实指数**（而非市值加权合成）：避免个别股票复权异常污染（曾遇到 600795 单日 +30% 异常）；
4. **因子收益回归加 Winsorize**：稳健化；
5. **统一有效归因日**：只有"active + 5 风格 + ε_adj 都完备"的日子才参与归因（末日前因子收益未生成则剔除），保证 Σ风格+α ≡ Active 精确恒等（4e-16）。

### 4.2 `daily_attribution.csv` 逐列解读

| 列 | 含义 | 怎么读 |
|---|---|---|
| `date` | 交易日 | — |
| `R_p` | 组合当日收益 | 组合今天赚/亏 |
| `R_b` | 上证综指当日收益 | 大盘今天涨/跌 |
| `f_0` | 回归截距（沪市市值加权市场收益） | **模型内部项，非评价基准**，仅作构成说明 |
| `size`…`volatility` | 各风格因子当日贡献 $X_j f_j$ | 今天靠这个风格赚/亏了多少 |
| `epsilon` | 绝对口径特质残差 $\varepsilon$ | 相对市值加权市场的选股残差 |
| `coverage` | 暴露覆盖权重 | 接近 1 = 持仓基本都算到暴露 |
| `active` | $R_p - R_b$ 当日超额 | **核心列** |
| `epsilon_adj` | Active 口径特质/alpha $\varepsilon^{adj}$ | **策略 alpha 的逐日值** |
| `period` | 所属调仓周期序号 | 每 20 日一期 |

**检查恒等**（可自己验算）：
- `f_0 + size+…+volatility + epsilon = R_p`（绝对口径，误差 0）
- `size+…+volatility + epsilon_adj = active`（Active 口径，误差 4e-16）
- `R_p − R_b = active`（定义）

### 4.3 `attribution_summary.csv` 解读

只有 6 行（5 风格 + alpha），全为 **Active 口径**：

| 列 | 含义 |
|---|---|
| `factor` / `label` | 因子名 / 中文名 |
| `cum_active_contribution` | Active 累计贡献（小数，×1e4 = bp）；**6 行相加 = Active 总超额** |
| `pct_of_active` | 占 Active 总超额比例 |
| `avg_portfolio_exposure` | 平均组合暴露（相对基准的标准差数） |

**读法**：哪一行的 `pct_of_active` 大，说明超额主要靠哪个来源。注意**风格因子行**回答"风格押注贡献"，**alpha 行**回答"选股贡献"。

### 4.4 `period_attribution.csv`

把 920 天分成每 20 交易日一个周期，逐周期展示 `active / size / beta / value / momentum / volatility / epsilon_adj`。**用途**：看 alpha 是否稳定——理想策略的 alpha 应多数周期为正；若 alpha 集中在少数周期爆发，则可能是运气。

### 4.5 `carino_attribution.csv` / `carino_link_factors.csv`

- `carino_attribution.csv`：`arith_cum`（算术累计贡献，bp）、`linked_contrib`（Carino 链接后对**复合 Active 超额**的贡献，小数×100=%）、`pct_of_compound`（占复合超额比例）。**6 行 linked_contrib 相加 = 复合 Active 超额**（恒等误差 8e-15）。
- `carino_link_factors.csv`：每天 $k_t$。$k_t \approx 1$ 附近波动；整体复合高于算术时 $k_t$ 均值 >1，反之 <1。

**与 summary 的区别**：summary 是算术口径（Σ贡献=算术 Active 4693bp）；carino 是复合口径（Σ链接贡献=复合 Active 52.49%）。两者都是正确的，**呈现角度不同**。

### 4.6 `factor_exposures.csv`

每日组合 5 因子暴露。**读法**：暴露的时间序列反映策略风格漂移——如果 size 暴露长期 −2 以上，说明策略持续重仓小盘；如果某个暴露在某个时点突然跳变，说明那期调仓风格突变。

## 五、实例解读：用真实回测完整走一遍

以下所有数字来自 `results/SmallAlpha191_20220801_20260522_20260805230911/attribution/`（微盘策略，2022-08~2026-05，920 个有效归因日，基准=上证综指）。

### 5.1 第一层：整体表现

| 指标 | 数值 |
|---|---|
| 有效归因日 | 920 天 |
| Active 算术累计 | **+4693 bp（+46.93%）** |
| 复合 Active（Carino） | **+52.49%**（恒等误差 8e-15） |
| 暴露覆盖 | 100% |

**读法**：策略 4 年多累计跑赢上证综指 46.93%（算术）。复合 52.49% > 算术 46.93% 是复利凸性所致（见 2.7），两者都正确。

### 5.2 第二层：超额从哪来（Active 累计归因）

| 来源 | 贡献 (bp) | 占 Active | 平均暴露 |
|---|---|---|---|
| 规模 size | +1803 | +38.4% | **−2.36** |
| Beta | +2350 | +50.1% | +0.32 |
| 价值 value | −216 | −4.6% | −0.47 |
| 动量 momentum | −138 | −2.9% | −0.22 |
| 波动率 volatility | −237 | −5.0% | +0.14 |
| **α（特质/选股）** | **+1131** | **+24.1%** | — |
| **合计** | **4693** | **100%** | — |

**读法（三步）**：
1. **整体**：超额 = 风格押注 76%（3562 bp）+ 选股 alpha 24%（1131 bp）——**这是一个偏风格的策略**；
2. **风格细节**：size 暴露 −2.36（比沪市平均偏小盘 2.36σ）+ beta 暴露 +0.32（偏敏感），且这 4 年小盘和高β因子收益为正 → 两项合计贡献 +4153 bp，是超额主力；价值/动量/波动率小负，是次要拖累；
3. **alpha**：剔除全部风格后仍跑赢上证综指 +11.31%——**有正 alpha**。

### 5.3 解读 alpha 与特质收益（最容易误解的点）

1. **α = ε_adj = +1131 bp**：这是"相对上证综指、剔除风格押注后"的选股/特质贡献，**正 alpha**；
2. **为什么 ε_adj（+1131）与绝对口径 ε（−1185）差 2316 bp**：因为 `ε_adj = ε + (f_0 − R_b)`，而 $f_0 − R_b = 5006 − 2690 = 2316$ bp 是**市场口径差异**（上证综指总股本加权被超大盘权重股拖累 vs 市值加权市场）——它被 Active 口径计入 alpha。**在"跟上证综指比"的框架下，这 2316 bp 是策略相对基准的真实超额来源之一**（策略不持有那些被压制的权重股），计入 alpha 是正确且无需剥离的；
3. **Active R² = −1.632 的正确理解**：R² 衡量的是**每日超额波动的方差**被风格解释的比例，它**不是**"贡献占比"。实测方差分解：风格日波动 σ=162.5 bp、特质日波动 σ=164.2 bp、两者相关系数 **−0.808**（强负相关，互相抵消）→ 组合超额实际日波动仅 101.2 bp < 各成分波动 → $\mathrm{Var}(\varepsilon)>\mathrm{Var}(Active)$ → R²<0。**一句话：风格贡献与特质收益日度强对冲，导致"波动"上风格解释不了（R² 负），但"累计水平"上风格仍占 76%——两者度量不同维度，不矛盾**（详见 [2.7-补充](#277-补充方差与水平分离为什么r²为负与贡献占比不矛盾)）；
4. **结论**：该策略**相对上证综指有正 alpha（+11.31%）**，同时风格贡献（小盘+高β）占超额累计大头（76%）——它是"风格为主（累计水平）、选股为辅但为正（且日度对冲风格波动）"的策略。

### 5.4 周期归因怎么用

打开 `period_attribution.csv`：逐周期看 `epsilon_adj` 列——若多数周期为正且无明显"暴富周期"，alpha 可信度高；若 alpha 集中在 1~2 个周期爆发，需警惕运气成分。

## 六、常见问题 FAQ

**Q1：为什么归因用算术收益，而报告写的是复合收益？**
A：归因要线性拆分（Σ贡献≡总收益），只有算术满足；复合收益非线性、无法拆分。两者差异=复利效应，报告会同时给出并注明（业界标准：BARRA 等全部用算术归因）。

**Q2：策略的 alpha 到底是哪一项？**
A：**Active 口径的 `epsilon_adj`**（summary 表"特质/alpha"行，+1131 bp）。绝对口径的 `epsilon` 是相对"市值加权市场"的残差，与用户指定基准（上证综指）不一致，只用于解释构成。

**Q3：为什么 ε 和 ε_adj 差这么多？**
A：`ε_adj = ε + (f_0 − R_b)`。$f_0$（市值加权市场收益）与 $R_b$（上证综指总股本加权收益）是两种市场口径，差 2316 bp 被吸收进 ε_adj。详见 5.3。

**Q4：Active R² 为负是什么意思？**
A：R² 衡量**每日超额收益波动的方差**被风格解释的比例，与"累计贡献占比"是两个不同维度（方差 vs 水平）。R² 为负意味着**风格贡献与特质收益日度强对冲**（本回测 corr=−0.808）：两者各自日波动很大（162/164 bp），但互相抵消后组合超额实际波动仅 101 bp → 特质方差大于超额方差 → R²<0。**它不表示"超额主要来自风格外"，也不表示 alpha 大**——它只说明"用风格预测每日超额"的预测力弱。累计水平上风格仍可占 76%（详见 2.7-补充）。

**Q5：为什么有的因子交叉验证相关只有 0.5~0.9？**
A：交叉验证是"本地重建暴露 vs 官方 CSI800 快照"的截面相关。差异主要来自数据口径（复权方式、市值源、市场收益代理），归因内部自洽不受影响（组合暴露与因子收益同口径）。

**Q6：为什么某些训练周期 AUC 恰好 0.5？**
A：AUC=0.5 表示模型退化为常数预测（无信号折）。弱信号池（如沪深300 大票）的某些时段因子信号消失时会出现，系统有"排除弱模型 + AUC 门控"双重兜底，属设计内行为（详见特征筛选文档）。

**Q7：我想给另一个回测跑归因，要注意什么？**
A：回测目录须含 positions.csv + daily_values.csv；持仓若含深市股，暴露用沪市基准池参数标准化（Active 收益含沪深市场分割成分，报告已注明）；首次运行约 30 分钟，之后缓存复用约 3 分钟。

**Q8：可以换成其他基准吗（如沪深300、全市场）？**
A：可以。修改脚本常量 `BENCH_NAME` / `BENCH_EXPOSURE_POOL` / `INDEX_FILE`（分别对应基准名称、暴露域、指数文件），清空缓存重建即可。基准域决定"和谁比、用什么参数标准化"。
